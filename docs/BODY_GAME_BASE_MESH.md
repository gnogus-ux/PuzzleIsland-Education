## 1. 사용 장면과 분리 계획

01:30의 기획 화면은 탑다운 슈터와 가까운 렌더를 함께 고려하고 전체 캐릭터 목표로 약20,000 tris를 적는다. 이는 강좌 예제의 **목표**다. 이 편에서 최종 전체 캐릭터를 측정한 값도, Android 권장 예산도 아니다.

분리 가능한 헬멧·머리·장비와 몸 베이스에 포함할 부분을 계획한다. 예제는 부츠·가슴 판을 몸에 포함하지만 장비 교체가 있는 다른 게임에서는 분리할 수 있다고 설명한다. 관절을 가로지르는 유연한 부위와 한 뼈에 붙을 단단한 부위를 같은 방식으로 취급하지 않는다. 루미의 별도 머리를 합치거나 승인 의상을 베이스에 융합하라는 규칙으로 확대하지 않는다.

## 2. 기준 이미지·축·Mirror

정면·측면·위쪽 이미지를 Empty로 배치해 바닥과 비율을 맞춘다. 강좌의 약1.8m 예제 크기를 루미 키로 고정하지 않는다. 실제 제작은 승인 원본·측정 기준에 맞춰야 한다. 강좌 자료실·유료 멤버십·템플릿·캐릭터 에셋을 다운로드하지 않았다.

몸 큐브의 절반을 편집하고 Mirror X/Clipping을 둔다. 손·발을 별도로 만들 때 오브젝트 원점은 대칭 기준에 두고 Edit Mode에서 형체를 옮기는 방법이 나온다. 화면의 월드 X와 모든 오브젝트의 로컬 X가 언제나 일치한다고 가정하지 않는다. [Mirror5.2 공식 문서](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/mirror.html)의 원점·로컬 축·Mirror Object·Merge Distance 조건을 확인한다.

## 3. 몸통·골반·팔다리의 큰 형태

처음에는 허리에서 위아래로 넓은 덩어리를 연장한다. 다리 시작을 사타구니 쪽에서 분리하고, 팔은 어깨에서 바깥으로 별도 진행한다. 루프가 전신 전체로 무조건 이어지지 않도록 국소적으로 방향을 바꾼다.

정면 윤곽 다음에는 측면에서 가슴·등·복부·엉덩이의 깊이를, 위에서 팔과 몸의 폭을 조절한다. 12:45 확대는 위쪽 기준에 맞추기 전의 평평한 깊이, 14:45는 추가 선을 둔 몸통의 입체 형태를 보여 준다. 초기의 상자 모양 단면을 완성 상태로 받아들이지 않는다.

세로 루프와 Edge Slide 등을 사용해 모서리·간격을 조절한다. 원본 자체에서 부피를 만들고 여러 방향으로 확인하는 것이 핵심이다. X-Ray로 선택할 때 반대쪽이나 무관한 부위까지 움직이지 않는지도 본다. 조작 배속 구간은 모든 클릭 순서를 연속 검증한 것으로 처리하지 않았다.

## 4. 손과 손목 연결

별도 손가락을 복제하고 손바닥·엄지 뿌리를 연결한다. 반복되는 손가락 기본 제작은 [손 기본형](HAND_BUILDING.md)과 [손 리토폴로지](HAND_RETOPOLOGY.md)를 함께 읽는다. 예제의 엄지 회전 수치와 손 크기를 캐릭터의 고정 치수로 옮기지 않는다.

손바닥에서 손목으로 가면서 경계 수를 줄여 팔 입구에 맞춘다. 자막의18→14→12는 해당 예제의 연결 계산이다. 숫자만 맞춰 실제 대응 위치가 어긋나면 Bridge가 비틀리거나 단면이 찌그러질 수 있다.

34:10 확대는 접합 직전의 열린 손목 경계를 보여 준다. 손을 선택하고 몸을 마지막 활성 오브젝트로 해서 Join한 뒤 두 경계를 **Bridge Edge Loops**로 잇는다. **Join만으로 정점이 용접되는 것은 아니다.** 실제 제작에서는 경계의 순서·방향, 내부 캡/면, 중복 정점·틈을 다시 확인한다.

## 5. 발과 발목 연결

별도 큐브에서 옆 윤곽·바닥·뒤꿈치를 잡고 앞부분을 나눈다. 예제는 외계인의 두 갈래 부츠/발과 사이 막을 만든다. 이를 사람 발의 기본 해부 구조나 루미의 맨발 목표로 재사용하지 않는다. 재사용할 것은 별도 단면 제작, 국소 밀도 감소, 바닥과 발목 접합 방법이다.

40:20 확대는 앞의 여러 열을 뒤쪽 적은 열로 전환하는 중간 상태를 보여 준다. 임시로 일부 면을 끊어 추가 루프가 전체를 가르지 않게 하고 다시 채운다. 중간에 보이는 구멍을 최종 상태로 남겨도 된다는 뜻은 아니다.

44:50에는 아직 분리된 발과 다리의 열린 영역이 보이고, 이후 Join과 대응 정점 Merge at Last/스냅·Auto Merge로 연결한다. 사용 후 Auto Merge를 끄는 설명도 나온다. 머리·손·다른 가까운 표면까지 우연히 합쳐지지 않도록 대상 경계를 한정해야 한다. 발목을 굽힌 실제 검증은 이 편에서 확인하지 못했다.

## 6. 국소 관절 보강

47:40–49:40 손마디에서는 일부 가장자리를 Rip하고 새 경계를 Bridge/Fill해 필요한 루프를 넣는다. 48:10 표본의 키 표시가 **V**다. 자동 자막의 B 표기는 그대로 지침에 복사하지 않았다. [Blender5.2 Rip Vertices](https://docs.blender.org/manual/en/5.2/modeling/meshes/editing/vertex/rip_vertices.html)도 V를 설명하며, 이동을 취소해도 분리 자체는 남는다는 점을 명시한다. 겉으로 같은 위치라고 용접된 것으로 간주하지 않는다.

50:00–50:57에는 무릎 앞 국소 패치를, 51:00–52:00에는 팔꿈치 쪽 다른 방향 전환과 중앙 루프를 만든다. 50:45 확대는 무릎 연결 후 면 흐름을 보여 준다. 두 부위가 같은 관절이라는 이유로 같은 모양을 무조건 복제하지 않는다. 강사는 향후 변형을 의도해 배치하지만 실제 리깅·가중치·포즈 비교는 이 편에 없다. [볼륨 보강 강좌](BODY_JOINT_VOLUME.md)의 실제 시연과 구분한다.

52:21 이후 추가하는 지느러미는 이 캐릭터 고유 디자인이다. 루미 몸의 기본 토폴로지 요구로 가져오지 않는다.

## 버전·오류·게임 적용 경계

원본 확대의 하단에서 **Blender3.3.1**을 읽었다. 현행5.2에서 같은 이름·단축키·모디파이어 조건을 공식 문서와 대조했지만 로컬 앱으로 재현하지는 않았다. 새 기능·애드온 설치도 하지 않았다.

| 문제 | 먼저 볼 것 | 다음 단계의 조건 |
|---|---|---|
| 정면은 맞고 몸이 납작함 | 옆/위 기준과 깊이, 상자 모서리 | 세 방향 실루엣이 승인 범위에 맞음 |
| 접합 후 갈라짐·비틀림 | Join/Bridge/용접의 구분, 대응 경계 순서 | 틈·내부 면·중복 면과 법선 문제 없음 |
| 면이 전신으로 과다 증가 | 국소 전환·임시 경계·주변 간격 | 필요한 위치에만 보강되고 원래 윤곽 유지 |
| Rip 후 같은 자리에 겹침 | 이동 취소 후 분리 정점·경계 검사 | 의도한 Bridge/Fill 또는 재용접 확인 |
| 게임용으로 완성됐다고 오해 | 실제 이 편의 종료 범위 확인 | UV·텍스처·리그·엔진·기기 검증을 별도 기록 |

게임 제작의 다음 단계에는 실제 삼각화 후 형태·변형, UV 늘어짐·여백, 베이크 누출, 노멀 규약, 재질 수·텍스처 크기·LOD·뼈 영향 수와 대상 Android 측정이 필요하다. 이 수업의 ‘Game Ready’라는 시리즈 이름만으로 이 항목을 통과 처리하지 않는다.
