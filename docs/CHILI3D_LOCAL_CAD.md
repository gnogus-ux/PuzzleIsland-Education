## 설치 전 확인

[공통 도구 규칙](COMMON_TOOL_POLICY.md)과 [설치 목록](AVAILABLE_TOOLS.md)을 먼저 읽는다. 새 프로그램 설치는 해당 사용자의 명시 승인 범위에서 수행한다. 설치 보류의 예외를 다른 프로그램으로 확대하지 않는다.

Chili3D는 브라우저에서 실행하는 CAD다. .blend 편집기나 Blender 리그·재질을 그대로 옮기는 도구가 아니다. 기본 CAD 작업은 외부 모델 API 키 없이 시작할 수 있다. AI 제공자와 유료 Pro 작업은 별도 범위로 확인한다. 주 소스는 AGPL-3.0, C++ 부분은 LGPL-3.0으로 안내되므로 수정·배포 시 저장소 라이선스를 직접 확인한다.

공식 소스를 독립 폴더에 받고 커밋을 고정한다. 기존 Node와 lockfile을 사용해 `npm ci`, 공식 `npm run dev` 경로를 따른다. 이번 제한 실기는 기존 Node 24.22.0/npm 11.19.1에서 실행했다. 포함된 WASM을 먼저 사용하고 필요하지 않은 C++/Emscripten을 일괄 설치하지 않는다. 설치 중 경고를 임의 전역 업데이트로 해결하지 않는다.

로컬 전용 작업은 loopback 주소와 고정 포트를 사용한다. 포트가 이미 다른 프로그램에 점유됐으면 종료하지 않는다. 제품을 열기 전에 로컬 HTML의 외부 분석 코드를 확인한다. 이번 독립 로컬 설치에서는 기본 Clarity 분석 코드를 제외했다. 외부 커뮤니티 링크까지 모든 네트워크 기능을 차단한 상태라는 뜻은 아니다.

## Blender 제품을 검토 문서로 옮기기

1. 현재 저장 버전·원본 해시·승인 참고자료를 확인하고 독립 사본을 만든다. 다른 담당의 라이브 장면을 읽는 것만으로도 점유가 생길 수 있으므로 진행 중인 장면에 무단 연결하지 않는다.
2. [Blender 제작 절차](BLENDER_SKILLS_WORKFLOW.md)의 사본·평가 메시 읽기/해제·단위·왕복 검증을 적용한다. [애드온 목록](BLENDER_ADDONS.md)을 먼저 확인하되 기본 읽기 기능으로 충분하면 새 애드온을 설치하지 않는다.
3. 기준 좌표계와 단위 변환을 기록한다. Chili3D 길이는 mm, 각도는 도다. Blender 장면 단위 설정·실제 평가 좌표·알려진 제품 치수를 함께 대조한다. 일반적인 m 좌표에는 1000을 곱하지만 파일마다 이를 확인한다.
4. 정확 곡면은 STEP/BREP를 우선한다. STL은 삼각면으로 변환되며 매끈한 CAD 곡면·UV·재질·리그·설계 이력을 되살리지 않는다. 큰 평가 메시 전체를 무조건 B-rep로 바꾸지 말고 검토 목적에 필요한 단면·부품부터 옮긴다.
5. 단면 교선에는 열린 조각·분기·중복·짧은 선이 있을 수 있다. 곡선 단순화를 썼다면 허용 편차와 누락 가능성을 기록한다. 단면 문서를 제조용 재단 패턴이나 완전한 제품 CAD로 표시하지 않는다.
6. 몸판·포켓·내피처럼 층을 별도 이름으로 유지한다. 두 점 거리, 선택한 형상의 길이·면적·체적은 해당 형상에 맞는 측정으로만 사용한다. 선 문서의 체적으로 가죽 부피를 판정하지 않는다. 높이 좌표 범위는 재료 두께와 다르다.
7. 외형을 실제 바꾸려면 [공통 작업 규칙](COMMON_WORK_RULES.md)의 실제 Guide→담당 인계→단독 점유→동일 solid/wire 검수 절차를 별도로 따른다. CAD 검토가 이 절차를 대체하지 않는다.

이번 로컬 선 형상 시험에서는 OCCT `boundingBox()`에 공차 여유가 포함되어 실제 꼭짓점 범위보다 크게 나왔다. 정확한 길이 확인에는 꼭짓점·끝점/커브 측정을 대조한다. 커널 바운딩 박스를 곧바로 제품 실측값으로 쓰지 않는다.

## 저장·재열기와 운영

- 자동 저장이 없다. Ctrl+S는 해당 브라우저 원점의 IndexedDB에 저장하고, 파일 저장은 .cd를 내려받는다. 중요한 시점에는 별도 .cd와 STEP/BREP를 함께 보관한다.
- 이 버전의 .cd는 문서 형식 0.7.1을 엄격히 확인한다. 앱 버전 0.8.0과 혼동하지 않는다. 버전 이동 전 백업하며 자동 마이그레이션을 가정하지 않는다.
- 이름 변경은 새 문서 ID를 만들지 않는다. 최근 프로젝트 삭제는 문서 본체도 삭제한다. 닫기 확인의 취소 역시 저장 없이 닫는 동작이다.
- 문서 저장→페이지 새로 열기→동일 .cd 로드→노드 수·형상·실측값 대조를 실행한다. STEP는 최종 형상 교환용이며 파라메트릭 이력과 문서 설정은 포함하지 않는다.
- 최소 화면 검수는 읽을 수 있는 카메라와 맞춤 보기로 한다. 최소화된 창에서 캡처가 실패하면 같은 작업 공간의 창을 정상 복원한 뒤 viewport 크기와 맞춤 보기를 갱신한다.
- 개발 서버는 해당 폴더의 소스와 의존성을 사용한다. 실행 중 서버·저장 문서·로컬 파일을 구별한다. 공개 코드 저장소에 비공개 제품 파일이 섞이지 않도록 로컬 제외 규칙과 실제 Git 상태를 확인한다.

## 2026-11-04 제한 실기

명시 승인된 독립 로컬 설치에서 의존성 설치, 앱 컴파일/형식 검사, ego-browser의 WASM 초기화·표시, 검토용 선 형상 생성, .cd 저장/재열기 및 STEP 출력을 실행했다. 재열기 후 10개 노드의 CAD 형상 검사를 통과했다. 실제 꼭짓점 범위를 대조했다.

이 결과는 Blender 원본 수정·전체 제품 폐합/충돌·물리 시뮬레이션·제조 공차 검증·AI API 연결·유료 Pro 기능 검증을 포함하지 않는다. STEP 출력 성공과 다른 CAD의 재수입 검증도 구별한다. 현재 실기는 STEP 재수입까지 확인하지 않았다. 개별 제품 자료·개인 경로는 공용 매뉴얼에 게시하지 않는다.
