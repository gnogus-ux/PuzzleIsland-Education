# 도구 확인 공통 규칙

2026-11-01 사용자 지시: 제작하려는 작업에 필요한 프로그램과 매뉴얼을 먼저 확인하고, 없거나 적용 근거가 부족하면 요청한다. 이 규칙은 여러 프로젝트에서 공통 사용한다.

프로젝트 작업 전에 [공통 작업·인계·검수 규칙](COMMON_WORK_RULES.md)도 함께 적용한다. 이 도구 확인 절차가 승인 범위·원본 보존·가이드·정상 점유·검수·비용·단계 인수 조건을 대체하지 않는다.

## 매뉴얼 사전 확인

- 2026-11-03 사용자 추가 지시: **다음 작업을 시작한다고 판단하는 시점마다 항상 관련 매뉴얼을 먼저 검색한다.** 대화 최초 시작뿐 아니라 같은 대화의 다음 작업·제작 단계, 인수 후 작업 시작, 작업 방법·도구·대상 기능이 달라지는 단계에도 적용한다. 사용자가 검색을 다시 지시할 때까지 기다리지 않는다.
- 실제 실행 전에 공용 교육 목록과 매뉴얼 본문을 작업 주제·기능·도구·버전 등의 관련어로 검색하고, 적합한 문서의 필요한 절을 읽어 적용 방법과 제한을 확인한다. 이미 아는 분야이거나 이전 단계에서 다른 매뉴얼을 읽었다는 이유로 새 작업의 검색을 생략하지 않는다. 동일 문서·버전을 직접 읽은 근거는 재사용하되 현재 작업과의 관련성과 최신 변경을 검색 결과로 확인하며, 무관한 전체 자료 반복 열람은 하지 않는다.
- 작업 기록에는 검색한 주제·관련어, 찾은 매뉴얼의 정본 주소와 적용할 핵심 내용, 부족하거나 미확인인 부분을 짧게 남긴다. 관련 매뉴얼을 못 찾은 경우에도 검색 결과 없음과 필요한 내용을 구분해 기록한다. 기존 승인·보류·금지를 유지하며 검색 자체를 이유로 반복 승인 질문을 추가하지 않는다.
- 작업 전에 [공용 교육 목록](../README.md)과 해당 주제의 매뉴얼을 읽는다. 필요한 매뉴얼이 없거나 내용이 부족하거나 버전 차이로 적용 근거가 부족하면 사용자에게 필요한 주제·작업 목적·부족한 내용·추가 학습/작성 필요사항을 요청한다.
- 이미 명시 승인된 강좌 학습·매뉴얼 작성 범위는 중복 질문 없이 수행한다. 매뉴얼이 없다는 이유로 승인받지 않은 새 강좌의 대규모 학습·설치·무근거 제작을 임의 시작하지 않는다. 일반 설치·설정 보류와 앱 조회 금지는 유지하며, 아래 Blender 애드온 상시 승인 범위는 예외다.

## Blender 애드온 사전 확인·활용·설치 상시 승인

2026-11-03 사용자 지시로 다음을 모든 Blender 작업에 적용한다. 이 범위에서는 2026-11-01의 일반 설치·설정 보류보다 아래 지시가 우선한다.

- 작업 전에 [Blender 애드온 목록](BLENDER_ADDONS.md)과 실제 설치·활성화·버전·호환 상태를 확인하고, 필요한 기존 애드온을 먼저 활용한다. 작업에 유용한 기존 애드온을 확인하지 않고 중복 설치나 대체 도구 제작부터 시작하지 않는다.
- 작업에 필요한 애드온이 없거나 필요한 기능을 쓸 수 없으면 **별도 사용자 승인 질문 없이 필요한 애드온의 설치·활성화·필요 의존성 구성·Blender 버전 호환 확인·제한된 기능 확인까지 진행한다.** 필요한 애드온 설치 자체를 이유로 멈추지 않는다.
- 공식 확장 저장소 또는 제작자의 공식 배포처에서 목적·버전·라이선스를 확인한다. 기존 설치·설정·사용자 작업을 보존하고 필요한 범위만 변경한다. 기존 파일과 열린 창을 임의 교체·종료하거나 무관한 애드온을 일괄 설치·업데이트하지 않는다.
- 설치됨, 저장 활성화, 현재 프로세스 로드 성공, 실제 기능 확인을 구분한다. 필요한 기능을 해당 프로젝트의 테스트·씬 변경 제한 안에서 확인하고 작업에 활용한다. 결과·버전·사용 이유·미확인 사항을 기록하고 공용 목록을 갱신한다.
- 이 상시 승인은 새 유료 구매·추가 결제·구독·라이선스 구입·유료 생성 제출을 포함하지 않는다. 사용자 직접 로그인·인증, 관리자 또는 도구가 요구하는 필수 승인은 정상 절차를 지킨다. 이미 보유한 정당한 라이선스의 설치·활용은 중복 승인하지 않는다.
- 다른 프로그램의 설치 보류·조회 금지, 원본 보존·단일 점유·수정 가이드·비용 한도·프로젝트별 제외 범위는 유지한다. 애드온 설치 승인으로 무관한 앱이나 외부 서비스의 조회·재시작·유료 호출을 허용한 것으로 해석하지 않는다.

## 프로그램 사전 확인

1. 제작·분석·자동화 도구를 새로 만들거나 설치하기 전에 [사용 프로그램 목록](AVAILABLE_TOOLS.md)을 읽는다. 필요한 기능을 기존 프로그램·검증된 스크립트·승인된 연결로 수행할 수 있는지 먼저 확인한다.
2. 목록의 ‘최근 실행 근거’, ‘설치만 확인’, ‘미완료/보류’를 구별한다. 파일이 있다는 이유만으로 실행·라이선스·모델 다운로드·외부 API 연결까지 완료됐다고 가정하지 않는다.
3. 필요한 프로그램이 없거나 사용할 수 없으면 프로그램명, 작업 용도, 현재 부족한 점, 설치/계정/비용 필요 여부를 정리해 사용자에게 요청한다. Blender 애드온은 위 상시 승인에 따라 설치하며, 그 밖의 임의 설치·구매·우회·대체 프로그램 제작을 시작하지 않는다.
4. 이미 해당 프로그램 설치·사용을 명시 승인받았으면 같은 승인을 반복 요청하지 않는다. 최신 보류·금지 지시, 사용자 직접 로그인·필수 승인 단계는 유지한다. 일반 프로그램 설치·설정 작업은 재개 지시 전까지 보류이며, 위 Blender 애드온 설치·활성화는 2026-11-03 지시로 상시 승인됐다.
5. 금지된 앱을 목록 확인 명목으로 조회·연결·시작·재시작하지 않는다. 다른 담당의 실행 중 작업과 도구 점유를 보존한다.
6. 새 확인이나 설치·장애가 발생하면 날짜·버전·검증 범위·남은 조건을 이 공용 목록에 갱신한다. 같은 장애를 반복 확인하거나 여러 프로젝트에 목록 사본을 만들지 않는다.
7. 공유 PC의 실제 설치와 다른 PC의 환경을 구별한다. 공개 문서에는 인증정보·개인 절대 경로·비공개 제품 자료를 기록하지 않는다. 정확한 경로와 진단 로그는 담당의 비공개 환경 기록에서 확인한다.
8. 공용 자료실의 단일 작성자·정상 커밋/푸시·manifest/링크/원격 해시 검증 규칙을 따른다.
