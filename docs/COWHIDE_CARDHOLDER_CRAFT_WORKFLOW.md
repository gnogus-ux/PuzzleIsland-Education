## 2. 재단 전 준비와 도면의 구분

**강좌 관찰:** EBS는 큰 앞뒤판 2장과 낮은 포켓판 1장을 전사해 준비한다(2강 00:54~02:34 자막, 01:00·02:30·03:00 화면). 비오공방은 이미 잘리고 펀칭된 부품과 스냅으로 시작한다(00:00·00:45 화면). 키트 조립 성공이 자유 설계 패턴의 검증을 대신하지 않는다.

**적용 절차:** 실제 수납물과 완성 크기를 정하고 다음 정보를 각 부품에 기록한다.

1. 부품 이름·수량·앞뒤·결 방향·겹 순서와 완성 재단선.
2. 봉제할 선, 열린 포켓 입구, 접착할 띠, 접착하면 안 되는 수납 공간.
3. 애벌 재단 여유, 피할 범위·잔여 두께, 접어 마감할 경우의 별도 여유.
4. 보강재의 경계·안감·중앙 굽힘 영역과 같은 단면에 쌓이는 층.
5. 카드 방향·장수·들어가는 깊이·잡고 빼는 노출 길이. 명함은 실제 사용할 규격을 따로 확인한다.

재단선·봉제선·접착 경계·수납물 도달 경계는 서로 다른 정보다. 포켓끼리 투영되어 교차하는 선을 임의의 절단·봉제선으로 만들지 않는다. 수납 깊이를 줄이는 숨은 멈춤선도 제품 근거 없이 추가하지 않는다.

강좌에서 사용하는 준비물은 패턴, 가죽, 표시용 송곳, 재단 매트·칼·자, 사포, 피할용 가죽칼, 접착제, 목타와 받침·망치, 바늘 2개와 실, 고정 집게 또는 포니, 가위와 단면 마감재·천이다. 보강재·안감·스냅은 설계에 따라 추가한다. 넓은 자와 좋은 칼날 상태를 유지하는 요령은 EBS 2강 02:43~04:35 설명에서 확인했다. 칼·목타 작업 때 손과 공구 진행 방향을 겹치지 않게 둔다.

## 3. 애벌 재단·입구 마감·피할

**강좌 관찰:** EBS 2강 04:38~05:53은 접착할 부분을 표시하고 표면을 가볍게 거칠게 만든다. 05:56~06:40은 나중에 접근하기 어려운 포켓 윗단을 먼저 마감한다. 06:44 이후에는 겹쳐 두꺼워질 가장자리를 피할한다. 08:48 화면의 권장 잔여 두께는 해당 예제에서 1~1.2mm이며 자막은 시작 가죽을 약 1.8mm로 설명한다.

**적용 절차:** 완성 패턴과 애벌 패턴을 나누고, 노출되는 입구와 겹 접착부를 표시한 뒤 작업한다. 입구를 덮어 버리기 전에 해당 가죽에 맞는 마감을 한다. 피할은 가장자리의 실체 두께를 줄이는 공정이며 포켓 전체를 같은 두께로 축소하는 것과 다르다. 원피를 전체적으로 얇게 나누는 작업도 별도로 기록한다.

예제 두께를 다른 제품에 복사하지 않는다. `그 단면의 가죽 + 안감·보강재 + 접착·마감`을 합산하고 봉제부의 찢김 저항도 남겨야 한다. 얇은 겹 지갑의 재료 후보와 공급처 허용 오차는 [가죽 두께·내부 보강재](WALLET_LAYERED_SHELL_VOLUME.md#7-가죽-두께와-내부-보강재를-선정하는-근거)를 따른다.

## 4. 보강재와 안감의 설계

**강좌 관찰:** TY LAB 01:34~02:46은 부드러운 몸판의 볼륨을 보강재로 만들고 안감으로 덮는 방식을 설명한다. 01:49 화면에 고발포·인솔 명칭이 있고 01:58 화면에는 스펀지 같은 시편이 보인다. 02:17 화면의 설명 자막은 경계 안쪽 배치를 말하지만 Illustrator 입력창은 조작 중의 다른 수치를 표시한다. 따라서 한 장면의 수치를 보편적인 이격 규격으로 채택하지 않았다. 03:00~04:00에는 겹 포켓 옆선을 경사지게 바꾸는 평면 패턴과 피할 영역 설명이 있다.

**적용 절차:** 형태 지지, 늘어남 억제, 부드러운 볼륨을 서로 다른 요구로 정한다. 보강재가 끝나는 위치와 봉제·피할·굽힘 경계가 충돌하지 않게 단면을 그린다. 보강재를 안쪽에 둔 거리와 부푼 높이는 같은 치수가 아니다. 스펀지 두께만으로 완성 외피의 부풀음 높이가 결정되지 않는다.

포켓의 옆선을 평면에서 줄이는 것과 두께 방향으로 피할하는 것도 다르다. 둘 다 겹 두께를 분산할 수 있지만, 원본의 포켓 수납 폭·깊이·연속된 판을 바꿔서는 안 된다. 사진 복원에서는 실제 근거가 없는 사다리꼴 패턴·보강재·안감을 추가했다면 설계 후보로 표시한다.

## 5. 접착·본재단·봉제 구멍

**강좌 관찰:** EBS 2강 09:16~10:30은 부품을 접착해 정렬한다. 10:35~11:35는 접착 후 다시 재단해 겹의 단차를 줄인다(11:16 화면). 11:39~13:09는 목타 간격·수직 정렬·앞선 마지막 구멍에 다음 첫 이빨을 맞추는 방법을 설명한다(12:55 화면).

**적용 절차:** 수납부를 피한 지정 접착 띠에만 접착하고, 실제 접착제의 도포·건조 조건을 따른다. 정확히 정렬해 붙인 뒤 설계된 본재단 여유 안에서 공통 가장자리를 정리한다. 예제의 접착 띠 폭을 제품의 모든 변에 그대로 복사하지 않는다.

봉제선이 입구를 막지 않는지 먼저 확인한다. 땀 간격은 목타 피치와 코너에서의 분배를 함께 계획한다. 도구를 수직으로 두고 연결 위치를 일정하게 맞추며 앞뒤면 모두 확인한다. 목타 피치가 사진 속 실 길이·폭·구멍 크기와 모두 같은 값이라는 뜻은 아니다.

3D 제품의 실 모양을 표현하기 위해 큰 관통 구멍을 반드시 만들 필요는 없다. 실제 공예의 바늘 통로와 렌더용 표면 표현은 구별하고, 구멍 보존·메움 여부는 해당 제품의 승인 기준을 따른다.

## 6. 새들스티치와 모서리 조립

**강좌 관찰:** EBS 3강 01:16~04:37은 미리 자른 실의 양끝에 바늘을 고정한다. 05:42~07:43은 양쪽 길이를 맞추고 같은 구멍을 두 바늘로 교대로 통과시키는 과정을 시연한다. 먼저 나온 실을 아래로 치우고 반대 바늘을 통과시킨다. 08:13~08:39 자막은 해당 방식의 앞·뒤 스티치 기울기가 다르게 나옴을 설명한다. 09:00~10:20은 실 끝을 뒷면으로 모으는 마무리다.

**적용 절차:** 실 길이 여유를 잡고 양끝에 바늘을 고정해 첫 구멍에서 좌우 길이를 맞춘다. 먼저 통과시킬 면과 실을 치우는 방향을 반복해서 유지한다. 두 번째 바늘이 이미 지나간 실을 갈라 꿰지 않도록 여유 공간을 확인하고 서서히 당긴다. 실이 표면을 잡되 가죽을 과도하게 주름지게 조이지 않는다. 시작·끝의 보강 방법도 같은 제품 안에서 일관되게 정한다.

EBS는 봉제 경로의 약 4~5배, 비오공방은 약 5배를 설명한다. 이는 준비량 예시이며 두께·피치·되돌아박기·조립 방법에 따라 달라진다. EBS와 키트 강좌의 되돌아박기 횟수 및 끝 처리도 같은 지시가 아니다. 열로 끝을 처리하는 장면은 열가소성 실에 관한 예이며 재질이 확인되지 않은 실에 일반화하지 않는다.

비오공방은 09:31 이후 앞판을 뒤로 보내 접는 측면 조립과, 20:16 이후 두 장을 포개는 측면 조립을 따로 설명한다. 10:30~12:55 자막에서는 모서리의 네 겹을 통과하는 구멍과 두 겹만 통과하는 경로를 구별한다. 겹의 순서가 달라지면 모서리 단면과 외형도 바뀐다. 이 키트의 상자 모양 접기를 평평한 겹 지갑에 자동 적용하지 않는다.

실의 입체 표현을 만들 때는 구멍에 들어가는 끝, 표면을 가로지르는 낮은 실 곡선, 꼬임, 앞뒤 기울기, 코너 전환과 국소 눌림을 나눠 관찰한다. 새들스티치 강좌가 특정 사진의 실 재질·굵기·장력·눌림 깊이를 측정해 주지는 않는다.

## 7. 엣지 마감과 수납 검수

**강좌 관찰:** EBS 3강 10:26~11:25는 단면에 마감재를 바르고 마른 천으로 문질러 보풀을 정리한다. 모서리를 눌러 부드럽게 정리하는 설명도 있다. 이 장면을 엣지 페인트의 도포 횟수·건조·연마·내구성 시험까지 학습한 것으로 기록하지 않는다. 비오공방의 마지막 열처리는 실 끝 마무리이며 엣지코트 공정이 아니다.

**적용 절차:** 가죽과 마감재에 맞는 공법을 선택한다. 단면을 문질러 다듬는 공법과 별도 페인트층을 쌓는 공법을 구별한다. 특정 제품에 엣지 페인트가 필요하면 그 제품 제조사의 도포·건조·연마 지침을 추가 확인한다. 기존 [실·엣지 마감 표현](SAMPLER_THREAD_EDGE_FINISH.md)은 표면 표현의 참고이며 실제 마감재의 작업 지침을 대신하지 않는다.

완료 후에는 아래를 검사한다. 이번 학습에서는 실물 검사를 수행하지 않았다.

| 구분 | 확인 항목 |
|---|---|
| 빈 지갑 | 입구 개방, 접착제의 수납부 침범, 겹의 단차, 봉제선과 재단선, 실 끝 |
| 실제 카드·명함 | 계획한 방향·장수로 넣기, 목표 깊이·노출량, 빼기 쉬움, 걸림·팽창·이웃 포켓 간섭 |
| 단면 | 가장 두꺼운 겹, 피할·접착·보강재가 끝나는 곳, 마감 후 전체 두께 |
| 접힘 | 빈 상태와 수납 상태 각각의 닫힘·중간·펼침, 중앙 굽힘과 외피 여유 |

## 8. 사진 복원과 Marvelous Designer에 넘길 정보

아래는 공예 학습에서 도출한 **제작 적용 제안**이다. 강좌에서 MD를 조작하거나 현재 제품을 재현한 결과는 아니다. 앱 단계는 [MD 재단·봉제 절차](MARVELOUS_WALLET_PATTERN_WORKFLOW.md)를 별도로 확인한다.

- 재단 부품 목록에 입구·봉제·접착·피할·보강재·안감의 역할을 기록한다. 사진에 안 보이는 층은 추정 상태를 유지한다.
- 실체 두께, 화면 표시 두께, 충돌 간격을 분리한다. 완성 엣지 총두께와 가죽 한 장 두께를 혼동하지 않는다.
- 포켓 입구를 열어 두고 실제 수납물과 수납 깊이로 검수한다. 슬롯만 다른 삽입 비율을 요구하면 해당 슬롯에만 적용한다.
- 원본의 연속 판·겹 순서·봉제실을 보존하고 변경 범위를 실제 Guide에 표시한다. 학습을 이유로 실·구멍·중앙 접힘을 임의 재설계하지 않는다.
