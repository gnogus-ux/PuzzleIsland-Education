## 1. 한 손가락에서 제어 관계를 만든다

강좌는 세 마디 변형 체인과 그 옆의 긴 제어 뼈를 만든다. 긴 제어 뼈의 회전을 Copy Rotation으로 각 마디에 전달해 한 번에 손가락을 말고, 각 마디는 추가로 조정할 수 있게 한다. IK나 driver를 설치·작성하는 단계는 확인되지 않았다.

후속 실습에서는 `CTRL_...`와 `DEF_...`처럼 역할을 구별할 수 있는 이름을 정하는 것이 좋다. 이는 **이 매뉴얼의 제안 명명법**이며 영상의 실제 이름은 `Bone`, `Bone.001` 등이다. 실제 강사 이름을 확인한 것처럼 바꾸지 않는다.

먼저 한 손가락만 만든 뒤 작은 회전으로 시험한다. 바인딩 전에도 뼈가 제어 뼈를 따라 어떤 공간에서 회전하는지 확인할 수 있다. 완성되지 않은 관계를 다섯 손가락에 복제하면 오류도 함께 늘어난다.

## 2. 대상·로컬 축·공간을 따로 확인한다

약03:30~04:15에는 Copy Rotation의 Target와 Bone 필드를 설정하는 예시와 선택 순서 단축 조작이 나온다. 선택한 모든 뼈에 자동으로 올바른 대상이 들어간다고 가정하지 않는다. 제약을 소유한 뼈와 참조하는 제어 뼈를 각각 읽는다.

약05:00 이후에는 World 회전과 Local 회전의 차이를 확인하고 roll을 정리한다. 부모 체인에서 로컬 회전이 누적되는 방식과 전역 방향을 맞추는 방식은 결과가 다르다. roll이 다르면 같은 로컬 축 이름으로 회전해도 굽힘 방향이 달라질 수 있다.

**화면에서 읽은 설정:** 약07:15에는 Local/Local과 옛 Offset 체크박스가 보인다. 약08~09분에는 축 복사 범위를 조정한다. 주된 굽힘과 옆 벌림을 다르게 다루며 높은 마디가 불필요하게 옆으로 퍼지지 않게 한다. 이 예제의 X/Y/Z를 다른 모델에 바로 대입하지 않는다. 로컬 축은 뼈의 휴지 방향·roll과 함께 확인해야 한다.

## 3. 전체 굽힘과 개별 마디 조절을 보존한다

하나의 컨트롤로 모든 마디를 굽히는 편의성과, 물체 접촉을 위해 끝·중간마디를 개별 조정하는 기능을 구분한다. 모든 마디가 항상 같은 각도로만 꺾이는 상태는 손가락 리그의 최종 목표가 아니다.

구 Offset는 소유 뼈의 추가 회전을 다루기 위해 사용된다. 현재 Blender의 Add와 이름만 바꿔 같은 것으로 간주하지 않는다. 아래 공식 대응에서 설명하듯 회전 결합 순서가 중요하다. 작은 굽힘→추가 마디 회전→벌림 조합을 각각 시험하고 의도한 결과를 선택한다.

위치·스케일 잠금과 회전 채널 잠금은 오조작을 줄이는 설정이다. 이것을 Limit Rotation 제약이나 해부학적 최대각 설정으로 설명하지 않는다. 강좌에서 실제로 만들지 않은 각도 제한·IK·driver·손목 전체 제어 계층을 매뉴얼의 관찰 결과에 추가하지 않는다.

## 4. 커스텀 모양은 표시와 조작을 돕는다

약11~15분에는 반원과 손잡이, 작은 원형 메시를 만들어 뼈의 Custom Shape로 연결한다. 표시가 너무 커지는 문제는 템플릿 메시를 Edit Mode에서 조정하며 다룬다.

이 모양은 피부 메시를 대체하거나 충돌을 계산하지 않는다. 모양을 만들었다고 제약 관계나 가중치가 자동 완성되지 않는다. 현재 공식 문서도 Custom Shape를 뷰포트 표시로 설명하며, 렌더되지 않고 템플릿 오브젝트의 Object 변환은 표시 인스턴스에 그대로 반영되지 않는다고 설명한다. [Blender5.2 Viewport Display](https://docs.blender.org/manual/en/5.2/animation/armatures/bones/properties/display.html)

후속 제작에서는 제어용 표시를 별도 컬렉션에 관리하고 뼈 길이 기준 크기·시인성을 확인한다. 색이나 반원 모양만 보고 실제 변형 뼈인지 제어 뼈인지 판단하지 않는다.

## 5. 다른 손가락과 엄지에 맞춘다

약16~19분에는 체인을 손에 맞추고 복제해 길이·관절 위치를 바꾼다. 복제 후에는 뼈 이름뿐 아니라 Copy Rotation의 Bone 대상이 새 손가락 컨트롤을 가리키는지 확인해야 한다. 원래 손가락을 계속 따라가는 오류를 막기 위한 적용 제안이다.

엄지는 약19분 이후 별도로 방향과 roll을 조정한다. 자동 자막의 숫자는 ‘1.2’처럼 깨져 있고 원해상도 표본도 입력 중간 화면이어서 정확한 완성 각도를 확정하지 않았다. **특정120°를 엄지의 보편 설정으로 쓰지 않는다.** 실제 손 모델에서 굽힘·벌림·손바닥 쪽 접촉이 원하는 방향인지 확인한다.

## 6. 컨트롤을 변형 계산에서 제외하고 바인딩한다

약23분 자동 가중치 이후, 강사는 제어 뼈도 Deform에 참여해 원치 않는 그룹·영향이 생긴 문제를 고친다. 약24:50 원해상도 화면에서 선택한 반원 제어 뼈의 Deform가 꺼진 것을 확인했다. 그 뒤 다시 바인딩한다.

강좌는 예제의 모디파이어와 그룹을 지우고 새로 시작한다. **기존 캐릭터의 모든 vertex group·모디파이어를 지우는 일반 절차로 복사하지 않는다.** 실제 프로젝트에서는 백업·기존 기능 확인 후 문제 그룹과 변형 역할을 식별하고, 필요할 때 별도 후보에서 바인딩한다.

현재 공식 문서에 따르면 With Automatic Weights는 변형 뼈에 대한 bone heat 가중치를 만들며, 가까운 다른 부위의 영향 때문에 수동 수정이 필요할 수 있다. 같은 이름의 기존 그룹 가중치는 덮어쓸 수 있다. 그러므로 기존 보정 데이터를 보존하고 재바인딩의 영향을 먼저 확인한다. [Blender5.2 Armature Deform Parent](https://docs.blender.org/manual/en/5.2/animation/armatures/skinning/parenting.html)

## 7. 가중치를 포즈와 함께 보정한다

약25~35분에는 Weight Paint에서 엄지·손가락의 영향이 손목이나 이웃 손가락으로 번진 부분을 빼고, 실제로 굽혀 보며 반복한다. 약32~34분에는 Edit Mode에서 그룹에 속한 정점을 선택해 잘못된 소속을 제거한다. 이는 **손 메시 정점을 삭제하는 작업이 아니다.**

후속 실습 순서는 다음과 같다.

1. 한 손가락만 조금 굽혀 엉뚱하게 움직이는 영역을 찾는다. 중립 화면의 빨강·파랑만으로 오류를 확정하지 않는다.
2. 해당 변형 뼈의 그룹과 인접 그룹을 확인한다. 표면 뒤쪽이나 손가락 사이의 숨은 정점도 조사한다.
3. 불필요한 영향을 국소적으로 줄이고 필요한 인접 뼈로 부드럽게 이어 준다. 모든 관절을 한 뼈1.0으로 칠하는 방식은 일반 처방이 아니다.
4. 가중치 합·미할당·불필요한 제어 뼈 그룹을 확인한다. 실제 엔진의 영향 수 제한을 적용한다면 정리 전후를 별도 시험한다.
5. 같은 포즈·시점으로 재시험하고 중립으로 돌아온다. 한 손가락을 고치면서 이웃 포즈가 나빠지지 않았는지 확인한다.

마지막에도 강사는 더 손볼 가중치가 남았다고 설명한다. 매끄러운 마지막 중립 화면은 주먹·엄지 접촉·모든 조합의 검수 PASS가 아니다. 위 과정은 우리가 실습한 결과가 아니라 실행 가능한 후속 절차다.

## 현재 Blender 5.2 대응

아래는 공식5.2 문서를 실제 읽어 비교한 내용이다. 현 앱의 클릭·메뉴 재현·파일 저장은 실행하지 않았다.

| 구버전 영상 | 5.2에서 확인한 대응과 주의 |
|---|---|
| Copy Rotation의 Offset 체크 | Mix의 **Offset (Legacy)**가 옛 동작에 해당하며 deprecated이고 여러 축 결합에 한계가 있다. Add/Before Original/After Original의 회전 결합은 서로 다르므로 목적을 정해 시험한다. 옛 Offset=현재 Add라고 단정하지 않음 |
| World/Local 두 공간 필드 | Target/Owner Space를 각각 확인하고 뼈 roll·부모 체인과 함께 해석 |
| bone roll 재계산 Ctrl+N | Edit Mode의 Armature→Bone Roll→Recalculate Roll, **Shift+N**. 선택 기준별 정렬 방향이 다르므로 무조건 한 번 실행해 해결됐다고 하지 않음 |
| 20칸 Armature Layers·Bone Groups | Blender4.0부터 **Bone Collections**로 대체. 역할 구분과 가시성은 현재 컬렉션에서 관리 |
| Custom Shape·Wireframe | Bone→Viewport Display의 Custom Shape/Custom Object와 표시 변환·Scale to Bone Length를 확인 |
| With Automatic Weights | 변형 뼈와 기존 동명 그룹 덮어쓰기·수동 보정 필요성을 확인 |

공식 근거: [Copy Rotation](https://docs.blender.org/manual/en/5.2/animation/constraints/transform/copy_rotation.html), [Bone Roll](https://docs.blender.org/manual/en/5.2/animation/armatures/bones/editing/bone_roll.html), [Bone Collections](https://docs.blender.org/manual/en/5.2/animation/armatures/properties/bone_collections.html), [Custom Shape](https://docs.blender.org/manual/en/5.2/animation/armatures/bones/properties/display.html), [Armature Deform](https://docs.blender.org/manual/en/5.2/animation/armatures/skinning/parenting.html).

## 실패를 구분하는 진단표

| 현상 | 먼저 볼 것 | 원인 확인 전 피할 것 |
|---|---|---|
| 컨트롤을 돌려도 엉뚱한 방향으로 굽음 | Target Bone·Owner/Target Space·roll | 메시 전체 리토폴로지 |
| 두 번째·세 번째 마디가 옆으로 퍼짐 | 축 복사 범위·부모 회전 누적·Mix | 전역 축 이름을 로컬 축으로 간주 |
| 한 손가락 컨트롤이 다른 손가락도 움직임 | 복제 후 제약 대상·가중치 둘 다 | 원인 하나로 미리 단정 |
| 손목이나 반대편 피부가 끌림 | 그룹의 숨은 영향·제어 뼈 Deform | 모든 그룹 삭제 |
| 뼈는 맞게 움직이지만 관절이 납작함 | 가중치 분포·관절 위치·면 간격 | 자동 가중치를 최종 상태로 승인 |
| 화면 컨트롤만 크게 보임 | Custom Shape의 표시 크기·템플릿 | 실제 손 메시 스케일 변경 |

제작 완료 보고에는 저장 파일, 실제로 시험한 포즈, 남은 가중치 문제, 게임 엔진 검증 여부를 포함한다. 지금 문서의 결과는 **학습·설계 정리 완료, 실제 리깅·변형 시험 NOT RUN**이다.
