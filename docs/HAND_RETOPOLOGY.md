## 1. 목표 동작과 스타일에 맞는 구조를 고른다

세 손은 길이·두께·엄지 출발 방향이 다르다. 단순한 손은 간결한 실루엣을, 자연스러운 손은 손바닥의 볼륨 변화를, 두꺼운 손은 큰 덩어리와 별도 제약을 다룬다. 강사가 설명한 기술적 휴지 자세의 제약을 인체 해부학의 고정 규칙으로 해석하지 않는다.

후속 제작에서는 필요한 화면 크기와 동작을 먼저 적는다. 멀리 보이는 손, 손가락 접촉이 강조되는 손, 장갑으로 덮이는 손은 필요한 밀도와 검수가 다를 수 있다. 다만 옷에 가린다는 이유만으로 변형에 필요한 손가락 사이와 엄지 기저부를 무조건 생략하지 않는다.

**판정 방법:** 중립과 주먹을 같은 시점으로 나란히 본다. 면 수가 적어도 목적 동작에서 볼륨과 윤곽을 유지하면 유효한 후보이고, 많은 quad라도 압축부가 찌그러지면 수정이 필요하다.

## 2. 손바닥의 덩어리와 경로를 먼저 본다

약07:45 이후 색으로 구분한 영역은 엄지 밑·새끼 쪽·손가락 아래의 볼륨과 이들을 잇는 면 흐름을 설명한다. 손바닥 중앙은 오목해지고 엄지 쪽과 바깥쪽은 서로 다른 방향으로 말린다. 이 교육용 구분을 고정된 의학적 근육 분할이나 Weight Paint 값으로 바꾸지 않는다.

1. 엄지 기저부를 돌아가는 경로를 추적한다. 손목에서 올라온 선이 엄지를 감싼 뒤 어디로 돌아가는지 확인한다.
2. 새끼 쪽 볼륨과 중앙 손바닥이 한 줄에 압축되는지 본다. 과한 밀도 전환이나 긴 면이 굽힘 중심에 몰리지 않게 한다.
3. 손가락 시작부와 손바닥 사이에서 경로가 끊기거나 나선처럼 불필요하게 돌지 않는지 확인한다.
4. 포즈에서 면을 보고 중립으로 돌아와 기본 실루엣도 확인한다. 포즈 하나를 위해 원래 손의 두께를 무너뜨리지 않는다.

## 3. 관절은 압축되는 쪽과 늘어나는 쪽이 다르다

약11:00~12:15에 관절 밑의 **3스팬에서2스팬으로 줄이는 모티프**를 설명한다. 굽힐 때 안쪽에 면이 뭉치지 않도록 하고 바깥 관절의 둥근 볼륨을 남기는 예제다. 같은 구간의 굽힌 화면에서 안쪽 접힘과 바깥 윤곽을 비교할 수 있다.

이 숫자는 저밀도 예제에서 읽을 수 있는 구조 설명이다. 모든 손가락에 동일한 줄 수를 넣는 처방이 아니다. 밀도가 높은 손, 수동 가중치, 별도 보정 변형을 사용하는 방식도 있을 수 있지만 이 강좌의 예시를 근거로 그런 보정이 자동 생성됐다고 주장하지 않는다.

**실패와 수정 방향:**

| 실패 | 우선 확인 | 수정 제안 |
|---|---|---|
| 관절 안쪽의 면이 겹치며 뾰족해짐 | 압축부 간격·밀도·관절 중심 | 간격과 면 전환을 재배치한 뒤 같은 포즈로 비교 |
| 바깥 관절이 평평해짐 | 지지 면 위치·뼈 중심·가중치 | 형태와 변형 원인을 분리해 고침 |
| 손가락 사이가 늘어난 막처럼 보임 | 벌림 방향의 연결·경계 높이 | 해당 공간의 흐름과 여유를 설계 |
| 손등의 긴 줄이 주먹에서 꺾임 | 손가락에서 손목으로 이어지는 경로 | 주요 변형부에서 갑작스러운 밀도 변화 분산 |
| 엄지 접촉에서 손바닥 전체가 끌림 | 엄지 기저부 경로와 가중치 | 메시를 먼저 탓하지 말고 변형 영향도 대조 |

## 4. 엄지와 손바닥을 잇는 모티프는 하나가 아니다

약14:30~18:30에는 단순 손과 자연 손의 손바닥을 반복해서 돌려 본다. 엄지를 감싸는 단순한 루프, 엄지·새끼 쪽 볼륨을 함께 잇는 8자에 가까운 경로, 두꺼운 손에서 엄지 영역을 돌아 팔로 이어지는 경로를 비교한다. 이는 흐름을 읽기 위한 설명이며 원본 파일의 완전한 연결 인덱스를 추출한 결과가 아니다.

모티프를 고르는 기준은 그 캐릭터가 엄지를 어느 방향까지 보내야 하는지, 손바닥을 얼마나 말아야 하는지, 손목 접속 경계가 어떤지다. 모티프 이름을 먼저 정한 뒤 모델을 억지로 맞추지 않는다. 표면 색만 따라 칠하는 것으로 면 흐름이 만들어지지도 않는다.

강사는 자동 가중치와 같은 리그를 이용한 비교라고 설명한다. 화면에도 Armature·Subdivision 등의 모디파이어가 보인다. 그러나 강사 파일의 모든 그룹·보정 데이터는 직접 검사하지 않았다. **이 예제가 보인다는 이유로 우리 모델의 자동 가중치도 항상 잘 나온다고 보장하지 않는다.**

## 5. 발 예시는 원리의 확장으로만 사용한다

약18:45~20:25에는 발과 발가락을 보여 주며 선의 방향과 밀도 전환을 설명한다. 보이지 않는 부분을 단순화할 수 있다는 취지와 다리로 올라가는 불필요한 나선 흐름을 피하는 설명이 포함된다. 승인 디자인·신발·요구 동작을 확인하지 않은 상태에서 발가락을 합치거나 생략하는 근거가 되지 않는다.

## 실제 리토폴로지 인계 전 체크

- [ ] 요구 포즈와 손가락 노출 범위를 기준으로 모티프를 골랐다.
- [ ] 관절 안쪽/바깥쪽, 엄지 밑, 새끼 쪽, 손가락 사이를 별도 영역으로 진단했다.
- [ ] 변경할 경로와 보존할 실루엣을 실제 Guide에 표시했다.
- [ ] 손목 접속 수·방향·전환부를 기록했다.
- [ ] 중립의 매끈함과 변형 시 품질을 별도로 판정했다.
- [ ] 토폴로지·관절 축·가중치를 구분하고 실패 원인을 추정으로 표시했다.

최종 판단은 [공통 QA 계획](HAND_FINGER_WORKFLOW.md#변형-qa-계획--미실행)을 실제 실행한 뒤 내린다. 현재 교육은 모티프 분석과 계획 작성이며 실제 손 리토폴로지나 변형 검증은 수행하지 않았다.
