# 가죽 엣지코트: 베이스·색 도포·건조·접힘부 검수

2026-11-05 Codex 작성. 제조사 웹 본문3개, 제작자 제작 안내2개와 영상3편을 대조했다. 영상은 **표본 화면70시점과 제공된 영어 자동 자막3개 트랙 전체**를 확인했다. 연속 전음성 시청·실물 도포·현재 제품 변경은 하지 않았다. [출처·실제 학습 범위](../reports/VideoLearning/20261105_EDGE_PAINT_FOLD_STUDY.json)를 함께 읽는다.

## 1. 재료와 공정을 먼저 구분한다

[Giardini의 고품질 엣지 공정](https://www.leatheredgepaint.com/how-to-get-high-quality-leather-edge)은 베이스를 먼저 바르고 건조한 뒤 가볍게 다듬고 색을 올리는 순서를 설명한다. [제품 종류 비교](https://blog.leatheredgepaint.com/choosing-the-perfect-leather-edge-paint-a-comparison-of-dense-basic-and-dull)는 Basic·Dense·DULL에 서로 다른 작업 조건을 제시한다. 예를 들어 DULL의 얇은 엣지에서 베이스를 생략할 수 있다는 설명을 다른 제품·두꺼운 단면에 복제하지 않는다.

학습용 기준 공정은 **Basecoat Dense → 가벼운 연마 → Dense 색 도포**로 정리한다. 다른 브랜드 제품을 무조건 섞는 조합이 아니며, 실제 구매·사용 제품이 정해지면 해당 제품의 최신 기술자료·가죽과의 적합성을 확인한다. 이 문서의 조합은 참고 제품에 사용된 브랜드를 식별한 결과가 아니다.

베지터블 가죽을 문질러 섬유를 정리하는 버니싱과 별도 도막을 쌓는 엣지코트는 구별한다. [MAKESUPPLY의 제작 안내](https://projects.makesupply.co/templates/make-a-leather-bi-fold-wallet-free-pdf-template-build-along-tutorial/)도 가죽 종류에 따라 엣지 마감 조건이 달라짐을 설명한다. 그 문서의 연결 영상은 비공개로 접근되지 않았으므로 영상 학습으로 계산하지 않았다.

자동 자막의 제품명·공구명 오인은 제조사 제목·문서·실제 화면으로 교정했다. Dense가 다른 단어로 전사되거나 adhesion이 잘못 전사된 부분을 그대로 재료 성질로 쓰지 않는다. 제조사 Basecoat Dense 웹 페이지 일부는 색 도료 설명이 중복된 상태였으므로 그 문단만으로 베이스 사양을 확정하지 않았다.

## 3. 단면 정리부터 색 도포까지

아래는 제조사 공정과 실제 시연을 종합한 작업 절차다. 특정 가죽에서 성공을 검증한 수치 처방은 아니다.

1. **층과 입구를 확인한다.** 맞닿는 겹의 단차·접착제 잔여·보풀을 확인한다. 자유롭게 벌어질 포켓 입구와 중앙 틈을 마감재로 가로질러 붙이지 않는다. 포켓 입구는 조립 전에 접근 가능한 순서로 마감한다.
2. **절단면을 정돈한다.** 엇갈린 층을 먼저 정리하고 가죽에 맞는 가벼운 연마로 표면을 다듬는다. 도막을 두껍게 쌓아 큰 절단 단차나 열린 접합부를 숨기지 않는다. 공방 영상의 특정 사포 입도를 모든 가죽에 복제하지 않는다.
3. **베이스를 첫 층으로 도포한다.** 제조사는 Basecoat Dense를 원 가죽 엣지에 먼저 사용하는 제품으로 설명한다. 유분·왁스 등 표면 상태에 따라 접착이 달라질 수 있다. 도움제를 자동 추가하거나 다른 화학제품과 임의 혼합하지 않는다.
4. **건조 후 가볍게 다듬는다.** 제조사 안내의 부직포·브러시·고운 사포 등으로 결점을 줄인다. 젖은 상태를 갈아 표면이 뜯어지지 않게 한다. 베이스가 젖었을 때 희게 보이다 건조 후 반투명해진다는 설명은 관찰 보조이며 이것만으로 내부 건조를 판정하지 않는다.
5. **색 도료를 얇고 일정하게 올린다.** 롤러나 적합한 도구를 일정하게 움직이고 조명 아래에서 흐름·공백·기포·옆면 번짐을 확인한다. Good Old Company 19:37·24:20 시점에서 롤러 적용이 보인다. 빠른 움직임·과도한 양으로 결점을 덮지 않는다.
6. **건조 후 필요한 구간만 재작업한다.** 첫 색 층 이후의 결점·겹 경계가 남으면 적합한 가벼운 연마와 다음 도포를 검토한다. 무조건 동일 횟수로 반복하거나 두껍게 만드는 것을 목표로 하지 않는다. 최종 광택을 바꾸려는 추가 마감재는 제품 호환성을 확인한 경우에만 사용한다.

공방 영상의 물 희석·용기 보관·열처리는 개인 작업법이다. 새 제품의 희석 비율·보존 기한·온도 처방으로 채택하지 않았다. 자막의450°C는 공구의 최대 표시값에 관한 언급이며 실제 엣지 처리 온도 설정값이 아니다. 열처리는 이번 기본 공정의 필수 단계에서 제외한다.

## 4. 건조 시간은 두 단계로 기록한다

[Giardini의 건조 설명](https://blog.leatheredgepaint.com/how-long-a-leather-edge-paint-need-for-drying)은 다음 작업을 진행할 수 있는 시간과 내부 휘발분이 충분히 빠지는 시간을 구별한다. 온도·상대습도·도막 두께의 영향을 받으므로 실제 제품 기술자료를 우선한다.

이2017년 제조사 글에는 상온에서 약30~35분의 예와 수성 제품의 충분한 건조·포장 전 대기에서 최대48시간의 설명이 있다. 이는 현재 모든 제품·환경의 보증 시간이 아니다. Good Old Company는 자신의 공정에서 도포 후 적어도 약1시간을 두는 사례를 설명한다. 서로 다른 예를 평균내거나 상온 대기와 전용 오븐 시간을 섞지 않는다.

작업 기록에는 제품명·도포 순서·온도/습도·도포량·층 사이 대기·포장/굽힘 시험 전 대기를 나눈다. 이번 학습에서 특정 제품의 최신 TDS, 실제 건조·반복 굽힘·박리 시험은 확인하지 않았다.

## 5. 접힘·입구·도막 두께의 검수

- **접힘부:** 굽힘 반경을 따라 도막이 늘거나 눌리는 구간을 따로 본다. 짧은 시연에서 균열이 안 보인다고 반복 사용 내구성 PASS로 쓰지 않는다. 보강판 끝의 급격한 단차와 도막의 탄성은 별도 요인이다.
- **열린 경계:** 포켓 입구·슬롯·두 판 사이의 빈 틈을 코팅막으로 연결하지 않는다. 맞붙여 마감하는 단면과 서로 독립된 입구를 구분한다.
- **두께:** 절단면 바깥으로 자라는 도막 두께와 위아래 어깨를 넘는 돌출은 축이 다르다. 완성 엣지의 측면 전체두께를 계산할 때 축을 맞춰 합산한다. 봉제실 높이·카드 공간을 도막 두께로 오인하지 않는다.
- **외관:** 같은 조명에서 색·반사 폭·라운딩·기포·겹 경계·옆면 번짐을 비교한다. 광택이 강한 추가 코팅을 참고 근거 없이 적용하지 않는다.

3D 적용에서는 큰 단면 라운딩을 실제 형상으로 다루고 도막의 미세한 표면결·광택을 재질로 나눈다. 가죽 엠보싱을 엣지코트에 그대로 복제하지 않는다. [실·엣지 표현 매뉴얼](SAMPLER_THREAD_EDGE_FINISH.md)과 [단면·보강재 선택](WALLET_LAYERED_SHELL_VOLUME.md#7-가죽-두께와-내부-보강재를-선정하는-근거)을 함께 확인한다. 공예 학습과 특정 MD/Blender 제품에서의 실행 성공은 별개다.
