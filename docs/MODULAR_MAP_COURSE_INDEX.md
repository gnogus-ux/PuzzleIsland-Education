## 출처와 권리

공개 재생은 원본 팩·교재·이미지·코드의 재배포 허가가 아니다. Curtis 리소스, LMHPOLY/Synty 팩과 부가도구는 다운로드·구매하지 않았다. Christina의 제공/제휴 고지는 제작자 영상의 맥락이며 이 저장소의 에셋 라이선스가 아니다. 원본 영상·전문자막·캡처·책 페이지를 공개하지 않고 자체 설명·도식과 출처 링크만 제공한다.

## 미확인

현행 Blender/Unity 공식 메뉴·API 웹 재대조는 완료하지 못했다. 원본에서 보이는 버전만 기록했다. 실시간 Blender·Unity·Android 실행, 새 지도/모델/텍스처 제작, FBX 왕복, 실제 배우 이동·NavMesh·복원·성능·독립 QA는 수행하지 않았다.
