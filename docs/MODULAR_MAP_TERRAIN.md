# 지형·절벽·해안과 경계 검사

[전체 순서](MODULAR_MAP_WORKFLOW.md) · [접합 규격](MODULAR_MAP_GRID_KIT.md) · [플레이 검수](MODULAR_MAP_PLAYABILITY_QA.md)

## 원본 지형 계열을 구별한다

[LMHPOLY 강좌](https://www.youtube.com/watch?v=SiEPhqd6rtI)는 기존 팩의 사용 안내다. 화면은 Unity 2019.2.6f1이며 공개 자막은 제공되지 않았다. 화면에 적힌 안내와 조작을 표본 확인했다. 팩 다운로드·라이선스 취득·직접 제작을 수행한 것은 아니다.

| 계열 | 원본에서 본 구조 | 확인한 사용 흐름 | 섞으면 안 되는 가정 |
|---|---|---|---|
| CPT | MeshRenderer·MeshCollider·팔레트 이미지 | 100m 크기 예시, 정점 스냅, 산 오버레이, 색 변경 | Unity Terrain 높이 붓이 바로 적용된다는 가정 |
| MT | 메시 지형·LODGroup, 공유 재질 | LOD0/1/2 시연, 산/지형 재질 교체·타일링 | 모든 물체가 한 draw call이라는 가정 |
| U | Terrain·TerrainData·TerrainCollider | 높이 올리기/내리기·Smooth·TerrainLayer 칠 | CPT UV 팔레트 편집과 같은 자료라는 가정 |

원본 00:30의 Linear 색 공간, MT 13:15의 타일링 5×5, CPT 05:45의 64×64 팔레트는 해당 예제의 설정이다. 현재 프로젝트의 렌더 파이프라인·재질을 검토하지 않고 전역 설정으로 복사하지 않는다. 원본은 Standard 계열 재질을 보여 주므로 URP에서 동일하게 작동한다고 판정하지 않는다.

## 메시 지형 조립 — 원본 확인과 보완

원본 01:00–05:30은 호환되는 경계를 가진 지형을 늘리고 산을 겹쳐 변형한다. 02:15에는 V를 누르고 마우스로 모서리 정점을 끌어 맞추는 안내가 보인다. 접합 규격이 다른 임의의 지형도 자동으로 이어진다는 뜻은 아니다.

적용 제안: 기준 셀의 양쪽 끝 높이·단면을 보존하고 내부 표면에만 변형을 준다. 산·바위 장식은 경계나 플레이 경로를 가리지 않는 곳에 둔다. 정면/사선/낮은 카메라에서 빈틈, 포개진 표면 깜빡임, 법선 차이, 콜라이더 단차를 각각 확인한다. 같은 위치의 삼각형을 겹쳐 놓아 틈을 감추는 방식은 충돌·깊이 문제를 별도로 검사해야 한다.

## Terrain 조각 — 원본 확인과 보완

원본 14:00–19:00은 U 계열에서 높이를 칠하고 TerrainLayer를 만들어 잔디·바위·눈을 배치한다. Shift로 낮추기, Smooth Height와 이웃 조각 배치를 볼 수 있다. 마지막 섬·강·절벽·물은 팩 데모 소개이며 해안/강을 처음부터 모델링한 과정이 아니다. Auto Connect/그룹 설정의 최종 일치 여부는 확인하지 않았으므로 완료 절차로 제시하지 않는다.

적용 제안: 인접 Terrain의 높이 범위·크기·해상도·레이어를 기록하고 이웃 경계의 높이와 재질 전환을 비교한다. 조각 하나를 수정한 뒤 이웃 경계까지 다시 검사한다. 같은 TerrainData를 여러 조각이 공유하는 경우 한쪽 편집이 다른 곳에도 영향을 주는지 먼저 확인한다.

## 섬 탐험용 추가 설계 — 강좌 구현 범위 밖

| 부품/영역 | 결정할 접합 조건 | 실제 시험할 내용 |
|---|---|---|
| 완만한 경사 | 하단/상단 높이·폭·진행 방향 | 오르내림, 진입각, 카메라 가림 |
| 계단 | 디딤 폭·높이와 단순 보행 표면 | 발/충돌의 걸림, 점프 필요 여부 |
| 절벽 직선/코너/끝 | 상부 바닥과 측면·바닥 마감 | 아래쪽에서 보이는 구멍, 통과 금지 경계 |
| 해안 직선/내외 코너 | 육지 단면·수면 높이·모서리 | 물 뒤로 낙하/우회, 수면 겹침 |
| 다리·전이 | 양쪽 접근면·난간·지지 콜라이더 | 끊긴 상태 차단, 복원 후 정확한 연결 |

이 표는 새 지형을 만들었다는 보고가 아니다. 게임의 승인된 지도와 이동 방식에 맞춰 이후 시험할 항목이다. 원본의 설원·일본풍 건물·로우폴리 지형 외형을 승인된 섬 디자인으로 취급하지 않는다.

## LOD와 반복

원본 MT는 09:00–11:00에서 LODGroup을 보여 주고 줌을 바꿔 전환한다. 화면에는 LOD bias 2 경고가 있다. 부드럽다는 제작자 설명과 별개로 모든 인접 쌍·회전·카메라에서 균열이 없다는 정밀 검사는 하지 않았다.

적용 제안: 한 조각은 LOD0, 이웃은 LOD1/2인 상태에서 공통 경계를 확인한다. 충돌이 시각 LOD에 따라 불필요하게 바뀌지 않는지 확인한다. 산과 수풀로 반복을 분산하되 투명 식생의 겹침·그림자 비용은 실제 기기에서 측정한다. [성능 점검](MODULAR_MAP_BLENDER_UNITY.md)으로 이어진다.
