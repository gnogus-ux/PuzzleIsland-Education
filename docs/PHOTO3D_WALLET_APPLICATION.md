# 2부. 예시 지갑에 적용하는 방법

## 예시 치수와 복원 결과의 역할

설명용 예시는 펼친 크기 **160 × 110mm**, 몸판 가죽 **2mm**, 척추 **1mm**다. 영상에서 측정한 수치가 아니며, 실제 제품에는 실측값을 대입한다. 기존 포켓·접힘 구조가 있다면 보존하며 대조한다.

스캔은 외형과 표면을 관찰하는 참고 자료로 둔다. 접힘과 카드 삽입이 필요한 지갑은 외피·내피·포켓·척추의 구조가 살아 있어야 한다. 한 덩어리의 삼각형 스캔을 얻었다고 바로 열리고 닫히는 지갑이 되는 것은 아니다. 이 부의 수치 예시·검수 기준·Blender 적용 순서는 프로젝트에 맞춘 제작안이다.

## 실측 크기로 맞추는 절차

1. 촬영 중 형태가 유지된 두 기준점의 실제 거리를 기록한다. 가능하면 복원 프로그램에서 거리 제약을 지정한다. 각 기준점은 여러 사진에서 정확히 같은 곳을 가리켜야 한다.
2. Blender로 가져온 뒤 장면의 길이 단위와 가져온 메시의 크기를 확인한다. 단위 표시만 바꿔서는 이미 잘못 들어온 크기가 자동으로 교정되지 않는다.
3. 기준 거리의 비율로 전체를 균일하게 확대·축소한다. 예를 들어 실제 100mm인 거리가 가져온 메시에서 80mm라면 배율은 100 ÷ 80 = 1.25다. 먼저 단위를 같게 환산한다.
4. 보정에 쓰지 않은 다른 길이로 검증한다. 펼친 지갑은 같은 자세에서 전체 폭·높이도 확인한다. 구부러진 표면의 길이와 양 끝의 직선거리를 혼동하지 않는다.
5. X·Y·Z를 각각 늘려 160 × 110mm에 강제로 끼워 맞추지 않는다. 독립 치수가 맞지 않으면 원근·변형·오정렬을 조사한다. 배율·축·기준점·검증 오차를 기록한다.

오차율(%) = 100 × |복원 거리 - 실측 거리| ÷ 실측 거리

허용 오차는 사용 목적에 따라 정한다. 제품 치수, 카드 간섭, 봉제 위치를 판단하는 작업에서는 실제 측정이 우선이다. 강좌나 프로그램 이름만으로 밀리미터 이하 정확도를 보장하지 않는다. [공식 거리 보정 원리](https://rshelp.capturingreality.com/en-US/tutorials/scaling.htm).

## Blender 정리와 재모델링

고밀도 스캔 원본을 보관하고 작업용 사본에서 시작한다. 메시를 내보낼 때 OBJ만 전달하고 연결된 MTL·이미지를 빠뜨리지 않는다. 파일을 다시 열어 색과 경로가 유지되는지 확인한다. P2에서 보인 메시 축소와 텍스처 내보내기는 이 흐름을 이해하는 예시다. [P2 메시 축소](https://www.youtube.com/watch?v=r5dJRac02j0&t=1036s), [P2 내보내기](https://www.youtube.com/watch?v=r5dJRac02j0&t=1350s).

1. **방향과 크기:** 앞·뒤·위 방향을 정하고 실측 스케일을 검증한다. 원점·회전·배율을 정리하기 전 기존 리그와 어떤 관계로 배치할지 결정한다.
2. **불필요한 표면 제거:** 배경·받침·떠 있는 조각을 지운다. 얇은 지갑 두 면을 하나로 합치는 넓은 거리의 자동 병합은 피한다. 모든 구멍을 한꺼번에 막기 전에 포켓 입구와 실제 틈을 구분한다.
3. **표면 검수:** 텍스처를 끄고 앞·뒤·옆에서 실루엣, 법선 방향, 두께, 자기 교차를 본다. 매끈한 음영 표시가 잘못된 메시를 고쳐 주지는 않는다.
4. **편집 가능한 구조 제작:** 몸판·척추·내피·포켓을 나누어 기존 모델과 대조한다. 접힘 주변에는 변형 방향을 따라 면을 배치하고 포켓 입구와 봉제 경로를 유지한다.
5. **선택적 형상 대조:** 필요하면 스캔 표면에 가까이 맞추는 도구를 제한된 부위에 사용한다. 앞뒤가 가까운 1~2mm 가죽에서 잘못된 면으로 달라붙지 않는지 확인한다. 스캔 오차까지 그대로 복사하지 않는다.
6. **세부 데이터 이전:** 검증된 고밀도 표면은 정리한 모델에 법선·높이 정보를 굽는 참고로 쓸 수 있다. 베이크 범위가 반대편 가죽을 잡지 않는지 시험한다. 불량 스캔에서 구운 맵도 불량이다.

메시를 줄이는 Decimate 비율이나 최종 삼각형 수를 강좌에서 복사하지 않는다. 지갑의 모서리·1mm 척추·포켓 틈이 유지되고 기존 2K 장면에서 필요한 품질과 속도를 충족하는지로 판단한다. 접힘용 면 배치가 필요하면 단순 축소 대신 다시 면을 구성한다.

## 사진 한 장뿐일 때: fSpy 활용

P5는 사진 속 서로 직교하는 평행선 묶음으로 카메라 원근을 맞추고, Blender에서 면·문·배관 등을 직접 만들어 사진을 투사한다. 건물처럼 긴 직선이 많은 대상에 유리하다. [P5 fSpy 설정](https://www.youtube.com/watch?v=F7PDYoemJvM&t=15s), [P5 Blender 형상 제작](https://www.youtube.com/watch?v=F7PDYoemJvM&t=85s).

지갑용 적용 순서는 다음과 같다.

1. 왜곡이 적은 원본 사진을 고른다. 과도한 광각, 파노라마, 원근 보정된 이미지와 비대칭으로 잘린 사진은 카메라 추정에 불리할 수 있다.
2. 실제로 평행하고 서로 직교하는 방향의 선을 찾는다. 휘어진 가죽 모서리나 곡선 봉제를 건물의 직선처럼 사용하지 않는다. 유효한 선이 없으면 치수 기반 모델을 사진과 수동으로 대조한다.
3. 원점과 축을 정하고 알려진 기준 길이를 지정한다. 사진상 가이드가 다른 위치에서도 자연스럽게 맞는지 확인한다. 기준 길이가 없는 기본값을 실측 크기로 해석하지 않는다.
4. 맞춘 카메라를 Blender로 가져와 기존 지갑의 실루엣·포켓 위치·패턴 배치를 대조한다. 뒷면과 깊이는 다른 사진·실측·구조 자료로 만든다.
5. 사진 투사는 해당 카메라에서의 외관 대조에 사용한다. 옆면이나 뒷면으로 이동했을 때 늘어짐과 가림을 확인한다. 지갑을 여닫는 장면에는 일반 UV와 필요한 면의 실제 이미지 자료를 준비한다.

fSpy는 카메라의 위치·방향·시야각을 추정한다. 단일 사진의 보이지 않는 부분이나 완전한 깊이 정보를 계산하는 도구로 설명하지 않는다. [공식 원리와 입력 조건](https://fspy.io/basics/), [기준 거리와 원점 설명](https://fspy.io/tutorial/).

## 사진 투사, UV와 재질의 차이

강좌의 카메라 기반 노드 방식은 투사 카메라에 의존한다. 카메라와 함께 보관할지, 일반 UV에 고정할지 먼저 정한다. UV Project 방식은 사용할 UV·투사 카메라·이미지 종횡비를 확인하고, 복사본에서 결과를 고정한 뒤 카메라 없이 다시 열어 점검한다. **UV 좌표를 고정하는 것과 그림자·반사광을 제거해 순수한 표면색을 만드는 작업은 별개**다. [P5 투사 고정 과정](https://www.youtube.com/watch?v=F7PDYoemJvM&t=650s).

사진에는 표면색 외에도 빛·그림자·반사가 함께 들어 있다. 사진을 Base Color와 Bump·Roughness에 동시에 연결하면 그럴듯해 보일 수 있지만, 검정 무늬가 움푹 들어가거나 하이라이트가 돌출되는 오류도 생긴다. P1·P5의 이런 연결은 시각적 후처리 예시로만 참고한다.

| 표현할 요소 | 이 지갑에서 사용할 데이터 | 검수할 점 |
| --- | --- | --- |
| 전체 외형·2mm 몸판·1mm 척추 | 실측과 편집 가능한 메시 | 형상·두께·접힘·카드와의 간섭 |
| 포켓·실·봉제 구멍 | 구조 모델과 경로 | 실제 층과 입구가 유지되는지 |
| 가죽색·악어 패턴 배치 | 색 자료와 UV | 조명 얼룩·늘어짐·다른 제품 무늬 혼입 |
| 파란 내피 미세 요철 | 검증한 별도 높이·범프 데이터 | 물리 크기·결 방향·반복 띠·양면 변형 |
| 광택과 거칠기 | 별도 재질 설정과 참고 사진 | 조명 방향을 바꿔도 자연스러운지 |

지갑 전체 사진으로 0.05mm 수준의 요철이 복원됐다고 추정하지 않는다. 그 크기를 말하려면 스케일과 형상 해상도·노이즈를 검증해야 한다. 미세 결은 별도 접사와 기존 표면 맵 매뉴얼로 관리한다.

경계 단차가 줄어도 결 밀도 차이와 복구 띠가 반복되면 완성된 심리스 맵으로 판정하지 않는다. 사진 복원 학습이 기존 높이맵 문제의 해결을 뜻하지는 않는다. [가죽 표면 맵 매뉴얼](https://github.com/gnogus-ux/PuzzleIsland-Education/blob/main/docs/WALLET_SURFACE_MAPS.md)과 연결해 사용한다.

## 제작 전후 체크리스트

- 촬영 전: 같은 실물·같은 자세, 안정된 받침, 확산광, 렌즈·노출 확인, 실측 기준 거리와 독립 검증 거리 기록.
- 촬영 후: 원본 보존, 흐림·반사·형태 변화 제외, 시작과 끝·높이·접사 구간 연결, 누락면 목록 작성.
- 복원 후: 카메라 경로와 분리 묶음 확인, 마스크 확인, 색을 끈 메시 검수, 앞뒤 변형 여부 확인.
- Blender 정리 후: 균일 스케일과 독립 치수 검증, 2mm·1mm 구조 유지, 포켓 틈과 법선·교차 확인.
- 재질 작업 후: 색과 높이의 역할 구분, 결 방향·물리 크기·반복 경계 확인, 옆·뒤 시점의 UV 늘어짐 확인.
- 애니메이션 검수: 열림·중간·닫힘에서 척추, 포켓, 카드 간섭을 확인한다. 좋은 정지 스캔이 좋은 접힘을 보장하지 않는다.
