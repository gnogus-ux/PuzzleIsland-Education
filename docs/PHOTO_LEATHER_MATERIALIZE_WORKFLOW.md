# 사진 한 장에서 가죽 PBR 맵 만들기 · Materialize

2026-11-04. 기존 [가죽 표면 맵](WALLET_SURFACE_MAPS.md)과 [심리스 제작](SEAMLESS_TEXTURE_WORKFLOW.md)을 실제 조작 순서로 연결한 매뉴얼이다. 사진에서 추정한 높이·거칠기를 실측 물성이나 3D 스캔으로 부르지 않는다.

## 근거와 적용 범위

서로 다른 강좌 3편의 실제 화면 43개 시점, 인접 자동 자막과 기존 매뉴얼을 대조했다. [학습 범위·교정 기록](../reports/VideoLearning/20261104_PHOTO_LEATHER_MATERIALIZE_STUDY.json)을 함께 읽는다. 전편 연속 시청·모든 음성 청취와 구분한다.

Materialize 1.78의 기존 설치·정상 작업 UI 기록은 [프로그램 목록](AVAILABLE_TOOLS.md)에 있다. 이번 문서 작성 시점에는 새 사진 로딩·생성·저장을 아직 실행하지 않았다. 강좌의 UI와 실제 설치 UI가 일치하는지 조작할 때 확인한다. Photoshop 강좌의 생성형 채우기·플러그인이 Materialize나 PhotoCraft에 있다고 가정하지 않는다.

## 1. 사진과 표본 보존

1. 사용자가 지정한 원본을 변경하지 않고 별도 작업 폴더에 사본·해시·픽셀 크기를 기록한다.
2. 가죽만 있는 표본을 고른다. 봉제실·바늘구멍·접합 띠·포켓 입구·배경·큰 접힘 그림자는 타일에 넣지 않는다.
3. 표본의 원본 좌표와 크기를 남긴다. 여러 표본을 비교해 방향·초점·원근·광택 포화가 가장 덜한 것을 고른다.
4. 원근 보정이 필요하면 기준점과 변환을 기록하고 결의 폭이 달라지지 않는지 비교한다. 정사각형 출력이 결을 찌그러뜨릴 이유는 없다.
5. 실제 표본 넓이를 모르면 미확인 또는 추정으로 남긴다. 화면 확대율이나 DPI를 가죽의 mm 크기로 사용하지 않는다.
6. 8비트 JPEG를 16비트 작업 이미지로 바꿔도 원래 높이 정보나 세부 결이 늘어나지 않는다. 작은 표본을 4K로 확대했다고 4K 원본이라고 부르지 않는다.

## 2. 색·조명·높이 분리

사진의 밝기는 색소, 표면 기울기, 조명과 광택이 섞인 값이다. 흰 점을 모두 봉우리, 어두운 색을 모두 골로 해석하지 않는다.

- 넓은 조명·비네팅은 조절 가능한 보정으로 줄이고 가죽결은 남긴다.
- Base Color에는 사진 속 반짝임과 접촉 그림자가 고정되어 남지 않는지 본다. 사진 한 장으로 완전히 제거되지 않으면 한계로 기록한다.
- 높이 입력은 상대 능선과 골의 연결이 읽히도록 정리한다. High Pass는 큰 명암을 줄이는 보조 수단이다. 이중 윤곽이나 능선 주위의 밝고 어두운 고리가 생기면 반경·대비를 줄인다.
- 회색·회갈색 재색칠용 색 타일과 높이 입력을 따로 둘 수 있다. 원본 표본·방향·좌표 관계는 같아야 한다.
- 사진 한 장의 자동 Roughness를 물성 정답으로 취급하지 않는다. 골과 능선의 반사 차이를 약하게 시작해 실제 빛에서 검수한다.

## 3. 반복 표본 먼저 정리

[심리스 검수](SEAMLESS_TEXTURE_QA.md)를 적용한다.

1. 넓은 명암을 보정한 사본에서 가로·세로 Wrap Offset으로 바깥 경계를 내부로 옮긴다.
2. 사선 결은 서로 맞는 능선을 이어 짧게 복구한다. Mirror로 끝을 맞추면 대칭 꺾임이 생길 수 있다.
3. 긴 십자선을 한 번에 흐리거나 넓은 패치를 반복해 결이 없는 띠를 만들지 않는다.
4. 다른 Offset으로 다시 확인하고 3×3 이상 축소 반복에서 사각 얼룩·십자 띠·밀도 변화·특이 흠집의 반복을 찾는다.
5. 높이·노멀 생성 뒤에도 같은 검수를 반복한다. 색 타일의 합격을 모든 파생 맵의 합격으로 확대하지 않는다.

강좌 S1의 생성형 채우기는 연결이 그럴듯해도 주변보다 해상도가 낮아질 수 있었다. 이 원리만 채택하며 신규 유료 생성·플러그인 설치를 자동 승인한 것으로 해석하지 않는다.

## 4. Materialize에서 입력 열기

기존 미저장 작업부터 확인하고 보존한다. 기존 작업을 Clear All로 지우거나 다른 사진으로 교체하지 않는다. 새 시험용 문서를 사용할 수 있는 상태를 확보한다.

1. Diffuse Map 열의 O(Open)를 선택해 준비한 가죽 표본을 연다.
2. 썸네일과 Preview에서 파일·방향·비율이 맞는지 확인한다.
3. 필요 시 Diffuse Edit의 지원 기능을 확인해 색·명암 보정을 한다. 원본과 편집된 Diffuse를 구분한다.
4. Height 입력이 Original Diffuse인지 Edited Diffuse인지 기록한다. 조명 보정을 한 결과가 실제 높이 입력에 사용되는지 확인한다.

입력·값·버전은 화면으로 확인하고 저장된 파일로 다시 검증한다. 메뉴가 보이지 않으면 비슷한 이름을 추측해 실행하지 않는다.

## 5. Height 만들기와 확정

1. Height Map > Create를 연다.
2. Height From Diffuse의 입력과 분할 미리보기를 확인한다.
3. Frequency Weight Equalizer와 Frequency Contrast Equalizer를 조절한다. Details·Displace 같은 프리셋은 비교 시작점이며 가죽용 고정 정답이 아니다.
4. 넓은 덩어리 명암보다 원래 엠보싱 능선이 읽히도록 한다. 큰 그림자가 산처럼 솟으면 입력 조명 보정 또는 낮은 주파수 비중부터 재검토한다.
5. Final Gain·Final Contrast·Final Bias는 능선·골이 클리핑되지 않도록 조절한다. 강좌의 바닥·도끼 수치를 가죽에 복사하지 않는다.
6. Set as Height Map을 눌러 확정하고 썸네일이 생성됐는지 확인한다. 미리보기만 보고 다음 단계로 넘어가지 않는다.
7. 생성된 Height는 상대 높이다. 무변위 중립값과 실제 mm 범위는 사용할 재질·변위 설정에서 별도로 정한다.

세부 노멀용 높이와 실제 변위용 높이를 다르게 만들 수 있다. 두 버전의 이름과 변경 관계를 기록하고, 높이를 다시 바꾸면 노멀 재생성 여부를 명확히 한다.

## 6. Normal 만들기

1. Height 확정 뒤 Normal Map > Create를 연다.
2. Normal From Height의 Pre Contrast·주파수·Final Contrast를 약하게 시작한다.
3. 작은 가죽결을 살리되 모래알·금속처럼 뾰족한 반짝임이나 이중 능선을 만들지 않는다.
4. Set as Normal Map으로 확정한다.
5. OpenGL/DirectX 또는 Flip Normal Y 상태를 기록한다. Blender의 OpenGL 입력에 맞추며 이미 뒤집은 녹색 채널을 다시 뒤집지 않는다.
6. 실제 출력에서 RGB 노멀인지, 평탄 구간이 대체로 중립 방향인지, 경계에 날카로운 선이 없는지 확인한다.

## 7. Smoothness·Roughness·AO·금속

| 출력 | 사용 방법 |
|---|---|
| Smoothness | Smoothness Map > Create, 입력·Base Smoothness·High Pass·Final Contrast/Bias를 확인하고 Set as Smoothness |
| Roughness | Smoothness와 반대 의미다. 일반적인 변환은 Roughness = 1 − Smoothness. 파일 변환 또는 소비 노드에서 한 번만 반전 |
| AO | 필요할 때 Normal + Depth to AO에서 약하게 생성. 골을 검게 칠하는 색맵 대용으로 쓰지 않음 |
| Metallic | 가죽은 비금속 0. 밝은 광택을 만들기 위해 금속 마스크를 추가하지 않음 |
| Edge | 꼭 필요한 별도 효과용일 때만 생성. 기본 가죽 PBR 필수 맵이 아님 |

D5 자동 자막은 Smoothness·Roughness·Glossiness를 같은 이름처럼 묶는다. 실제 10:58 화면의 Invert → Roughness 연결로 교정한다. Smoothness를 그대로 Roughness에 넣지 않는다. 도끼의 금속/목재 분류 예제도 가죽에 적용하지 않는다.

## 8. 미리보기와 출력

Show Full Material에서 평면·구·원통 등 제공 형태를 확인한다. Parallax Displacement는 화면상 깊이 표현이며 실제 Blender 정점 변위 성공의 근거가 아니다. Normal과 Height를 동시에 너무 강하게 주지 않는다.

1. Saving Options에서 무손실 포맷을 선택한다. 해당 빌드의 PNG/TIFF가 몇 비트인지 저장 후 확인한다.
2. Save Project로 새 이름을 사용한다. 프로젝트 파일과 생성된 각 맵을 함께 보존한다.
3. 개별 저장과 Quick Save의 실제 경로·덮어쓰기 동작을 확인한다. 원본 사진을 덮어쓰지 않는다.
4. 새로 저장한 프로젝트를 다시 열어 같은 맵·방향·설정이 남는지 확인한다.
5. 출력 이름, 해상도, 채널, 실제 비트 깊이, 해시와 높이 범위를 기록한다. 8비트 출력을 16비트 컨테이너로 바꿨다고 고정밀 생성으로 보고하지 않는다.

권장 인계 구성은 source/crop, 편집본, BaseColor, Height, NormalGL, Roughness, 선택 AO, Materialize 프로젝트, 설정 기록과 검수 이미지다. 상수 금속값은 재질에서 0으로 둘 수 있다.

## 9. 맵 검수와 재질 시험

- 원본 표본과 같은 크기의 결과를 나란히 보고 결 방향·폭·능선 위치를 확인한다.
- 단일 타일·두 가지 Offset·3×3 축소 반복을 색/높이/노멀에서 본다.
- 경계 픽셀 차이와 내부 차이의 비율은 보조 수치다. 끝 행/열을 복사해 숫자만 0으로 만들지 않는다.
- 좌·우에서 비추는 고정 조명과 중립 색으로 높이 반전·사진 하이라이트 고정·반사 과장을 확인한다.
- 실제 변위를 시험할 때는 별도 시험용 평면과 충분한 세분화를 사용하고 변위 OFF/ON의 평가 좌표 차이를 확인한다. 지갑 원본을 자동 교체하지 않는다.
- 물리 표본 크기가 미확인일 때 결의 mm 치수를 정확하다고 주장하지 않는다. 시험 크기와 추정임을 명시한다.
- 내부 반복 띠·구역별 결 크기 변화·좁은 클리핑·노멀 이음선이 남으면 PARTIAL 후보로 보존한다.

Blender 적용은 [표면 맵 연결](WALLET_SURFACE_MAPS.md#6-blender-연결은-데이터-용도별로-만든다)과 현행 버전의 재질·변위 문서를 다시 확인한다. 강좌의 예전 Blender UI, 1704W 예시 광원, 자동 노드 연결을 현재 제품의 기준값으로 복사하지 않는다.

## 완료 기록

사진 표본, 조명·심리스 보정, Height 확정, Normal 생성, Smoothness→Roughness, 프로젝트/맵 저장과 재열기, 반복 검수, 실제 재질 시험을 각각 기록한다. 문서 학습 완료, 파일 생성, 최종 외관 승인과 제품에 적용한 상태는 서로 다르다.
