# 상품 영상용 가죽 · 부품별 고유 텍스처 세트

2026-11-04. 상품 접사·영상용 재질에서 같은 작은 표본이 한 면에 반복되는 문제를 다룬다. 이미지 해상도, 표현하는 실제 가죽 면적, 메시 표본 간격을 따로 검수한다. [기존 사진 맵](SAMPLER_PHOTO_PBR.md), [UV 인계](UV_TEXTURE_SETS_HANDOFF.md), [텍셀 밀도](UV_TEXEL_DENSITY_PACKING.md), [표면 변위](WALLET_SURFACE_MAPS.md)를 함께 따른다.

## 목표와 원본

- 부품마다 4096×4096 색·거칠기·노멀·높이 세트를 구성할 때 부품·UV·재질·파일 이름을 명시한다. 기존 공유 아틀라스를 부품별 세트라고 보고하지 않는다.
- 이미지 픽셀만 늘려도 같은 작은 표본을 UV에서 여러 번 읽으면 반복은 남는다. 원본이 덮는 실제 넓이와 대상 면의 넓이를 확인한다.
- 넓은 사진이 없으면 참조 기반 재구성 영역을 명시한다. 재구성한 결과를 원본의 숨겨진 픽셀·실측 스캔으로 부르지 않는다. 결의 물리 크기는 유지하고 독특한 흠이나 패치를 주기적으로 복제하지 않는다.
- 기존 UV·재질·원본을 보존하고 새 UV와 후보 세트를 별도로 만든다. 실제 가이드·담당 인계와 단일 점유 규칙을 따른다.

## Sampler 해상도

1. 넓은 원본을 별도 SSA에 불러오고 기존 표본을 덮어쓰지 않는다. 비정사각 원본은 결과와 사용 UV의 종횡비가 서로 대응하는지 확인한다.
2. 레이어 해상도는 Document와 아래 레이어 입력을 따를 수 있다. 실제 스택에 표시된 처리 크기와 최종 출력 크기를 읽는다. 출력 창의 숫자만으로 내부 처리도 같은 해상도라고 추정하지 않는다.
3. Upscale은 아래 PBR 채널을 AI로 2배 또는 4배 확대한다. Adobe는 아래 레이어를 Layer Input Max/Min으로 두는 방법을 권한다. AI가 추정한 세부는 관측된 원본 세부와 구분한다.
4. 공식 Upscale 본문의 예시에는 `4098` 표기가 있으나 4K 표준 출력 수치의 근거로 채택하지 않는다. 실제 PNG 헤더에서 4096×4096인지 검사한다.
5. 여러 번 확대하거나 높은 해상도를 쓸 때 계산·메모리 비용을 확인한다. 게임용 예산으로 상품 접사 품질을 임의 제한하지 않으며, 무제한 세분화나 물성 정확도를 주장하지 않는다.

## 부품별 UV로 옮기는 베이크

1. 가이드에 부품 목록·기존 UV 보존·새 목적 UV·이미지 해상도·실제 표본 넓이·허용 겹침을 표시한다. 고유한 전후면이 필요한지, 숨은 띠가 같은 표본을 공유해도 되는지 기록한다.
2. 원본 재질을 읽는 UV와 출력 세트를 쓰는 목적 UV를 분리한다. 두 UV 이름을 명시하고 픽셀 간격·방향·체커를 대조한다. 이미지 전체를 부품 전체에 무조건 늘이면 부품마다 결 크기가 달라질 수 있다.
3. Cycles 이미지 베이크는 활성 Image Texture 노드의 이미지를 대상으로 삼는다. 임시 베이크 재질과 대상 이미지를 별도로 만들고 원래 재질을 보존한다. 여러 재질 슬롯이 있으면 대상 노드 누락으로 빈 영역이 생기지 않는지 본다.
4. 색·높이 같은 원시 채널을 옮길 때 Emit 경로를 사용할 수 있다. 조명·반사를 원치 않는 데이터 맵에 구워 넣지 않는다. Roughness 전용 패스는 소비 셰이더의 출력 거칠기를 굽는다는 차이를 기록한다.
5. 접선 노멀은 목적 UV의 접선 기준으로 베이크한다. RGB 이미지를 단순 재투영한 결과가 다른 접선 기준에서도 맞는다고 가정하지 않는다. OpenGL 규약, 미러·회전된 섬과 실제 변형 상태를 확인한다.
6. 실제 변위를 별도로 유지한다면 노멀 베이크에 그 변위가 중복 포함되는지 확인한다. 임시 proxy/출력 상태·복원을 기록하고 생산 메시를 Apply로 굳히지 않는다.
7. Margin은 섬 경계를 확장하는 별도 출력 단계다. Extend와 Adjacent Faces의 의미를 구별하고 실제 목적 UV 간격을 넘는 padding 충돌을 확인한다.
8. 출력 후 이미지 재열기·비트 깊이·해시·파일 경로, 부품별 올바른 연결을 검사한다. 실제 변위는 새 높이 범위에 맞춰 재보정하고 보호 경계와 평가 정점 차이를 다시 측정한다.

## 상품 접사 검수

같은 카메라·조명에서 원래 재질과 새 후보를 비교한다. 한 면 전체에서 반복 표식을 찾고, 100% 접사에서 결의 선명도·쌍대 윤곽·모래 노이즈·갈고리 같은 흠을 확인한다. 좌우 빛에서 고정된 사진 반사와 실제 셰이딩을 구별한다. 프레임 전체·사선·카드 입구·봉제·외곽 보호와 Solid/wire를 확인한다. 4K 맵이 생겨도 거친 변위 격자는 세밀해지지 않으므로 실제 메시 간격과 노멀의 역할을 함께 기록한다.

## 2026-11-05 제한된 실기와 수정 교훈

Sampler6.0.2의 별도 재구성 원본에서 Leather/Shiny·Equalize·Upscale4×를 사용했다. 스택에서8192×4096 처리 크기를 읽고 최종4096² PNG를 실제 출력했다. 색·금속·거칠기8비트, 높이·노멀16비트였다. 물리 표본180×120mm는 가정이며 실측 스캔이 아니다. 빠른 작업이 만든 기존 AI 레이어가 사용 불가로 표시되어, 현재 사용 가능한 Image to Material AI 레이어를 별도로 추가한 경로를 실제 사용했다.

Blender5.2.2의 임시 Cycles 프록시에서8개 부품별 색·거칠기·높이·접선 노멀, 총32개4096² 맵을 실제 베이크했다. 색은 sRGB8비트, 데이터 채널은16비트 PNG다. 소스 DirectX 노멀은 Native Normal Map Convention으로 해석하고 목적 UV 기준 OpenGL 노멀을 베이크했다. 원본의 모든 UV·원시 기하·보호 가중치는 보존했다. 노멀 베이크에는 실제 변위를 넣지 않았다.

첫 후보는 기존 공유 아틀라스의 부품별 최외곽 UV 박스만 정규화했다. 큰 면의 밀도가 약8–9px/mm에 머물러4K 파일이 생겨도 접사 효율이 나빴다. 이 후보는 보존하고 최종 후보로 채택하지 않았다. 별도 실제 가이드에서 Native Average Islands Scale 뒤 기존 UniV4.0.0의 Native AABB/EXEC·회전OFF·32px 간격으로 부품별 패킹을 다시 했다. 주요 큰 부품의 평균 밀도는 약23–37px/mm가 됐다. 가죽의 원본 물리 범위와 source UV는 유지하고 새 destination UV로32개 맵을 다시 베이크했다. 섬의 AABB 경계0–1과 최소 간격, 다른 섬과의 AABB 무겹침을 검사했다. 이는 섬 내부의 모든 자기 접힘에 대한 증명과 다르다.

데이터 출력은 중립 배경과8px 확장을 사용했다. 첫 후보의 극소수 검은 빈 픽셀은 별도 원본을 보존하고 데이터 중립값으로 보정했다. 재패킹한 두 번째 후보는 검은 빈 데이터 픽셀 없이 재열기·높이 범위 검사를 통과했다. 첫 시험의16비트 raw 높이 저장/재열기 오차는 약7.69e-6이었다. 검은 padding을 포함한 최솟값으로 변위 강도를 다시 정하지 않는다.

최종 후보는32파일 헤더·비트 깊이·해시·재열기와8부품의 실제 평가 정점 off/on 변위를 확인했다. 실제 변위는±0.04mm 이내, 보호 표본14,624개의 이동은0이었다. 같은 카메라·조명에서 정면·사선·슬롯 접사·매크로 Cycles256과 Solid/evaluated-wire 전후를 실제 열람했다. 별도 blend 저장 후 같은 파일을 실제 다시 열어 원본 보존·부품 재질·UV 연결을 재확인했다.

이 실기는 부품별4K 구성의 동작 확인이다. 재구성·업스케일 원본의 부드러운 부분, 일부 부품의 거친 변위 격자, 실물과 다른 촬영 조건은 남는다. 상품 영상의 최종 외관 승인·전체 동작·시간에 따른 반짝임·완성 영상 출력은 검증하지 않았다. 기존 재질의 노드 배치를 보존했으며 Frame 소속11개 확인과 실제 Node Editor의 모든 표시 경계 검증을 구별한다. 상세 기록은 [Sampler 실기 보고](../reports/ToolInventory/20261104_SAMPLER_RUNTIME.json)에 있다. 비공개 제품 이미지·경로·원본 파일은 게시하지 않는다.
