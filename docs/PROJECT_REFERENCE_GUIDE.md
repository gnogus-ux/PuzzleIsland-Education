# 프로젝트 참고자료 준비

이 공개 공유본에는 교육용 자체 문서와 도식만 포함한다. 특정 게임의 승인 캐릭터 원본·팔레트·모델·텍스처는 포함하지 않는다.

작업할 때마다 [참고 자료 상시 확인 규칙](COMMON_WORK_RULES.md#작업별-참고-자료-상시-확인)을 적용한다. 현재 작업의 첨부·지정·승인 자료를 직접 열어 출처·버전·적용 범위를 확인하고 필요한 기준을 기록한다. 같은 대화의 다음 단계·인수 후 작업과 결과 검수에도 적용하며, 결과를 실제 참고와 대조한다. 요약이나 기억만으로 확인을 대신하지 않는다.

실제 제작을 시작하기 전 사용자가 승인한 정면·측면 자료와 색상 기준을 받아 확인한다. 이름이나 교육 문서만으로 캐릭터 외모를 추정하지 않는다.
프로젝트마다 게임 엔진·대상 기기·폴리곤 예산·텍스처 규격·애니메이션 요구를 별도로 정한다. 예제 모델과 숫자는 보편적인 제작 규칙이 아니다.
원본을 보존하고, 수정 범위와 보존 경계를 정한 뒤 가이드·별도 후보·검수를 순서대로 진행한다.
학습 기록의 프로젝트 예시는 교육 당시 상태이며, 공개 저장소가 실제 게임 에셋이나 승인 디자인을 제공한다는 뜻은 아니다.
