# Sampler에서 사진으로 PBR 맵 만들기

2026-11-04. 설치된 Sampler 6.0.2 한국어 시작 화면을 직접 확인했다. 아래 절차는 Adobe 공식 문서 4개의 해당 본문을 읽고 교차 확인한 작업 기준이다. 문서 학습과 사진 처리·저장·출력의 실기 성공은 구별한다. [학습 기록](../reports/VideoLearning/20261104_SAMPLER_DOCUMENT_STUDY.json).

## 준비와 적용 범위

- 원본 사진과 열린 작업을 보존하고 별도 시험 프로젝트를 만든다. 원본·재구성 이미지·자동 추정 맵의 출처를 구별한다.
- 가죽 표본에는 봉제실·포켓 윤곽·큰 접힘 그림자가 없어야 한다. 실제 표본 크기가 없으면 mm 크기와 높이는 미확정이다.
- [기존 사진 맵 검수](PHOTO_LEATHER_MATERIALIZE_WORKFLOW.md)의 표본·타일·요철 방향 기준을 함께 적용한다. Materialize 버튼을 Sampler 버튼으로 간주하지 않는다.
- 새 결제·유료 생성·인증 대행·다른 앱 전송은 이 절차에 포함하지 않는다. 계정 화면이나 비용 안내가 나타나면 자동으로 진행하지 않는다.

## 1. 입력과 표본 분리

1. 시작 화면의 이미지→재질 빠른 작업 또는 새 프로젝트에서 입력 이미지를 지정한다. 이미 만들어 둔 맵을 불러오는 Texture Import와 구별한다.
2. 봉제·주름이 포함된 원본은 먼저 Crop으로 깨끗한 표면을 분리한다. 이미지 입력 다음, 재질 변환 이전에 적용해 경계가 높이로 생성되지 않게 한다.
3. Crop은 선택 영역 밖을 제외하는 변환이므로 일반 Transform과 크기 조작의 의미가 반대다. Layer Inputs 표시와 실제 입력 픽셀을 보고 영역을 확인한다. 원본 표본 좌표·해상도를 남긴다.
4. 작은 표본을 확대해도 관측된 세부가 늘어나지 않는다. 재구성 타일을 사용하면 원본 사진의 직접 추출로 보고하지 않는다.

## 2. 재질 변환

1. Image to Material의 AI Powered를 확인한다. 이는 색에 고정된 그림자·광택을 줄이고 높이·노멀·거칠기를 추정한다. B2M은 별도 절차형 알고리즘이다.
2. 처리 완료 후 레이어와 각 채널을 확인한다. 미리보기 표시만으로 출력 파일 생성까지 완료됐다고 하지 않는다.
3. 넓은 사진 조명이 Base Color나 Height에 남는지 본다. 그림자와 색소를 모두 깊은 골로 취급하지 않는다. 포화된 반사는 한 장으로 정확히 복원할 수 없다.
4. 높은 해상도에서 오래 걸리면 레이어 해상도를 확인한다. 무한 재시도·임의 모델 재설치를 하지 않는다.

## 3. 저장과 출력

1. 별도 프로젝트로 저장하고 경로·파일 생성·재열기를 확인한다.
2. Export 창에서 PNG 등 채널별 이미지 형식을 고르고 전용 출력 폴더·이름·출력 해상도를 확인한다. 적용할 채널 목록을 실제 화면에서 읽는다.
3. Height와 Normal은 지원 형식에서 16비트 출력 대상이다. 실제 PNG 헤더도 검사한다. 16비트 파일이 실측 높이 정밀도를 보증하지 않는다.
4. OpenPBR와 ASM 선택에 따라 채널 의미·파일명이 달라진다. 이름만 바꿔 거칠기·색·금속을 잘못 연결하지 않는다. 실측 크기는 출력 창에서 확정하지 않는다.
5. 생성 파일의 크기·비트 수·해시·채널 대응을 기록하고 Height·Normal·색의 픽셀 정렬을 확인한다.

## 4. 검수와 다음 단계

- 원본 표본과 결과를 직접 대조한다. 사선 교차 결의 방향·간격, 능선과 골, 고정된 반사 얼룩을 본다.
- Height 흰색/검정의 돌출 방향과 노멀 규약을 별도로 확인한다. 높이를 뒤집는 작업과 노멀 녹색 채널 규약 변경은 같은 작업이 아니다.
- 중립 재질·고정 조명에서 좌우 광원과 사선 확대를 확인한다. Sampler 미리보기의 볼록함을 제품 메시 실제 변위로 보고하지 않는다.
- 심리스 여부는 별도 검사한다. 크롭과 Image to Material만 실행했다고 타일 이음이 해결된 것으로 처리하지 않는다.
- 지갑 등 제품에 적용할 때는 제품 승인 범위·가이드·단일 점유와 실제 변위 단위 검증을 별도로 따른다.

## 반복 재질과 노멀 규약 보강 · 2026-11-04

같은 날짜에 아래 서로 다른 Adobe 공식 문서 3개 본문을 추가로 읽고 교차 확인했다. 문서 학습이며 새 필터 실기는 실행 기록으로 따로 구분한다.

| 원출처 | 실제 확인 범위 |
|---|---|
| [Make it Tile](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/filters/tools/make-it-tile) | 수정일 2026-04-07, 추출 본문 9–56행. 다중 패치·문턱값·접합 평활·높이 일치와 패치 위치 |
| [Tiling](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/filters/tools/tiling) | 수정일 2026-04-07, 10–76행. 겹침 변환·채널별 엣지 검출·경계 표시·남은 접합 결함 |
| [Normal Format](https://experienceleague.adobe.com/en/docs/substance-3d-sampler/using/interface/preferences/normal-format) | 수정일 2026-04-07, 4–24행. 내부 DirectX 처리, 기본값과 수입·비트맵 출력 규약 |

1. 별도 후보 SSA로 저장한 뒤 최종 재질 위에 Make it Tile을 적용한다. 색·높이·노멀·거칠기에 같은 패치 배치를 사용하고 각 채널을 따로 육안 검사한다.
2. 문턱값과 패치 위치는 결의 방향·밀도를 유지하도록 조정한다. 과한 대비 감소나 흐림으로 접합만 숨기지 않는다. 높이 일치 옵션은 높이만 바꾸므로 그 변화가 노멀에도 자동 반영된다고 가정하지 않는다.
3. 패치가 뭉치거나 교차 결이 끊기면 원래 후보를 보존하고 Tiling의 겹침·엣지 경로를 비교한다. 다른 방식의 성공은 실제 반복 화면으로 판정한다.
4. 100% 단일 타일·다른 Offset·3×3 축소 반복·반대쪽 빛에서 검사한다. 숫자 접합 개선만으로 내부 띠나 반복 얼룩을 통과시키지 않는다. [반복 검수 기준](SEAMLESS_TEXTURE_QA.md)을 따른다.
5. Normal Format은 환경설정의 실제 현재 값을 읽고 기록한다. 기본 DirectX라는 문서 설명만으로 현재 사용자 설정을 단정하지 않는다. 공유 설정을 바꾸면 기존 값과 복원 여부를 남긴다.
6. Blender용 OpenGL 출력과 높이 돌출 방향을 별도로 검수한다. 녹색 규약 변경이 높이 반전 수정이라고 보고하지 않는다. 원본 높이·노멀을 보존하고 렌더러에서 좌우 빛과 회색 대조로 확인한다.
7. 실제 크기가 없는 사진 표본은 mm 크기를 가정으로 명시한다. 0.04mm 목표는 이미지 숫자만이 아니라 실제 평가 메시의 변위를 측정해 검수한다.

교차 확인: Make it Tile과 Tiling은 별도 알고리즘이다. 전자는 높이 일치 조정이 노멀까지 바뀌지 않는다는 제한이 있어 각 출력 채널을 재검수한다. DirectX/OpenGL은 노멀 해석 규약이고 요철의 봉우리·골 및 실측 높이는 다른 문제다.

### 반복 필터·Blender 시험 평면 실기

2026-11-04 별도 SSA에 Make It Tile을 추가했다. 관찰한 기본값은 Threshold 0.86, Smoothness 0.2, Contrast 0.97, Color Equalizer 20, Height Matching Minimum이다. 이 값들을 모든 가죽에 적용하는 권장값으로 일반화하지 않는다. 3×3 색·높이 반복과 다른 Offset의 네 채널에서 이전의 선명한 가로·세로 경계가 줄었으나, 패치 사이 결 밀도 차이와 미세 결의 부드러움은 남았다. 외곽 지표의 개선을 심리스 품질 백분율로 해석하지 않았다.

출력 직전 실제 환경설정 DirectX를 읽고 OpenGL로 바꿔 Normal을 출력했으며, 출력 후 DirectX로 복원했다. 이번 필터를 거친 출력은 색·금속 8비트, 높이·노멀·거칠기 16비트다. 이전 필터 없는 거칠기 8비트 출력과 구분한다.

Blender 5.2.2의 별도 32mm 시험 평면에서 새 사진 맵의 색·거칠기·OpenGL 노멀과 실제 Displace를 연결했다. 타일 32mm와 16mm는 가정이며 실측값이 아니다. 16mm 시험은 32mm 평면에 2×2 반복, 실제 평가 Z −0.039999999~+0.039999999mm, Cycles 128 samples 좌우 광원 확대 렌더를 직접 확인했다. IOR 1.46, Specular IOR Level 0.6, Coat 0.02, Normal strength 1은 이 시험 조건이며 자동 정답이 아니다. 반사 위치가 조명에 따라 바뀌고 사선 교차 결이 보이지만 작은 원본에 따른 흐림·울렁이는 결 일부가 남아 완전한 실물 복원으로 보고하지 않는다.

블렌드 Save As 때 상대 경로를 먼저 바꾸면 이전 디렉터리로 재매핑될 수 있었다. 새 파일 위치를 확정한 뒤 이미지 경로를 다시 읽고, 새 폴더 기준 상대 경로·재로드·누락 의존성 0을 검사했다. 렌더 호출 응답이 끊겨도 출력이 늦게 생길 수 있어, 작업 상태와 파일 존재를 먼저 확인하고 같은 렌더를 중복 실행하지 않았다. 제품 적용 여부와 제품 메시 실제 변위는 이 평면 시험과 별도로 기록한다.

## 사진 생성·저장 실기 기록

2026-11-04 실제 한국어 UI에서 원본 사진 입력, Crop 핸들로 봉제선 없는 표본 분리, 그 위에 새 Image to Material AI Powered를 추가해 Leather/Shiny 변환, 별도 SSA 저장, OpenPBR PNG 5채널 출력을 실행했다. 원본 전체를 변환했던 예비 레이어는 시험 프로젝트에 보존했다. 최종 출력 이미지를 별도로 열어 봉제선이 빠진 표본인지 확인했다.

출력은 모두 2048×2048이며 Height/Normal 헤더는 16비트, 색/거칠기/금속은 8비트였다. 작은 원본 표본의 확대 출력이므로 새 실측 세부를 얻었다고 주장하지 않는다. 실기 중 레이어 텍스트 드래그가 이동되지 않아 그 방법을 성공 처리하지 않았고, 아이콘으로 레이어를 선택한 뒤 Crop 위에 새 변환 필터를 추가했다. 화면 밖 채널 버튼의 접근성 인덱스는 좌표 오인 가능성이 있어 사용하지 않고 실제 내보낸 파일을 검사했다.

저장 파일 열기 명령 후 재질 표시도 확인했으나 앱을 종료한 완전 재기동 검증과 구별한다. 미세 결 일부가 부드러워졌으며, 심리스·요철 방향의 제품 실기·mm 변위·제품 적용·모든 조명 조건은 아직 미검증이다. [제한 실기 기록](../reports/ToolInventory/20261104_SAMPLER_RUNTIME.json).
