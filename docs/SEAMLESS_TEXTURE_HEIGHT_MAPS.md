# 가죽 높이 맵 · 범프와 디스플레이스먼트 적용 매뉴얼

[다섯 강좌와 심리스 제작](SEAMLESS_TEXTURE_WORKFLOW.md) · [반복 검수](SEAMLESS_TEXTURE_QA.md)

이 문서는 강좌의 사진 패턴 제작 원리를 **가죽 높이 데이터 작업으로 확장한 제안**이다. 강좌 5편이 실제 가죽의 높이를 스캔하거나 이 절차를 Blender에서 검증했다는 뜻은 아니다. 이번 학습 작업에서는 새 재질·메시·렌더를 제작하지 않았다.

## 색, 높이, 노멀을 구분한다

| 데이터 | 담는 의미 | 주의점 |
|---|---|---|
| Base Color | 재질의 색 | 사진에 찍힌 광택과 그림자를 그대로 포함하면 조명에 고정된 얼룩이 생김 |
| Height | 표면의 상대적인 높이 | 사진 밝기는 색·반사·그림자도 포함하므로 측정 높이가 아님 |
| Normal | 표면 방향 | 보라색 노멀 맵을 흑백 높이 입력에 바로 사용하지 않음 |
| Roughness | 반사의 퍼짐 | 밝은 높이값이 반드시 매끈함을 뜻하지 않음 |

어두운 파랑은 움푹하고 밝은 파랑은 볼록하다는 해석은 **출발 가설**이다. 실제로 밝은 부분은 능선 옆의 반사일 수 있다. 가죽 결의 형태와 서로 다른 방향의 빛을 비교해 봉우리·골의 위치를 정한다. 단일 사진만 있으면 이 불확실성을 기록한다.

## 사진에서 높이 맵을 만드는 순서

1. 깨끗한 가죽 표본을 확보하고 심리스 접합과 넓은 명암을 정리한다. 원본·작업용 사본·출력본을 구분한다.
2. 가능하면 초기 작업부터 16비트 문서로 진행한다. 이미 손실된 8비트 정보가 16비트 전환으로 복원되지는 않지만 후속 보정의 계단 현상은 줄일 수 있다.
3. 흑백 변환 후 큰 조명 얼룩과 미세한 결을 분리해 관찰한다. High Pass 같은 필터는 조명 변화 일부를 줄이는 도구이며 실제 높이 복원기는 아니다. 반경을 너무 작게 하면 이중 테두리, 너무 크게 하면 넓은 얼룩이 남는다.
4. 조절 가능한 레이어·마스크로 상대 높이를 정리한다. 예리한 반사점과 업스케일이 만든 가짜 선을 그대로 봉우리로 삼지 않는다. 능선의 연결과 골의 연속성을 확대해 본다.
5. 바늘 같은 점이나 계단 현상이 있다면 최소한으로 정리한다. 전체 무늬를 흐리게 만들어 접합을 숨기지 않는다. Levels를 끝까지 밀어 검정·흰색을 넓게 잘라내면 평평한 단과 절벽이 생길 수 있다.
6. 높이 0의 기준으로 사용할 중간값과 범위를 기록한다. 기준을 0.5로 정했다면 그것이 무변위가 되도록 소비하는 쪽도 맞춘다. 사진의 평균 밝기와 모델의 기준면이 자동으로 같은 것은 아니다.
7. **높이 변환 후 다시** Offset·반복·저장 파일 검수를 한다. 필터가 이미지 테두리에서 계산되는 방식 때문에 기존 색 타일의 연결성이 달라질 수 있다.
8. 무손실 높이 이미지와 편집본을 함께 보관한다. 16비트 PNG/TIFF 또는 목적에 맞는 고정밀 형식을 실제 비트 깊이까지 확인한다. JPEG는 높이 데이터 보존용으로 피한다.

수치 예제의 목적은 원리를 설명하는 것이다. 어떤 사진에서 쓴 High Pass·Blur 반경, Levels 값, 변위 강도를 다른 가죽에 그대로 고정하지 않는다. **같은 픽셀 수라도 표본의 실제 넓이가 다르면 결 크기가 달라진다.**

## Blender에서 단계적으로 확인

다음은 적용 절차 제안이다. 입력 이름은 실제 버전과 노드 종류에서 확인한다. 높이·노멀·거칠기 같은 데이터는 색 보정 대상이 되지 않도록 읽고, Base Color와 분리한다.

### A. 먼저 범프

같은 UV/매핑으로 Height 이미지 → Bump의 Height → 표면 셰이더의 Normal을 연결한다. 처음에는 약하게 시작해 결의 방향·크기와 봉우리/골의 뒤집힘을 확인한다. 범프는 음영을 바꾸며 메시의 외곽 실루엣을 실제로 바꾸지 않는다. 이미지의 Cubic 보간은 계단 현상 완화에 도움이 될 수 있으나 전체 반복 검수를 대신하지 않는다. [Blender 5.2 범프·변위 설명](https://docs.blender.org/manual/en/5.2/render/materials/components/displacement.html), [Image Texture 설명](https://docs.blender.org/manual/en/5.2/render/shader_nodes/textures/image.html)

### B. 실제 형상이 필요한 부분에 변위

적절한 세분화가 있는 메시와 변위 경로를 사용한다. 셰이더 방식이면 높이 → Displacement → Material Output의 Displacement와 렌더·재질 설정을 함께 확인한다. Displace modifier 방식이면 사용할 이미지 텍스처·UV·방향·Midlevel·Strength·적용 정점 범위를 따로 지정한다. 서로 다른 두 방식을 중복 적용하지 않는다.

Displace modifier의 원리는 `변위 = (텍스처 값 − Midlevel) × Strength`다. Midlevel 아래는 음의 방향, 위는 양의 방향으로 이동한다. Strength 수치만으로 월드 공간의 최대 높이를 단정하지 않는다. 실제 이미지 값 범위와 오브젝트/부모의 변환을 고려해 평가된 정점의 이동량을 확인한다. [Blender 5.2 Displace modifier](https://docs.blender.org/manual/en/5.2/modeling/modifiers/deform/displace.html)

큰 요철을 실제 변위, 작은 결을 범프로 나누는 방법은 가능하다. 같은 결을 강한 변위와 강한 범프로 이중 강조하지 않는다. 충분히 조밀한 실제 변위가 이미 작은 결까지 표현한다면 추가 범프의 비용과 효과를 비교한다. 변위에 필요한 세분화와 메모리 비용도 함께 평가한다. [Blender의 방식별 비교](https://docs.blender.org/manual/en/5.2/render/materials/components/displacement.html)

### C. 평면부터 검수한 뒤 실제 모델

- 같은 색·거칠기·카메라에서 범프/변위 강도 0을 대조군으로 만든다.
- 왼쪽과 오른쪽에서 비추는 빛을 바꿔, 결의 음영이 조명에 반응하는지 본다. 사진의 하이라이트가 고정된 색처럼 남으면 높이와 색 분리가 필요하다.
- 평면을 실제 반복 크기로 확인하고, 필요하면 곡면에서도 검사한다. 실루엣 변화와 정점 이동은 실제 변위 경로에서 별도 확인한다.
- 실제 모델에서는 봉제선·슬롯·얇은 가장자리와 뒷면이 부풀지 않는지 확인한다. 색/높이/노멀의 UV와 회전·타일 크기는 일치시킨다.
- 모바일 게임은 엔진의 실제 재질·화면 크기·성능에서 다시 검증한다. Blender 미리보기를 Unity/Android 적용 완료로 표시하지 않는다.

## PhotoCraft에서 작성할 때

Photoshop 강좌의 메뉴 이름을 참고하되 PhotoCraft의 실제 지원을 확인한다. 이미지 제목의 `RGB/16` 표시와 저장된 PNG/TIFF의 비트 깊이를 모두 확인한다. 패턴 미리보기는 겉보기 검사이고, PSD 저장은 편집 가능성 확보이며, 이미지 내보내기는 Blender에 전달할 데이터 생성이다. 세 단계를 같은 완료 조건으로 취급하지 않는다.
