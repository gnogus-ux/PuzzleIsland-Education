# 심리스 텍스처 검수 · 이음선과 반복감 분리

[제작 순서](SEAMLESS_TEXTURE_WORKFLOW.md) · [가죽 높이 맵과 Blender](SEAMLESS_TEXTURE_HEIGHT_MAPS.md)

**경계 수치가 좋아졌어도 반복 띠가 눈에 보이면 완료가 아니다.** 원본 크기, 축소 반복 화면, 실제 재질의 세 조건을 확인한다. 다음 항목은 강좌들의 검수 원리를 작업 체크로 정리한 것이며 특정 엔진의 공식 합격 규격은 아니다.

## 1. 검사 화면

| 화면 | 찾는 결함 | 검사 방법 |
|---|---|---|
| 단일 타일 100% | 흐린 패치, 이중 윤곽, 끊긴 능선, 점 노이즈 | 복구 전후를 같은 배율로 비교 |
| 다른 위치로 Offset한 단일 타일 | 원래 테두리, 생성·합성 결과의 새 이음선 | 가로·세로를 각각 옮겨 내부에서 관찰 |
| 3×3 이상 축소 반복 | 밝기 체스판, 십자 띠, 독특한 흠집, 밀도 차이 | 원래 타일 위치를 몰라도 경계가 읽히는지 확인 |
| 실제 표시 크기 | 결의 크기·촘촘함, 모아레, 과한 대비 | 최종 카메라와 목표 해상도로 확인 |
| 방향을 바꾼 조명 | 고정된 사진 반사, 높이 반전, 과한 변위 | 고정 재질에 좌우 빛을 번갈아 비교 |

반복 화면을 볼 때 타일 경계 표시선을 잠시 숨겨 본다. 표시선이 없는데도 일정 간격의 사각형을 지목할 수 있다면 저주파 명암·색·결 밀도가 남아 있을 수 있다. 반대로 확대해서 연결선이 보이지 않는다는 것만으로 반복감까지 통과한 것은 아니다.

## 2. 원인별 수정

| 증상 | 가능한 원인 | 다음 조치 |
|---|---|---|
| 얇고 선명한 세로/가로선 | 외곽이 이어지지 않음, 테두리 재손상 | Wrap Offset으로 옮겨 결을 다시 연결 |
| 십자 또는 흐린 띠 | 복구 브러시·블러를 길고 일정하게 적용 | 정상 결을 짧게 재구성하고 넓은 흐림 제거 |
| 경계는 자연스럽지만 사각 얼룩 | 조명·비네팅·색·높이 평균 차이 | 반복 화면에서 마스크 명암 보정 |
| 일정 간격으로 눈에 띄는 흠집 | 독특한 표식이 타일마다 반복 | 일부 표식을 제거하거나 표본 영역 확대 |
| 엠보싱이 구역마다 굵어짐 | 원근·촬영 거리·업스케일·복구 표본 차이 | 원근과 표본 선택을 재검토, 원본 결과 비교 |
| 높이 맵에 절벽이나 평평한 반점 | 강한 Levels 클리핑, 반사점 오해석 | 범위를 완만하게 하고 실제 능선 위치 재확인 |
| 흑백에서 맞지만 노멀에 선이 생김 | 높이 기울기의 불연속, 변환 필터의 경계 처리 | 주기 경계와 변환 결과를 함께 재검사 |
| 가죽이 부풀고 슬롯이 무너짐 | 실제 크기/Strength/적용 범위/세분화 문제 | 중립 대조군, 실제 변위와 경계 마스크 확인 |

가죽의 결이 대각선이면 서로 맞는 능선을 이어야 한다. 좌우·상하 반전으로 끝 픽셀을 맞추면 결이 접히는 대칭무늬가 생길 수 있다. 숫자를 맞추기 위해 Mirror로 바꾸는 것을 일반적인 해결책으로 쓰지 않는다.

## 3. 픽셀 검사는 보조 근거

높이 이미지 `H[y,x]`에서 좌우·상하 접합의 평균 차이를 다음처럼 계산할 수 있다.

```text
접합 X = mean(abs(H[:, 0] - H[:, -1]))
접합 Y = mean(abs(H[0, :] - H[-1, :]))
내부 X = mean(abs(H[:, 1:] - H[:, :-1]))
내부 Y = mean(abs(H[1:, :] - H[:-1, :]))
비교 X = 접합 X / 내부 X
비교 Y = 접합 Y / 내부 Y
```

원본과 수정본은 같은 값 범위·색 해석·해상도에서 비교한다. 내부 차이가 0인 상수 이미지에서는 나눗셈을 하지 않는다. 평균 외에 큰 오차가 몰린 구간과 모서리 교차부도 확인한다. 평균이 낮으면 작은 구간의 심한 결함이 가려질 수 있다.

이 비율에 보편적인 합격값은 없다. 대비를 낮추거나 전체를 평평하게 만들면 숫자가 좋아져도 재질은 망가질 수 있다. 특히 높이 맵은 값의 연결뿐 아니라 경계 양쪽의 **기울기**도 중요하다. 정상적인 주기 샘플에서 첫 열과 마지막 열은 한 픽셀 간격의 이웃이므로 반드시 똑같은 값일 필요는 없다. 끝 행/열을 강제로 복사해 같게 만드는 것만으로 해결하지 않는다.

반복 얼룩과 내부 복구 띠는 접합 지표만으로 판정할 수 없다. 숫자 개선율을 “심리스 완성도”나 “품질 상승률”로 부르지 않는다.

## 4. 출력 인수 체크

1. 원본 이미지·편집본·출력 이미지의 경로와 버전을 구분한다.
2. 저장된 파일을 다시 열어 실제 가로·세로, 채널, 비트 깊이, 값 범위와 불필요한 알파를 확인한다.
3. 색/높이/노멀/거칠기의 용도와 파일 이름을 일치시킨다. 높이와 노멀을 혼용하지 않는다.
4. 실제 사용한 UV·방향·표본의 물리 크기와 반복 횟수를 기록한다. 화면 확대율을 물리 크기로 기록하지 않는다.
5. 원본 크기, 다른 Offset, 축소 반복, 최종 재질에서 확인한 결과와 남은 결함을 기록한다.
6. 내부 띠나 반복 얼룩이 남으면 `PARTIAL`로 저장하고 기존 승인 재질을 대체하지 않는다.

## 5. 로컬 영상 분석 도구를 쓸 때

FrameLens는 장면 변화·대표 프레임·움직임을 찾는 보조 도구다. 화면 녹화에서는 창 이동·확대·선택 표시도 장면 변화로 잡힐 수 있다. 검출된 컷 수를 편집 단계 수나 학습 완료량으로 해석하지 않는다.

Qwen3-VL 같은 시각 모델의 메뉴·레이어·값 판독은 원본 프레임과 대조한다. 여러 이미지의 시간 순서를 뒤섞거나 배율을 스케일로 오독할 수 있다. 모델의 `uncertain=false`는 검증 증거가 아니다. 잘못 읽은 값은 매뉴얼에 채택하지 않는다.

자동 자막에는 용어·고유명·숫자·단축키 오류가 있다. 예를 들어 Content-Aware Fill, Generative Fill, Offset과 Mirror를 문맥과 실제 UI로 구분한다. 자막만으로 출력 완료나 저장된 파일의 품질을 확정하지 않는다. 시연용 mock 결과를 실제 영상 분석으로 쓰지 않는다.
