# Solid Edge 도면·판금 전개 제한 검증

2026-11-10. 설치된 Solid Edge를 도면·합성 판금 검산에 사용하기 위한 사전 확인 절차다. **현재 실행 시 라이선스 오류로 편집 화면에 진입하지 못했다. 도면·판금 생성, 저장·재열기·전개·교환은 미실행이다.** 가죽의 재단 정확도와 완성품 제조 품질도 미검증이다. [실제 학습 범위](../reports/ExternalLearning/20261110_SOLID_EDGE_SHEET_METAL_STUDY.json)를 함께 읽는다.

## 설치와 사용 가능 범위를 분리한다

실행 파일226.00.01.004, Siemens 유효 서명, COM 등록과 로컬 타입 라이브러리를 확인했다. 기존 실행 중 객체는 연결되지 않았고 대상 앱 창도 없었다. 정상 실행 시도에서는 유효 라이선스가 없다는 오류가 표시되어 문서 편집에 진입하지 못했다. 라이선스 설정·인증·서버 변경은 하지 않았다. 오류 확인 후 창0을 확인했고, 일시적인 창 없는 프로세스 상태를 거쳐 후속 최소 조회에서 소유 PID 부재로 종료를 확인했다. 종료코드는 미수집이며 강제 종료나 재기동은 하지 않았다. 설치·서명·기동 시도가 사용권이나 기능 성공을 뜻하지 않는다.

현지 공식 SDK 안내는2026 SDK/SESDK.chm을 Siemens Support에서 별도로 받도록 설명한다. 이번에는 인증·다운로드·설치를 하지 않았다. 포함된 interop 메타데이터에서 관련 속성·메서드 존재만 확인했으며 실제 COM 문서 호출 성공을 주장하지 않는다.

## 두께·경로·중립계수의 정의

| 값 | 뜻과 확인 조건 |
|---|---|
| T_stack | 특정 단면의 가죽·안감·보강재·접착·마감 총두께. 카드/빈 공간 포함 여부와 피할·압축을 별도로 기록한다. |
| t | 합성 판금 모델의 단일 균일 판두께. T_stack을 자동 대입하지 않는다. |
| d | 비교할 안팎 두 경로의 반경 차. 완성 엣지 두께나 외피 솟음과 동일하다고 가정하지 않는다. |
| Ri | 단일 판의 내측 굽힘 반경. 외측반경과 구별한다. |
| θ | 실제 굽힘 회전각, 라디안. UI의 포함각·sweep·bend angle 표기와 대조한다. |
| K 또는 NF | 내측면에서 중립경로까지의 위치를 판두께로 나눈 계수. 실제 로컬/전역/표의 적용값을 확인한다. |
| A/B | 원호 접선점에서 끝점까지 직선부 길이. 외곽 완성 치수·가상 교점까지 길이와 섞지 않는다. |

ST5 표준식은 굽힘 구간 길이 `PZL=π(Ri+NF·t)·angle_deg/180=θ(Ri+Kt)`를 설명한다. 단순 한 굽힘 쿠폰에서 A/B를 위처럼 정의한 자체 검산은 `L_flat=A+B+PZL`다. 전체 외곽 치수에 같은 식을 무조건 더하지 않는다. 사용자식·gage 표·relief·flange 치수 정의가 다르면 별도 대조한다.

개별 NF를 설정해도 UseGlobalNeutralFactor가 참이면 로컬값은 무시된다. 2025 KB는 gage table이 굽힘별 NF를 적용할 수 있고, 속성 주석에는 전역값이 표시될 수 있다고 설명한다. 따라서 실제 굽힘값을 확인하는 절차로 Inspect →3D Measure →Inquire Element →Bends only를 제시한다. 현재226에서 이 절차의 실기는 미실행이다.

## 가죽 재단식으로 확정하지 않는다

[겹 구조 매뉴얼 §8](WALLET_LAYERED_SHELL_VOLUME.md#8-중앙-굽힘보강판-끝안팎-길이를-따로-검토한다)의 `ΔL=θd`는 동심 원호 설명용 검산이다. θ=π, 실제 정의된 d=2mm일 때 차이는6.283185mm다. 이를 T_stack=2mm인 가죽 겉장 여유로 바로 확정할 근거는 없다.

아래는 제시된 후보식을 그대로 계산한 **산술 비교**다. 안전 여유나 실제 제품 사양이 아니다. 54/85.6도 이 비교의 인용 입력값이며 여기서 카드 규격 표준·공차를 새로 검증한 값이 아니다.

| 가정 T(mm) | πT | 1.5T~2T | 높이54+T+1 | 폭85.6+2s+2T+2, s=3~4 |
|---:|---:|---:|---:|---:|
|1.0|3.141593|1.5~2.0|56|95.6~97.6|
|1.2|3.769911|1.8~2.4|56.2|96~98|
|2.0|6.283185|3~4|57|97.6~99.6|

따라서 T=2의 πT와3~4mm는 서로 다른 결과다. 같은 T=2에서 폭식과96~98mm 권장값도 일치하지 않는다. T=1.2일 때의 산술 일치가 실제 재료두께를 입증하지 않는다. 카드 수납 깊이·노출량·계단 간격·재단 높이는 따로 정의한다.

이번 공식 자료에서 NF0.33~0.35가 가죽에 가장 정확한 값이라는 근거는 확보하지 못했다. 판금 기능 설명은 가죽의 압축·신장·결 방향·함수율·접착·마찰·봉제·카드 적재·피할 거동의 보증이 아니다. [가죽 제작 매뉴얼](COWHIDE_CARDHOLDER_CRAFT_WORKFLOW.md)의 실제 시편·수납·접힘 검수와 구별한다. 프로그램에 활용하더라도 근거·조건과 함께 편집 가능한 시험 가정으로 보관한다.

## 별도 합성 쿠폰과 완료 조건

정당한 라이선스 사용 가능 상태와 정상 단일 점유가 확인된 다음 진행할 **준비 절차**다. 원본 도면을 수정하지 않고 먼저 별도 Guide에 대상·단위·치수 정의·보존 경계를 남긴다.

1. **2D DFT:** 새100×60mm 사각형, 중심(50,30)mm의 R5mm 원. 실제 치수 표시→새 native 파일 저장→닫기→재열기 후 좌표·크기 확인.
2. **한 굽힘 PSM:** θ90°, Ri2mm, t1mm, W20mm, 접선 기준 A40/B30mm. 처음 NF0.33, 비교0.35/0.50은 각 별도 후보로 저장한다. 다른 형상 값은 유지한다.
3. **전개 검산:**90° 기초 쿠폰의 기대 길이는 각각73.659955441/73.691371368/73.926990817mm다. 0.33→0.35 변화의 기대차0.031415927mm를 확인한다. 이어 **별도180° 쿠폰**을 준비한다. A/B40/30mm, Ri2mm, t1mm, W20mm, NF 세 값은 유지하며 `70+π(2+NF)`의 기대 길이는77.319910883/77.382742736/77.853981634mm다. 이때0.33→0.35 기대차는0.062831853mm다. 원출처의 각도 포함 수식에서 자체 파생한 합성 검산이며 실기 결과가 아니다. 180°가 실제 회전각인지(포함각0°와의 구별), 평행한 양쪽 판의 간섭·접촉 여부와 해당 기능 지원을 먼저 확인하고90° 파일을 덮어쓰지 않는 별도 후보로 만든다. 비교 오차 목표0.001mm는 CAD 합성 검산용이며 가죽 제조공차가 아니다. UI 반올림과 실제 수치를 구별한다.
4. **보존:** native 재열기 후 두께·반경·각도·직선 길이·NF·전개 업데이트 상태가 유지되는지 확인한다. 부품형상·저장·재열기·전개는 각각 별도 판정한다.
5. **교환:** 문서상 지원되는 neutral 형식을 별도 출력하고 새 문서로 재수입한다. mm 단위·bounds·선/원/곡선·레이어·절단/굽힘 의미를 확인한다. ST5의 Flatten은 같은 문서의 연관 전개이고 Save As Flat은 별도 결과로, 연관성이 유지된다고 가정하지 않는다. 구버전의 DXF/PSM/PAR 지원을 현지226 성공으로 표기하지 않는다.
6. **수신 프로그램:** 실제 가져오기 구현·형식·단위를 확인하기 전에는 교환 후보 형식까지만 보고한다. DXF가 생겼다는 사실이 메이2D 수신·전체 연결 성공은 아니다. 제품 앱/원본 데이터 변경은 별도 승인 범위를 따른다.

라이선스·계정·권한 모달, 확인되지 않은 API 인수/단위, 반복 실패가 있으면 해당 실행을 보류하고 정확한 상태를 기록한다. 같은 장애를 무한 재시도하거나 새 연결·다른 앱으로 우회하지 않는다. 기존 문서 저장상태를 먼저 보존하고 전역 템플릿·재료 라이브러리·변환 설정을 임의 변경하지 않는다.

## 현재 검증 상태

설치·버전·서명·등록 확인은 제한 통과, 편집 가능 라이선스는 오류 확인 상태다. 공식 자료의 위 제한 학습과 자체 산술·Guide 준비만 완료했다. native 생성·치수·저장·재열기·전개·neutral 왕복·메이 수신은 **미실행**, 실가죽·전체 제품·제조 정확도는 **미검증**이다. 전체 결과는 PARTIAL로 유지한다.
