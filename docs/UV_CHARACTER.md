# 캐릭터 UV · 얼굴·눈·몸과 적용 캐릭터 점검 계획

[UV 시작점](UV_WORKFLOW.md) · [시임과 전개](UV_SEAMS_UNWRAP.md) · [재질 인계](UV_TEXTURE_SETS_HANDOFF.md)

주요 근거는 [Dikko 캐릭터 강좌](https://www.youtube.com/watch?v=ZyRtd8iYBOg)와 [CG Boost 46:43 머리·54:18 눈](https://www.youtube.com/watch?v=JwkgVckqGw4&t=2803s)이다. 아래 적용 캐릭터 항목은 **적용 전 점검 계획**이다. 현재 모델·승인 이미지·UV를 이번 학습에서 새로 검사하거나 고친 것이 아니다. 다른 강좌 캐릭터의 외모·시임·타일 수를 적용 캐릭터의 승인 사양으로 삼지 않는다.

## 얼굴 앞면의 연속성을 우선한다

얼굴 앞면은 눈썹·눈 주변 선·홍조·입술처럼 작은 차이가 잘 보인다. 볼을 가로지르는 절개를 줄이고, 뒤통수·귀 뿌리·턱 밑 등에서 표면을 여는 안을 먼저 시험한다. 얼굴을 연속으로 둔다고 눈 안쪽 벽과 입 안의 면까지 모두 한 덩어리로 눌러 넣어야 하는 것은 아니다. 깊은 내부 구조가 볼·눈·입 주변 UV를 당기는지 분리해서 본다.

| 영역 | 강좌에서 확인한 처리 | 실제 모델에서 확인할 항목 |
|---|---|---|
| 뒤통수 | CG Boost와 Dikko의 숨은 세로 절개 | 정수리·앞이마 연속성, 머리카락 아래에서도 볼 수 있는 영역 |
| 귀 | CG Boost는 뿌리 둘레와 귀 내부 길이 절개, Dikko는 캐릭터별 다른 배치도 제시 | 귀 앞뒤·귓바퀴·귀 뿌리의 접힘, 해상도와 피부 경계 |
| 눈 안쪽 | 눈꺼풀 안쪽 벽을 분리하는 시임 | 보이는 속눈썹/눈꺼풀 선을 가로질러 끊지 않는지, 벽이 앞면을 당기는지 |
| 입 | 입술 바깥이 아니라 입 안으로 말려 들어간 뒤의 경계 절개 | 입꼬리 쏠림·입 안 연결·입술 텍스처 경계 |
| 목 | CG Boost는 턱 아래/귀 뒤 분리, 아래 둘레와 뒷목 길이 절개 | 머리·몸 UV 사이 색/거칠기/노멀 연속성, 목 크기 비율 |

눈·코·입의 UV를 조정한다고 3D 위치·형태를 바꾸지 않는다. 국소 영역을 크게 하면 주변은 더 좁아질 수 있으므로 바로 옆 볼·콧방울·입꼬리 체커까지 다시 본다. 좌우가 다른 왜곡을 보이면 내부 연결·시임·핀부터 확인하고 강제로 완전 대칭에 맞추지 않는다.

## 눈꺼풀 UV의 면적 확보

CG Boost 52:50~54:10은 눈 주변을 핀으로 보존하고 중간 눈꺼풀 루프의 핀을 해제한 뒤 UV의 눈 틈을 좁힌다. 그 결과 눈꺼풀 표면에 이미지 면적을 더 배정한다. 이는 **UV 평면의 조정**이며 3D 눈꺼풀을 닫거나 셰이프키를 만드는 시연이 아니다.

적용할 때는 외곽 눈 주변과 눈꼬리 랜드마크를 보존하고, 중간 루프가 교차하지 않도록 작은 범위로 조정한다. 열린 눈의 가시부뿐 아니라 눈꺼풀 안쪽·두께·접히는 곳의 체커를 확인한다. 기존 닫힌 눈 상태가 제공된 경우에는 그 상태도 후속 검수에 쓴다. 이번 교육 때문에 새 깜박임 리그나 표정을 추가 제작하지 않는다. [눈꺼풀 볼륨](FACE_EYELID_VOLUME.md)과 [셰이프키 교육](FACE_EYELID_SHAPE_KEYS.md)은 별도 주제다.

## 오목한 홍채를 가진 눈의 UV

CG Boost의 눈은 이미 중앙이 안으로 들어간 형태다. 강좌는 이 눈을 새로 모델링하지 않고 전개한다. 뒤쪽 캡을 떼고 가시 정면보다 뒤에 둘레 시임을 놓아 앞쪽을 원형으로 펼친다. 처음의 방향 문제를 수정하고, 홍채와 바깥 경계를 핀으로 유지하면서 홍채 주변 UV 면적을 조절한다. 뒤쪽 캡은 상대적으로 줄인다.

이 시연으로 확인할 수 있는 것은 앞쪽 홍채를 읽기 좋은 UV와 숨은 시임 배치다. 인버티드 콘케이브 눈의 깊이·광학·각막 셰이더·시선 추적·회전 중심이 검증되었다는 뜻은 아니다. 적용 캐릭터 눈 재제작에는 승인된 형태와 별도 모델링 가이드가 필요하다. UV를 원형으로 정리했다는 이유로 실제 홍채 지름이나 눈의 3D 깊이를 바꾸지 않는다.

| 눈 검수 항목 | 확인 방법 | 불합격 예 |
|---|---|---|
| 홍채 중심과 방향 | 중심 십자·동심원·방사선을 가진 진단 이미지 | 중심 쏠림, 방사선 꼬임, 한쪽만 반전 |
| 홍채/흰자 경계 | 같은 조명·크기의 정면과 사선 | 경계가 타원으로 늘거나 선이 끊김 |
| 숨은 시임 | 허용된 시선 범위의 옆·아래·위 | 회전하면 뒤쪽 절개가 정면에 나타남 |
| 좌우 고유성 | L/R 문자와 비대칭 점 | 의도와 다른 겹침으로 두 눈에 같은 점 |
| 재질 대응 | 눈 오브젝트/재질/UV 이름과 파일 표 | 피부 UV나 다른 이미지로 연결 |

진단 이미지의 실제 제작·적용과 시선 범위 시험은 이번 학습에서 하지 않았다. 향후 승인 범위 안에서 수행할 체크리스트다. 텍스처를 별도로 만들더라도 최종 눈 메시·UV 버전과 중심/경계 기준을 먼저 고정해야 다시 맞추는 비용을 줄일 수 있다.

## Mirror에는 서로 다른 두 목적이 있다

Josh는 대칭 부품의 UV를 **포개서 같은 이미지 영역을 재사용**한다. CG Boost 57:35 이후는 한쪽 눈을 타일의 절반에 두고 Mirror의 UV U 반사를 이용해 **다른 절반으로 대응**시키는 예다. 같은 Mirror라는 이름만 보고 동일한 배치로 취급하지 않는다.

고유 페인팅을 해야 하는 얼굴·눈에서는 비대칭 마크가 양쪽에 복사되는지 확인한다. 대칭 무늬를 공유하기로 했다면 겹침 쌍과 방향을 기록한다. 노멀/AO 베이크나 Painter 투영 결과까지 안전하다고 자동 판단하지 않는다. 적용 전후의 실제 평가 메시와 UV를 확인하며, UV를 보기 위해 원본 Mirror를 무조건 적용하지 않는다.

## 전신·손·머리카락의 연속성과 절개

Dikko는 옷을 재단하는 관점으로 몸의 옆면, 팔 아래, 다리 안쪽, 목과 손목 경계를 설계한다. 손은 손목 둘레와 손가락 측면을 이어 손바닥·손등을 펼치는 경로를 사용한다. 손가락 사이가 깊고 가늘기 때문에 뿌리 부분 쏠림과 손톱 방향을 가까이서 본다. 강좌의 특정 손가락 경로를 모든 손에 동일하게 복사하지 않는다.

몸통 앞뒤가 어깨·사타구니의 연결 때문에 계속 당겨지면 그 연결을 확인하고 추가 시임 후보를 비교한다. 관절 루프가 많다는 이유만으로 UV에서도 작은 별도 섬으로 모두 떼지 않는다. 피부 무늬의 연속성과 필요한 변형 여유를 함께 본다. [손 면 흐름](HAND_RETOPOLOGY.md), [전신 리토폴로지](BODY_RETOPOLOGY.md)는 UV와 구별되는 메시 구조 교육이다.

머리카락 띠처럼 규칙적인 쿼드는 정렬/Follow Active Quads를 시험할 수 있다. Dikko의 UV Squares는 추가 기능 사용 예이며 이번 작업에 설치하지 않았다. 불규칙 면이나 극점까지 무조건 사각 그리드로 밀지 않는다.

## 적용 캐릭터 적용 전 체크와 전달 형식

현재 제작 대상이 머리인지 몸인지 파일·오브젝트로 다시 식별한다. 별도 제작한 두상을 몸의 머리와 중복 수정하지 않는다. 기본 모델에 없는 옷·장식은 UV 누락 결함으로 취급하지 않는다. 최신 승인 이미지의 실제 원본, 가이드와 후보 파일의 관계를 확인하고 구체적인 외형을 문서만으로 확정하지 않는다.

1. 머리·좌우 눈·몸·입 안의 오브젝트/재질/UV 이름, 메시 버전, 기존 텍스처 대응을 읽어 기록한다.
2. 얼굴 연속성, 눈꺼풀 내부 벽과 입 안 연결, 귀 앞뒤, 목 경계, 의도된 좌우 겹침을 체커와 레이아웃으로 확인한다.
3. 수정이 필요하면 원본 보존 파일의 별도 Guide 컬렉션에 대상 범위·경계·랜드마크를 실제 표시하고 정면·사선·측면/세부 캡처, 필요한 면·정점 인덱스를 남긴다. 가이드 제작만으로 피부나 UV를 바꾸지 않는다.
4. 담당에게 가이드 파일과 실제 수정 후보를 구분해서 전달한다. 보존할 UV/재질/형태, 바꿀 범위, 체커·겹침·경계 완료 조건을 적는다. 정상 점유 해제 후 단독 작업한다.
5. 같은 시점·체커·이미지 해상도의 실제 전후를 검수한다. 외형 수정이라면 solid/wire도 비교한다. 파일 저장이나 면적 숫자 통과만으로 성공 처리하지 않는다.

교육 학습은 위 실제 제작·가이드·변형 시험을 수행했다는 보고가 아니다. 움직임·리깅 보류 범위를 유지한다.
