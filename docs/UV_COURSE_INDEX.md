# UV 5강 · 실제 학습 색인과 설명 대조

[통합 매뉴얼](UV_WORKFLOW.md) · [학습 보고서](../reports/VideoLearning/20261101_UV_REVIEW.md) · [기계 판독 색인](../reports/VideoLearning/20261101_UV_COURSE_INDEX.json)

영상 메타데이터 합계 **2시간 29분 54초**다. 각 원본의 전체 흐름을 30초 간격 및 시작/끝 표본으로 확인하고, 주요 조작은 추가 세부 시트와 단독 화면으로 대조했다. 전편의 이용 가능한 영문 자동자막을 중복 정리해 읽었다. 연속 전편 청취·모든 프레임 검사·시연의 직접 재현은 수행하지 않았다. 아래 구간은 탐색 기준이며 실제 동작은 해당 구간 안에서 이어진다.

## 2. CG Boost · Jim Morren의 전개 도구와 얼굴·눈

[UV Unwrapping in Blender (Full Beginner Tutorial)](https://www.youtube.com/watch?v=JwkgVckqGw4), 60:16. 정확한 원본 앱 버전은 확정하지 않았다. 메뉴에서 Angle Based·Conformal·Minimum Stretch와 UV 도구를 실제 확인했지만 현행 버전 호환 시험과 구별한다.

| 구간 | 직접 확인한 내용 | 기억할 제한 |

| 06:53~11:34 | Color Grid, Material/Solid Texture 표시, UV 원점 | 이미지·Mapping 좌표·실제 재질 연결 구별 |
| 11:34~17:20 | 상자, 시임과 Live Unwrap | 시임을 위한 엣지 선택과 전개 대상 면 선택은 별개 |

| 25:32~29:07 | UV Toolkit, 기본 Average Island Scale/Pack | 추가 기능 설치·최적 성능 동일성을 주장하지 않음 |
| 29:07~32:11 | 구, 쿼드 정렬과 극점, Pin/Unpin | 삼각 극점까지 쿼드 도구로 강제하지 않음 |

| 46:43~50:00 | 머리, 눈 안쪽/입 안/귀/턱 아래·목 시임 | 보이는 눈·입 가장자리를 무조건 절개하지 않음 |

## 설명이 충돌해 보일 때의 선택

| 쟁점 | 자료 대조 결과 | 매뉴얼의 기준 |
|---|---|---|
| Conformal은 쓸모없는가 | CG Boost는 Suzanne에서 불리, Josh는 기계형에 사용 | 같은 조건으로 형태별 비교 |
| 모든 체커는 같은 크기여야 하나 | 정규화 예와 얼굴/카메라 우선 배정이 공존 | 기준 밀도와 허용 예외를 분리해 기록 |
| 게임에는 단일 타일만 가능한가 | Dikko는 단일 타일도 소개, UDIM은 고해상도 캐릭터 예 | 실제 엔진·셰이더 지원과 예산으로 결정 |
| Mirror UV는 포개지는가 | Josh의 공유 스택과 CG Boost의 다른 절반 반사 | 평가된 실제 UV와 진단 문자로 구별 |
| UV 공간은 반드시 꽉 채워야 하나 | Josh는 밀도 맞춘 빈 공간, Huge는 여러 대안 | 밀도·간격·가시부 품질을 점유율보다 먼저 검사 |

이번 5강에는 완성 Painter 베이크/레이어 제작, 최종 Unity/Android 성능 검증, 인버티드 콘케이브 눈의 모델링과 회전 리그, 트림시트 제작 전체가 포함되지 않는다. 이 주제의 체크리스트를 강좌의 검증 결과로 인용하지 않는다.
