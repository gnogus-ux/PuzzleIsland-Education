# UV 제작 · 다섯 강좌 통합 매뉴얼

UV는 3D 표면이 이미지의 어느 위치를 읽을지 정하는 좌표다. 잘 펴진 UV, 충분한 텍스처 해상도, 좋은 원본 이미지, 올바른 재질 연결을 함께 확보해야 한다. 체커가 촘촘해졌다는 이유만으로 품질이 좋아졌다고 판단하지 않는다.

이 문서는 지정된 **Ryan King Art·CG Boost/Jim Morren·Dikko·Josh/BlenderBros·Huge Menace/Tristan의 영상 5편**을 학습한 교육자료다. [강좌별 시간 색인](UV_COURSE_INDEX.md), [실제 확인 범위](../reports/VideoLearning/20261101_UV_REVIEW.md)를 함께 읽는다. 기존 캐릭터의 UV나 메시를 수정한 결과가 아니다.

## 시작 전에 정할 계약

먼저 최종 카메라에서 표면이 차지하는 크기와 가까이 볼 수 있는 범위를 정한다. 정면 얼굴과 거의 보이지 않는 발바닥에 같은 픽셀 예산이 항상 필요한 것은 아니다. 반대로 지금 가려진 면도 다른 의상·시점·포즈에서 나타날 수 있다. UV 공간 확보를 이유로 승인되지 않은 메시 삭제를 하지 않는다.

작업 기록에 메시 버전, 오브젝트 이름, 단위와 월드 크기, Object Scale, UV 맵 이름, 재질 슬롯과 면 할당, 기존 텍스처 파일, Mirror/변형 모디파이어 상태를 남긴다. 이미 칠하거나 베이크한 모델이라면 UV의 변경은 기존 이미지와의 대응을 바꾼다. 원본 복사와 별도 후보 저장이 선행되어야 한다.

| 결정 | 기록할 내용 | 아직 정하지 못했다면 |
|---|---|---|
| 고유 페인팅 또는 반복 재질 | 글자·점·흉터 등 비대칭 필요, 허용된 겹침 쌍 | 우선 고유 영역으로 검사하고 겹침을 확정하지 않음 |
| 이미지 예산 | 세트별 W×H, 채널, 대상 카메라, 목표 밀도와 단위 | 강좌의 2K/4K나 px/cm를 사양으로 고정하지 않음 |
| 재질 구성 | 피부·눈·의상 등의 셰이더 차이와 내보내기 단위 | Blender 재질 수와 최종 드로 콜 수를 동일시하지 않음 |
| 가시성·변형 | 눈꺼풀·입 안·귀 뒤·손가락 사이의 노출 가능성 | 숨은 영역을 삭제하거나 지나치게 축소하지 않음 |
| 인수 도구 | 타일 지원, UV 채널, 노멀 규약, 이미지 연결 | UDIM·아틀라스 도입을 보류하고 호환 여부부터 확인 |

## 재사용 가능한 작업 순서

1. **진단용 사본**을 준비한다. 선택 범위와 활성 UV 맵, 표시 중인 이미지가 맞는지 확인한다. 새 체커는 작업용 재질에서 연결하고 원래 재질의 이름과 파일 대응을 보존한다.
2. **시임을 설계**한다. 표면을 평면으로 펴기 위한 절개와 보이는 경계의 연속성을 함께 고려한다. 원통의 뒤쪽 길이 방향 절개, 얼굴 뒤통수와 입 안의 절개처럼 위치에 이유를 붙인다. 시임 표시는 피부 메시를 물리적으로 자르는 작업과 다르다.
3. **선택 영역만 펼친다.** Angle Based·Conformal 등 후보를 같은 시임과 동일한 체커 조건에서 비교한다. 특정 방법이 모든 형태에 최고라고 정하지 않는다. 기존 핀·겹침·다른 재질 세트까지 전체 재전개로 덮지 않는다.
4. **왜곡부터 고친다.** 체커 사각형의 찌그러짐, 글자의 좌우 반전, 접힘·겹침, 극점 쏠림을 본다. 필요하면 시임을 보강하고, 유지할 경계를 핀으로 고정한 뒤 UV Relax나 국소 조정으로 푼다.
5. **상대 밀도를 맞추고 예외를 기록**한다. Average Island Scale은 섬의 상대 크기 조정이다. 목표 px/m와 이미지 크기를 지정하는 작업과 구별한다. 얼굴 우선 배정 등 의도적인 차이는 수치와 이유를 남긴다.
6. **패킹**한다. 회전 허용, 섬 크기 보존, 의도된 겹침, 타일 경계와 실제 픽셀 간격을 확인한다. 최종 패킹 후 밀도를 다시 잰다. 빈 공간을 채우는 자동 확대가 목표 밀도를 바꿀 수 있다.
7. **대표 이미지와 실제 출력 조건으로 재검사**한다. 체커에 더해 눈 주변 선·입술 경계·피부 점·의상 패턴처럼 실제로 필요한 디테일을 확인한다. 축소 이미지와 mip 단계에서 경계 번짐도 본다.
8. **인수 자료**를 만든다. 후보 파일, UV 레이아웃, 같은 시점의 체커 전후, 재질/이미지/세트 표, 의도된 겹침, 남은 문제를 전달한다. 텍스처나 엔진에서 열어보지 않았다면 해당 검사는 미실행으로 남긴다.

## 증상별로 돌아갈 단계

| 증상 | 우선 분리해서 볼 원인 | 바로 하지 않을 일 |
|---|---|---|
| 눈·입 주변만 줄무늬가 길어짐 | 내부 면 연결, 시임, 경계 핀, 국소 UV 면적 | 전체 이미지 해상도만 올리기 |
| 서로 다른 부품의 체커 크기가 다름 | 세트별 이미지 크기, 월드 단위, UV 상대 스케일 | 패킹 효율만 보고 섬을 임의 확대 |
| 한 방향은 정상, 측면은 길게 늘어남 | Project from View의 투영 방향과 겹침 | 한 장의 정면 캡처로 통과 처리 |
| 양쪽 얼굴에 같은 점이 나타남 | Mirror 또는 고의/실수 UV 겹침 | 페인트 프로그램의 오류로 단정 |
| 경계에 다른 색 선이 생김 | 섬 간 간격, 베이크 확장, 필터링·mip·압축 | 시임을 모두 지우고 다시 펼치기 |
| UV는 고른데 텍스처가 흐림 | 원본의 실제 선명도, 출력 크기, 화면 투영 크기 | 텍셀 밀도만으로 합격 판정 |

## 교육과 제작의 완료 조건

이번 학습은 전편의 정제 자동자막과 시작부터 끝까지 분포한 화면 표본을 확인해 문서로 만든 것이다. 모든 프레임 검사나 연속 전편 청취를 뜻하지 않는다. 강좌 UI 중 Ryan은 3.2.0, Josh는 2.92.0, Huge Menace는 4.1.0 표시를 확인했다. CG Boost와 Dikko의 정확한 버전 및 현행 Blender 5.2의 메뉴·연산자 동작은 이번 작업에서 검증하지 않았다. 표시된 원본 UI와 적용 전 확인할 항목을 구분한다.

실제 제작 완료에는 후보 파일을 다시 열어 UV·재질·이미지 대응을 확인하고, 의도하지 않은 겹침/접힘과 가시부 왜곡을 해결하며, 지정한 카메라·출력 크기에서 품질을 확인해야 한다. 숫자 검사나 저장 성공만으로 시각 품질을 통과시키지 않는다. 이번에는 Blender·Painter·Unity를 실행하거나 캐릭터·게임 데이터를 바꾸지 않았다.
