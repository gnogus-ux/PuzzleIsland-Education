# 등록한 입구·고정 경계를 평판 메시 후보에 연결하기

2026-11-08. 사진/도면 경계를 가진 **평면 사각 패널의 별도 후보**를 만들기 위한 설계다. 기존 생산 메시나 곡면 패널의 보편 복원법이 아니다. 먼저 [곡면·포켓 높이 §1~3](WALLET_BROAD_CURVATURE_AND_POCKET_HEIGHT.md)과 [사진 배율](PHOTO3D_WALLET_APPLICATION.md)을 적용한다.

## 직접 읽은 공식 자료3개

| 원문 | 확인 범위·적용 |
|---|---|
| [Blender5.2 Geometry Utilities](https://docs.blender.org/api/5.2/mathutils.geometry.html) | `delaunay_2d_cdt`의 인수, 출력0~5, epsilon, 입력↔출력 orig 목록. 반환 정점 순서·위치·개수는 입력과 같지 않을 수 있다. 전체 출력0은 볼록껍질 삼각형이며 슬롯/구멍을 자동 생성하는 옵션이 아니다. |

| [Blender2.81 Python API 릴리스노트](https://developer.blender.org/docs/release_notes/2.81/python_api/) | Mathutils–Geometry 절. 이 기능의 도입 및 평면 제약 보존/교차 처리 설명을 확인했다. 역사적 문서이며5.2 실행 근거를 대신하지 않는다. |

웹 도구의402/캐시 실패 후 공식 원문을 직접 받아 해당 절을 읽었다. 실제5.2.2 LTS의 격리 factory 프로세스에서 함수 docstring과 교차 대각선 쿠폰의5정점·8선·4삼각형 및 orig 목록 반환을 확인했다. 설정 파일 전후 해시는 같고 저장/사용자 씬 조회는 없었다. 별도 삼각화 라이브러리·새 Geometry Nodes 노드나 애드온 설치가 필요한 경로가 아니다. 이 쿠폰이 완성 입구 메시·물리 성능 검증이라는 뜻은 아니다.

## 1. 원본·좌표·조건을 먼저 고정한다

대상 부품 ID, 원본 메시 해시, 도면 계획과 사진 해시, 자유 입구와 고정 선, 이동 법선, 두께를 기록한다. 사진 ROI→평면 XY 대응은 기존 임시 도면의 배치 가정일 수 있으며 원근 보정이나 실측 복원이 아니다. 미확정 구속을 사용할 후보는 가정 모드를 명시하고 기존 등록의 확인 플래그를 바꾸지 않는다.

처음에는 평면 사각 패널과 분리된 내부 입구를 지원한다. 비평면·비사각·겹친 입구·내부의 자유 끝점처럼 지원하지 않는 경계는 이유를 표시하고 보류한다. 고정 끝점과 자유 끝점을 임의로 교환하지 않는다.

## 2. 제약 선에 맞는 면 흐름을 만든다

외곽, 샘플링한 입구 곡선, 고정 봉제/접착/접힘 선을 제약으로 넣고 내부 표본점으로 분해능을 정한다. CDT 반환의 orig edge 목록을 통해 제약 선을 실제 출력 에지에 대응한다. 교차·중복·epsilon으로 합쳐진 정점과 퇴화 삼각형은 좁은 검사로 확인한다. UV/재질/기존 키가 입력에 없다면 보존했다고 주장하지 않는다.

삼각화만으로 입구가 열리지는 않는다. 입구 양편의 면을 구분하고 입구의 내부 정점을 양쪽으로 나눈다. 고정된 슬롯 끝은 같은 위치로 이어지게 한다. 입구 위쪽과 아래쪽이 같은 정점을 계속 공유한 채 표면만 부풀리면 실제 벌어짐이 아니다. 자유 끝·곡면의 일반 위상 수선은 별도 설계가 필요하다.

## 3. 부드러운 변위와 두께를 별도로 처리한다

아래는 기존 C2 곡면 매뉴얼을 이용한 자체 설계다. 입구를 따라 정규화한 위치의 양끝 마스크와 몸판 쪽 복귀를 곱한다. 등록 고정 선과 보존 외곽에서는 추가 변위와 그 첫 두 미분이0이어야 한다. 다른 입구의 경계에서 한 조절기의 영향이0이 되는지도 확인한다.

이동량을 `h=sum(A_i W_i)`로 두면, 고정된 분해망에서 각 `W_i`와 XY 기울기를 캐시할 수 있다. 높이 슬라이더는 이 계수의 합을 갱신한다. 입력 경계·좌표 대응·영향 폭을 바꾸면 캐시를 무효화한다. 슬롯의 양편은 서로 다른 분기에서 높이/기울기를 평가한다.

평판 두께를 `t`, 변형 중간면을 `m`, 정규화한 중간면 법선을 `n`으로 두고 앞뒤 대응을 `m±(t/2)n`으로 생성하면 **그 대응점 사이 거리**는 `t`다. 단순히 두 Z값에 같은 높이를 더한 결과와 구분한다. 이 성질만으로 주변 면 사이의 최단 두께·압축·길이/체적 보존·충돌 부재를 보장하지 않는다.

## 4. Guide·후보·검증을 분리한다

원본 형상과 등록된 선/이동 방향을 담은 Guide를 먼저 별도 저장한다. 후보는 새 파일/데이터로 만들고 생산 원본에 덮어쓰지 않는다. 변경하지 않은 부품은 원본과 해시/정점을 대조한다. 후보를 다시 열어 실제 정점과 면을 읽는다.

검수는 입구 양편 정점의 분리와 벌어짐, 고정선 오차, 앞뒤 대응 두께, 퇴화/면 방향/에지 사용수,0복귀, 조절기 독립성, 동일 시점 solid/wire를 포함한다. 전역 충돌·재료 시뮬레이션·실물 적합성은 별도 단계로 남긴다. 함수의 C2 성질이 성긴 삼각형 메시에서 그대로 보인다고 가정하지 않는다.

문서 학습·기본 API 쿠폰·후보 생성·재열기·제품 최종 승인을 구별해 각 작업 실행 근거에 기록한다. 이 문서는 비공개 제품 사진·모델·로컬 경로를 포함하지 않는다.
