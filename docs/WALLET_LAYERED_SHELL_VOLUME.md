# 겹 구조 지갑: 추가 내피와 외피 여유분의 펼침 볼륨

2026-11-04 Codex 작성. 박스를 지지하는 안쪽 구조와 봉제 경계 사이에서 자유로운 외피를 구분하는 제작 절차다. 아래 공식 자료 세 문서의 필요한 본문을 직접 읽고 대조했다. **문서 학습과 실제 제품 제작·접힘 검증은 별개**이며 특정 제품의 치수·가죽 물성을 검증한 문서가 아니다. [열람 범위](../reports/ExternalLearning/20261104_LAYERED_WALLET_STUDY.json)를 함께 확인한다.

## 1. 자료에서 확인한 기능과 적용 한계

| 직접 읽은 Blender 5.2 공식 문서 | 확인한 기능 | 적용 한계 |
|---|---|---|
| [Cloth Shape](https://docs.blender.org/manual/en/5.2/physics/cloth/settings/shape.html) 전체 본문 | Pin Group의 가중치, 면에 속하지 않은 연결 엣지로 구성하는 Sewing, Shrinking Factor, Dynamic Mesh와 Rest Shape Key | 실제 제품의 봉제 위치나 여유 길이를 자동으로 결정하지 않는다. Sewing과 Pinning은 다른 구속이다. |
| [Cloth Physical Properties](https://docs.blender.org/manual/en/5.2/physics/cloth/settings/physical_properties.html) 전체 본문 | 인장·압축·전단·굽힘 저항, Internal Springs, Pressure | Pressure는 유체가 들어 있는 연성 껍질을 위한 모델이다. 열린 겹 가죽의 여유분 볼륨에 그대로 적용할 근거가 아니다. |
| [Shape Keys Panel](https://docs.blender.org/manual/en/5.2/animation/shape_keys/shape_keys_panel.html) 전체 본문 | Relative Key의 기준과 영향값, Vertex Group 제한, 동일 토폴로지 조건, Basis 적용·삭제의 효과 | 키 보간 자체는 길이 보존·접촉·충돌을 보장하지 않는다. 실측 가죽 시뮬레이션으로 주장하지 않는다. |

아래 겹 구조와 제작 순서는 이 기능들을 조합한 **적용 설계안**이다. 공식 문서에 완성 지갑의 동일 구조가 예제로 실려 있다는 뜻은 아니다. Cloth Filter의 Inflate는 [기존 지갑 매뉴얼](WALLET_MODELING.md)의 퀼팅 설명과 구별한다.

## 2. 먼저 겹 순서와 연결을 그린다

제품별로 기존 내피, 박스, 추가 내피, 외피의 위치를 실제 단면으로 확인한다. 필요한 구간의 순서는 `박스 → 추가 내피 → 외피`이며, 이미 있는 포켓용 내피를 추가 내피로 오인하거나 삭제하지 않는다. 추가 내피는 박스와 외피 사이의 별도 지지층이다. 박스와 어떤 경계에서 연결되는지, 외피와 공유하는 봉제 경계가 어디인지 표시한다.

- 박스를 잡는 내피의 지지 역할과 외피의 자유 면을 분리한다.
- 외피는 지정 봉제 구간을 공유하되 그 외 전 면을 내피에 접착·전달 웨이트로 밀착시키지 않는다. 모서리·입구·등·포켓의 실제 고정 여부를 따로 기록한다.
- 외피 면의 자유도가 있어도 전체가 관통해도 된다는 뜻은 아니다. 가죽 두께와 박스·내피 사이 간격은 별도로 검사한다.
- 내피 한 장을 추가했다는 사실만으로 외피에 부피가 자동 발생하지 않는다. 외피의 자연 길이, 봉제 경계 위치, 닫힘 때 감싸는 거리와 펼침 때의 경계 간 거리가 함께 맞아야 한다.

가이드에는 허용 이동 면, 고정 봉제 경계, 기존 입구·등·모서리의 보존 범위, 추가 내피의 단면 위치와 원하는 외피 윤곽·이동 방향을 표시한다. 별도 Guide 파일과 원본 보존 파일을 먼저 만들고 가이드 인수 후 실제 수정을 시작한다.

## 3. 여유 길이를 부피 수치와 구분한다

닫힌 외피는 박스와 겹의 바깥 둘레를 돌아야 한다. 펼쳤을 때 같은 외피가 더 짧은 경계 간 거리에 연결되면 여유분이 곡면으로 분배될 수 있다. 하지만 두께, 굽힘 저항, 마찰, 봉제 위치 등에 따라 결과가 달라져 크기 차이만으로 특정 볼록 높이나 주름 방향이 정해지지는 않는다.

대표 단면을 정하고 아래를 측정한다.

1. 닫힘 때 외피가 실제로 따라가는 바깥 경로 길이와 두께 누적.
2. 펼침 때 같은 봉제 경계 사이의 내피 경로 길이와 외피 곡면 경로 길이.
3. 외피의 여유 길이 차이와 가장 높은 위치, 봉제 주변 복귀 폭.
4. 중간 각도에서 길이·간격이 급변하는지와 모서리·입구의 변형.

봉제 경계를 움직여 여유를 만든 것과 면 내부에 실제 경로 길이를 확보한 것을 구별한다. 전체 스케일 확대는 실밥·구멍·입구까지 움직일 수 있으므로 기본 해결책으로 쓰지 않는다. 봉제선을 같은 위치에 두고 외피 내부 면에 완만한 곡률을 배분한다. 예시 높이·여유 비율을 실측값이나 보편 합격선으로 고정하지 않는다.

## 4. 제작 경로 A: 형상 키로 통제하는 비물리적 표현

재생·시뮬레이션이 보류된 프로젝트에서는 이 경로를 우선 검토한다. 기존 펼침 제어를 보존하고 외피의 닫힘·중간·펼침 목표 형상을 제한적으로 작성한다. 이는 접힘 각도에 맞춘 표현 제어이며 물리 해석의 성공을 뜻하지 않는다.

1. 원본 메시·UV·재질·기존 변형과 사용자 변경을 보존한다. 기존 키가 있는지 먼저 확인한다.
2. 추가 내피는 별도 메시로 만들고 실제 승인 단면의 지지 위치를 따른다. 기존 내피·박스·포켓을 새 층의 자리로 임의 밀어내지 않는다.
3. 외피에 필요한 면 흐름이 있는지 확인한다. 형태 키 사이 정점 대응과 토폴로지를 유지한다. 필요 토폴로지 변경은 키 작성 전에 별도 가이드로 처리한다.
4. 닫힘 목표에서는 바깥 경로를 따라 밀착시키되 두께를 없애거나 박스를 관통시키지 않는다. 펼침 목표에서는 여유분을 면 내부의 완만한 볼륨으로 분배한다.
5. 고정 봉제 경계의 이동량은 0으로 두고 자유 면으로 매끄럽게 전환한다. 키의 Vertex Group은 영향 제한에 사용할 수 있지만 각 키의 경계 좌표도 직접 확인한다.
6. 기존 펼침 값과 키 영향값의 대응을 기록한다. 중간 형상이 직선 보간만으로 올바르다고 가정하지 않고 필요한 중간 목표를 검수한다. 기존 리그 전체를 재설계하거나 다른 파트에 새 동작을 만들지 않는다.
7. 기본 외피, 외피 포켓, 덧댐, 실·엣지코트 중 무엇이 같은 표면을 따라야 하는지 구분한다. 봉제 연결 파트는 같은 경계 변형을 따라야 하며 단순히 같은 부모를 둔 것만으로 이를 검증했다고 하지 않는다.

키를 Basis에 적용하거나 Apply All/Delete All을 실행하면 보존된 편집 구조가 바뀐다. 원본 보존 단계에서 일괄 적용·삭제하지 않는다. 전체 키 잠금도 변환·토폴로지 작업을 모두 막는 것은 아니다.

## 5. 제작 경로 B: 별도 승인된 Cloth 시험

이 경로는 시뮬레이션·접촉 시험이 허용된 별도 사본에서만 실행한다. 가이드나 문서 작성 승인으로 기존 물리·재생·베이크 보류를 해제하지 않는다.

Pin Group은 경계 목표를 강하게 잡는 구속이다. Sewing은 한 천 메시의 부분 정점을 느슨한 엣지로 연결해 서로 당기는 가상 스프링이다. 보이는 실 한 땀 메시나 다른 오브젝트의 가까운 정점이 자동으로 Sewing이 되는 것은 아니다. 전 면을 Pin하면 외피의 자유도가 사라진다. Max Sewing Force의 0은 무제한이므로 안정적인 봉제력이 0이라는 뜻으로 해석하지 않는다.

자연 길이와 인장·압축·굽힘 저항을 함께 다룬다. Shrinking Factor의 음수는 성장을 제어하지만 이를 무조건 켜서 특정 볼륨을 얻는 공통 수치로 쓰지 않는다. Dynamic Mesh는 앞선 변형에 따라 매 프레임 rest shape를 다시 계산하므로 고정 자연 길이 전제와 다를 수 있다. Rest Shape Key와 Dynamic Mesh는 서로 배타적인 선택이다. Pressure로 부풀린 결과를 봉제 경계 사이의 여유 길이로 생긴 볼륨과 동일하게 취급하지 않는다.

## 6. 좁은 검수와 인계

| 상태/구분 | 확인할 것 |
|---|---|
| 닫힘 | 외피가 바깥 경로에 밀착하고 박스·추가 내피를 관통하지 않는지, 겹 두께와 봉제 위치 |
| 중간 펼침 | 외피 볼륨의 급변·뒤집힘, 입구·등의 꺾임, 실·코팅의 분리 |
| 완전 펼침 | 내피의 지지 유지, 자유 면의 곡면·여유 경로, 보존 경계 이동 0 |
| 단면/와이어 | 추가 내피가 독립 층인지, 메시·두께·면 흐름이 의도한 구조인지 |
| 동일 조명 전후 | 큰 곡면의 반사 변화와 미세 PBR 결을 분리해서 비교 |

사용자가 승인한 상태의 정지 검수를 우선한다. 수행하지 않은 전체 충돌·위상·물리 시뮬레이션·영상 렌더를 PASS로 쓰지 않는다. 고정 경계 최대 이동, 대표 단면 경로 길이와 층 간격, 목표/실제 윤곽, 보존된 파일·UV·다른 파트를 기록한다.

인계에는 가이드 파일·캡처·대상 오브젝트·영역 정보·보존 경계·새 내피의 연결 역할·각도별 목표·실행한 검수·미검증을 포함한다. 기존 [공통 작업 규칙](COMMON_WORK_RULES.md)과 [가이드 절차](WALLET_MODELING.md)를 따른다. Claude는 기존 매뉴얼을 읽어 제작·검수하며, 새 교육·매뉴얼 보강은 Codex에 알린다.
