# 카드지갑 모델링과 봉제선 제작 매뉴얼

이 매뉴얼은 펼침 160×110mm, 몸판 가죽 2mm, 등 가죽 1mm의 카드지갑을 예시로 작성한 제작 절차다. 수치는 설명용 예시이며 각 제품의 실측값으로 바꾼다. **외형과 접힘은 메시, 봉제선은 경로를 따르는 실 메시, 미세한 가죽 결은 표면 맵으로 나누어 만든다.** 강좌의 아이콘 비례와 퀼팅 변형을 제품 치수에 그대로 옮기지 않는다.

강좌 화면에서 확인한 방법은 각 출처 링크로 표시했다. 아래 지갑 제작 순서와 통과 기준은 그 방법을 지갑 예시에 맞춰 구성한 적용안이며, 새 지갑 모델에서 검증된 결과를 뜻하지 않는다.

## 1. 어떤 강좌를 먼저 활용할 것인가

| 대상 | 우선 자료 | 예시 지갑에 가져올 원리 |
|---|---|---|
| 외피와 안쪽 포켓 | [M2 지갑 배속 모델링](https://www.youtube.com/watch?v=2w6d4JSK3mw) | 참고 사진을 나란히 보며 외곽, 지지 루프, 내부 파트를 나누어 제작 |
| 테두리 실밥 | [M5 봉제선](https://www.youtube.com/watch?v=LxRl6K-S5T4) | 표면의 엣지에서 경로를 얻고 실 한 땀을 반복 배치 |
| 단순한 외형 시안 | [M1 지갑 아이콘](https://www.youtube.com/watch?v=xkWrT79HkTI), [M3 미니멀 지갑](https://www.youtube.com/watch?v=-mn100riec4) | 둥근 외곽과 별도 부품의 비례를 빠르게 확인 |
| 퀼팅이 있는 제품 | [M4 Cloth Filter](https://www.youtube.com/watch?v=jVgxGea8mE8) | Face Sets로 영역을 나누고 Inflate로 구역별 부피 조절 |

M1·M3는 단순화한 지갑 형태를 만들며, 실제 카드 슬롯의 작동이나 특정 접힘 리그를 검증하는 강좌는 아니다. M4의 다이아몬드 퀼팅은 예시 파란 내피의 작은 엠보싱과 크기·역할이 다르다.

## 2. 작업 시작 전 기준을 고정한다

1. 대상 제품과 기준 모델을 확인하고 승인본·시험 후보·렌더용 사본을 구분한다.
2. 승인본, 범프 후보, 실제 변위 후보 중 무엇을 기준으로 하는지 정하고 별도 후보로 저장한다. 모델 파일과 렌더용 스크립트의 역할을 구분한다.
3. 펼침 치수, 몸판·등 두께, 카드 모델, 접힘 축, 고정 패널을 기록한다. 안쪽 슬롯의 높이·폭·봉제선 간격은 기존 모델과 실물 참고로 확인한다.
4. 처음에는 단순 회색 재질로 외곽·단면·겹침을 본다. 가죽 무늬가 형상 결함을 가리지 않게 한다.
5. 기존 리그에 연결된 오브젝트의 Scale을 일괄 적용하지 않는다. 두께와 변위가 로컬 좌표를 사용한다는 사실을 확인하고, 필요한 보정은 사본에서 리그·애니메이션까지 함께 검증한다.

## 3. 외피와 등 가죽의 형태를 만든다

M2의 [00:30~03:00](https://www.youtube.com/watch?v=2w6d4JSK3mw&t=30)에서는 둥근 판의 외곽과 테두리 루프, 분리된 파트를 확인할 수 있다. M3의 [01:00](https://www.youtube.com/watch?v=-mn100riec4&t=60)에서는 두께가 있는 접힌 외피 형태를 볼 수 있다. 예시 지갑에는 다음 순서로 응용한다.

1. 외곽의 가로·세로와 모서리 곡률부터 맞춘다. 물결 모양의 결이나 봉제선은 나중에 추가한다.
2. 등 가죽의 굽힘 영역은 하나의 날카로운 경첩선으로 접지 않고, 곡률을 조절할 수 있는 여러 줄의 면으로 구성한다. 접힘을 가로지르는 긴 면과 한 지점에 몰린 면을 피한다.
3. 몸판과 등 가죽의 2mm·1mm 차이를 구조 또는 두께 제어에 반영한다. 앞뒷면 사이 실제 거리를 평가해 확인한다.
4. Solidify를 사용하는 파트는 법선 방향, Thickness의 부호, Offset과 Rim을 확인한다. 이미 닫힌 두께 메시에는 같은 두께를 다시 더하지 않는다.
5. Bevel과 지지 루프를 이용해 모서리 반경을 조절한다. 정면이 부드럽다는 이유만으로 통과시키지 말고, 옆면의 두께와 하이라이트가 꺾이는 위치도 본다.

Solidify의 입력값은 로컬 좌표를 기준으로 하며, 비균일 Scale과 면 배치에 따라 최종 두께가 달라질 수 있다. Even Thickness도 모든 부분의 정확한 두께를 보장하지 않는다. [Blender Solidify 설명](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/solidify.html)

## 4. 카드 포켓은 열린 입구와 겹침을 가진 별도 층으로 만든다

M2의 [06:30~08:30](https://www.youtube.com/watch?v=2w6d4JSK3mw&t=390)에서는 내부 판과 포켓을 분리하고 Solidify로 두께를 주는 작업을 볼 수 있다. 화면의 포켓 제작 원리는 사용하되, 영상 속 두께나 폭을 예시 제품의 실측값으로 취급하지 않는다.

1. 카드 한 장과 포켓 한 개로 맞춤을 확인한 뒤 슬롯 수를 늘린다. 카드가 들어가는 빈 공간과 입구가 실제로 열려 있어야 한다.
2. 앞 포켓의 높이, 뒤 포켓의 노출량, 좌우 여유를 먼저 맞춘다. 각 층을 외피 표면에 겹쳐 붙이기만 하면 접히거나 카드가 들어갈 때 관통할 수 있다.
3. 가장자리와 봉제되는 구역은 정리하되, 입구를 가로질러 막는 면이나 불필요한 Rim이 생기지 않았는지 검사한다. Rim은 한 장의 가죽 단면을 닫는 것이며 포켓 입구를 봉합하는 기능과 다르다.
4. 안쪽 면과 카드 사이 여유는 실제 카드 모델을 기준으로 본다. 재질 음영만으로 여유가 있는지 판정하지 않는다.
5. 층이 늘어날수록 닫혔을 때 두께가 누적된다. 펼침 상태, 중간 접힘, 닫힘 상태에서 슬롯 입구·등·카드의 겹침을 함께 확인한다.

포켓이 납작해지는 문제는 먼저 면 배치·지지 루프·두께·변형 가중치에서 찾는다. 가죽 범프를 강하게 해서 포켓 형태를 복구하려 하지 않는다.

## 5. 봉제선을 만드는 절차

M5에서는 Suzanne의 엣지를 복제·분리해 커브로 바꾸고, 작은 실 조각을 Array와 Curve로 배치한 뒤 두께와 둥근 단면을 조정한다. [02:30](https://www.youtube.com/watch?v=LxRl6K-S5T4&t=150), [04:30~07:00](https://www.youtube.com/watch?v=LxRl6K-S5T4&t=270) 화면을 참고한다.

1. 외곽에서 일정하게 안쪽으로 들어온 봉제 경로를 만든다. 기존 엣지를 복제·분리하거나 별도 커브를 만들되, 실제 봉제되는 부분과 슬롯 입구를 구분한다.
2. 실 한 땀을 낮은 볼륨의 메시로 만든다. 실 중앙은 약간 떠 있고 양 끝은 표면으로 들어가도록 조절한다. 강좌의 평면 조각을 그대로 두지 않는다.
3. 반복하는 실과 경로의 원점, 진행 축, Scale을 맞춘다. 실이 엉뚱한 곳으로 날아가면 Count보다 이 정렬을 먼저 확인한다.
4. 강좌 방식에서는 반복을 만든 뒤 Curve로 변형한다. 영상의 120개 전후 Count나 1.1 Relative Offset은 예시다. 예시 지갑은 경로 길이와 실제 한 땀의 길이·간격으로 다시 정한다.
5. 모서리에서 실이 겹치거나 늘어지면 곡률과 간격을 함께 조절한다. 폐곡선의 시작·끝 중복과 열린 경로의 마지막 실 위치를 확인한다.
6. 실 단면을 충분히 둥글게 만들되 화면에서 구분되지 않는 세분화는 줄인다. 실 아래의 눌림 홈은 보조 표현이며, 실제 가죽 2mm·1mm를 뚫을 만큼 깊게 만들지 않는다.
7. 가죽과 봉제선이 같은 접힘을 따라야 한다. 같은 부모만 지정해도 동일한 표면 변형이 된다고 가정하지 말고, 기존 변형 체계와 커브 또는 실 메시의 연결을 검사한다.

Blender 5.2에는 새 Array와 Array Legacy가 함께 있다. 영상의 Fixed Count·Relative Offset·Fit Curve UI는 기존 방식과 대응하므로, 현재 설치 버전의 실제 항목을 확인한다. Fit Curve는 반복 길이를 맞추는 기능이며, 기존 방식에서 경로를 따라 구부리는 Curve modifier와 구분한다. [Array Legacy](https://docs.blender.org/manual/en/5.2/modeling/modifiers/generate/array_legacy.html), [Curve modifier](https://docs.blender.org/manual/en/5.2/modeling/modifiers/deform/curve.html)

## 6. Cloth Filter를 사용할 부분과 보류할 부분

M4의 [02:00](https://www.youtube.com/watch?v=jVgxGea8mE8&t=120)에서는 격자 영역 구분이 보이고, [03:00](https://www.youtube.com/watch?v=jVgxGea8mE8&t=180)에서는 Inflate·Use Face Sets가 표시된다. 완성 결과는 다이아몬드 구역이 부푼 퀼팅이다.

예시 제품에 퀼팅 사양이 없다면 이 격자를 새로 넣지 않는다. 향후 부드러운 가죽의 큰 눌림을 표현할 때는 별도 시험 파트에서 경계와 봉제 부위를 마스크 또는 Face Sets로 보호하고 약하게 사용한다. 미세 엠보싱은 높이맵으로 처리한다. Cloth Filter가 만들어 낸 모양을 실측 두께가 보존되는 접힘 시뮬레이션으로 취급하지 않는다. [Cloth Filter와 고정 영역](https://docs.blender.org/manual/en/5.2/sculpt_paint/sculpting/tools/cloth_filter.html)

## 7. 접힘과 카드 동작 검수

아래는 예시 지갑을 위한 적용 검수안이다. 다섯 모델링 강좌가 이 리그나 동작을 직접 가르치는 것은 아니다.

| 상태 | 확인할 것 |
|---|---|
| 완전히 펼침 | 160×110mm 치수, 등과 몸판의 연속성, 슬롯 입구와 실밥 위치 |
| 열림 중간 | 등 안쪽의 압착, 바깥쪽 늘어짐, 포켓과 봉제선의 분리·관통 |
| 카드 삽입 중 | 카드가 입구로 들어가는지, 옆이나 뒷면을 뚫고 통과하지 않는지 |
| 닫힘 | 카드와 각 가죽 층의 누적 두께, 등 반경, 앞뒷면 교차 |
| 최종 2K 구도 | 실밥이 과하게 크지 않은지, 가장자리 떨림과 반짝임이 생기지 않는지 |

형상 → 두께 → 포켓 → 봉제선 → 접힘 → 표면 결 순서로 확인한다. 한 단계가 실패하면 그 원인부터 고친다. 기존 연출이 있다면 고정 패널, 카드 진입 방향과 타이밍은 별도 기준으로 보존한다.
