카드지갑 모델링과 봉제선 제작 매뉴얼

이 매뉴얼은 펼침 160×110mm, 몸판 가죽 2mm, 등 가죽 1mm의 카드지갑을 예시로 작성한 제작 절차다. 수치는 설명용 예시이며 각 제품의 실측값으로 바꾼다. 외형과 접힘은 메시, 봉제선은 경로를 따르는 실 메시, 미세한 가죽 결은 표면 맵으로 나누어 만든다. 강좌의 아이콘 비례와 퀼팅 변형을 제품 치수에 그대로 옮기지 않는다.

강좌 화면에서 확인한 방법은 각 출처 링크로 표시했다. 아래 지갑 제작 순서와 통과 기준은 그 방법을 지갑 예시에 맞춰 구성한 적용안이며, 새 지갑 모델에서 검증된 결과를 뜻하지 않는다.

1. 어떤 강좌를 먼저 활용할 것인가

대상우선 자료예시 지갑에 가져올 원리
외피와 안쪽 포켓M2 지갑 배속 모델링참고 사진을 나란히 보며 외곽, 지지 루프, 내부 파트를 나누어 제작
테두리 실밥M5 봉제선표면의 엣지에서 경로를 얻고 실 한 땀을 반복 배치
단순한 외형 시안M1 지갑 아이콘, M3 미니멀 지갑둥근 외곽과 별도 부품의 비례를 빠르게 확인
퀼팅이 있는 제품M4 Cloth FilterFace Sets로 영역을 나누고 Inflate로 구역별 부피 조절

M1·M3는 단순화한 지갑 형태를 만들며, 실제 카드 슬롯의 작동이나 특정 접힘 리그를 검증하는 강좌는 아니다. M4의 다이아몬드 퀼팅은 예시 파란 내피의 작은 엠보싱과 크기·역할이 다르다.

2. 작업 시작 전 기준을 고정한다

1. 대상 제품과 기준 모델을 확인하고 승인본·시험 후보·렌더용 사본을 구분한다.

2. 승인본, 범프 후보, 실제 변위 후보 중 무엇을 기준으로 하는지 정하고 별도 후보로 저장한다. 모델 파일과 렌더용 스크립트의 역할을 구분한다.

3. 펼침 치수, 몸판·등 두께, 카드 모델, 접힘 축, 고정 패널을 기록한다. 안쪽 슬롯의 높이·폭·봉제선 간격은 기존 모델과 실물 참고로 확인한다.

4. 처음에는 단순 회색 재질로 외곽·단면·겹침을 본다. 가죽 무늬가 형상 결함을 가리지 않게 한다.

5. 기존 리그에 연결된 오브젝트의 Scale을 일괄 적용하지 않는다. 두께와 변위가 로컬 좌표를 사용한다는 사실을 확인하고, 필요한 보정은 사본에서 리그·애니메이션까지 함께 검증한다.

3. 외피와 등 가죽의 형태를 만든다

M2의 00:30~03:00에서는 둥근 판의 외곽과 테두리 루프, 분리된 파트를 확인할 수 있다. M3의 01:00에서는 두께가 있는 접힌 외피 형태를 볼 수 있다. 예시 지갑에는 다음 순서로 응용한다.

1. 외곽의 가로·세로와 모서리 곡률부터 맞춘다. 물결 모양의 결이나 봉제선은 나중에 추가한다.

2. 등 가죽의 굽힘 영역은 하나의 날카로운 경첩선으로 접지 않고, 곡률을 조절할 수 있는 여러 줄의 면으로 구성한다. 접힘을 가로지르는 긴 면과 한 지점에 몰린 면을 피한다.

3. 몸판과 등 가죽의 2mm·1mm 차이를 구조 또는 두께 제어에 반영한다. 앞뒷면 사이 실제 거리를 평가해 확인한다.

4. Solidify를 사용하는 파트는 법선 방향, Thickness의 부호, Offset과 Rim을 확인한다. 이미 닫힌 두께 메시에는 같은 두께를 다시 더하지 않는다.

5. Bevel과 지지 루프를 이용해 모서리 반경을 조절한다. 정면이 부드럽다는 이유만으로 통과시키지 말고, 옆면의 두께와 하이라이트가 꺾이는 위치도 본다.

Solidify의 입력값은 로컬 좌표를 기준으로 하며, 비균일 Scale과 면 배치에 따라 최종 두께가 달라질 수 있다. Even Thickness도 모든 부분의 정확한 두께를 보장하지 않는다. Blender Solidify 설명

4. 카드 포켓은 열린 입구와 겹침을 가진 별도 층으로 만든다

M2의 06:30~08:30에서는 내부 판과 포켓을 분리하고 Solidify로 두께를 주는 작업을 볼 수 있다. 화면의 포켓 제작 원리는 사용하되, 영상 속 두께나 폭을 예시 제품의 실측값으로 취급하지 않는다.

1. 카드 한 장과 포켓 한 개로 맞춤을 확인한 뒤 슬롯 수를 늘린다. 카드가 들어가는 빈 공간과 입구가 실제로 열려 있어야 한다.

2. 앞 포켓의 높이, 뒤 포켓의 노출량, 좌우 여유를 먼저 맞춘다. 각 층을 외피 표면에 겹쳐 붙이기만 하면 접히거나 카드가 들어갈 때 관통할 수 있다.

3. 가장자리와 봉제되는 구역은 정리하되, 입구를 가로질러 막는 면이나 불필요한 Rim이 생기지 않았는지 검사한다. Rim은 한 장의 가죽 단면을 닫는 것이며 포켓 입구를 봉합하는 기능과 다르다.

4. 안쪽 면과 카드 사이 여유는 실제 카드 모델을 기준으로 본다. 재질 음영만으로 여유가 있는지 판정하지 않는다.

5. 층이 늘어날수록 닫혔을 때 두께가 누적된다. 펼침 상태, 중간 접힘, 닫힘 상태에서 슬롯 입구·등·카드의 겹침을 함께 확인한다.

포켓이 납작해지는 문제는 먼저 면 배치·지지 루프·두께·변형 가중치에서 찾는다. 가죽 범프를 강하게 해서 포켓 형태를 복구하려 하지 않는다.

5. 봉제선을 만드는 절차

M5에서는 Suzanne의 엣지를 복제·분리해 커브로 바꾸고, 작은 실 조각을 Array와 Curve로 배치한 뒤 두께와 둥근 단면을 조정한다. 02:30, 04:30~07:00 화면을 참고한다.

1. 외곽에서 일정하게 안쪽으로 들어온 봉제 경로를 만든다. 기존 엣지를 복제·분리하거나 별도 커브를 만들되, 실제 봉제되는 부분과 슬롯 입구를 구분한다.

2. 실 한 땀을 낮은 볼륨의 메시로 만든다. 실 중앙은 약간 떠 있고 양 끝은 표면으로 들어가도록 조절한다. 강좌의 평면 조각을 그대로 두지 않는다.

3. 반복하는 실과 경로의 원점, 진행 축, Scale을 맞춘다. 실이 엉뚱한 곳으로 날아가면 Count보다 이 정렬을 먼저 확인한다.

4. 강좌 방식에서는 반복을 만든 뒤 Curve로 변형한다. 영상의 120개 전후 Count나 1.1 Relative Offset은 예시다. 예시 지갑은 경로 길이와 실제 한 땀의 길이·간격으로 다시 정한다.

5. 모서리에서 실이 겹치거나 늘어지면 곡률과 간격을 함께 조절한다. 폐곡선의 시작·끝 중복과 열린 경로의 마지막 실 위치를 확인한다.

6. 실 단면을 충분히 둥글게 만들되 화면에서 구분되지 않는 세분화는 줄인다. 실 아래의 눌림 홈은 보조 표현이며, 실제 가죽 2mm·1mm를 뚫을 만큼 깊게 만들지 않는다.

7. 가죽과 봉제선이 같은 접힘을 따라야 한다. 같은 부모만 지정해도 동일한 표면 변형이 된다고 가정하지 말고, 기존 변형 체계와 커브 또는 실 메시의 연결을 검사한다.

Blender 5.2에는 새 Array와 Array Legacy가 함께 있다. 영상의 Fixed Count·Relative Offset·Fit Curve UI는 기존 방식과 대응하므로, 현재 설치 버전의 실제 항목을 확인한다. Fit Curve는 반복 길이를 맞추는 기능이며, 기존 방식에서 경로를 따라 구부리는 Curve modifier와 구분한다. Array Legacy, Curve modifier

6. Cloth Filter를 사용할 부분과 보류할 부분

M4의 02:00에서는 격자 영역 구분이 보이고, 03:00에서는 Inflate·Use Face Sets가 표시된다. 완성 결과는 다이아몬드 구역이 부푼 퀼팅이다.

예시 제품에 퀼팅 사양이 없다면 이 격자를 새로 넣지 않는다. 향후 부드러운 가죽의 큰 눌림을 표현할 때는 별도 시험 파트에서 경계와 봉제 부위를 마스크 또는 Face Sets로 보호하고 약하게 사용한다. 미세 엠보싱은 높이맵으로 처리한다. Cloth Filter가 만들어 낸 모양을 실측 두께가 보존되는 접힘 시뮬레이션으로 취급하지 않는다. Cloth Filter와 고정 영역

8. 다음 실제 작업에서 남길 기록

대상 버전, 기준 모델, 새 후보 경로, 변경한 파트, 사용한 modifier 순서, 실제 치수, 실밥 간격, 접힘 확인 시점과 남은 결함을 기록한다. 스틸 검수가 끝났다는 기록과 전체 영상 렌더가 끝났다는 기록은 구분한다.

파란 가죽 높이맵과 범프 및 디스플레이스먼트 매뉴얼

예시 파란 내피는 엠보싱의 능선과 골이 조명에 반응하되, 얇은 가죽과 카드 슬롯의 형태를 유지하는 것이 목표다. 사진의 진한 부분을 모두 깊은 골로 바꾸거나, 강한 범프로 접합 띠를 가리는 방식은 피한다. 먼저 높이 데이터와 반복 품질을 정리하고, 범프로 결의 방향·크기를 확인한 뒤 필요한 만큼만 실제 변위를 더한다.

아래는 강좌 D1~D5의 원리를 가죽 제작에 맞춘 적용 절차다. 학습 완료는 높이맵이나 제품 품질의 실제 검증 완료를 뜻하지 않는다.

1. 표현할 크기에 따라 방법을 고른다

대상기본 방법판단 기준
접힌 등, 가죽 두께, 슬롯 입구메시 모델링외곽과 실제 공간을 형성함
표면 위로 나온 실밥커브 경로를 따르는 실 메시근접·옆면에서도 실루엣이 필요함
작은 결과 엠보싱 음영Height → Bump 또는 RGB Normal → Normal Map표면 방향을 바꿔 빛에 반응시킴
옆면·접사에서 필요한 능선 높이세분화 + 실제 Displacement형상을 바꾸는 비용과 슬롯 변형을 감수할 이유가 있음

D1은 01:00 부근에서 범프·노멀의 외곽이 평평한 것을 보여 주며, 03:16 부근에서는 변위 강도에 따른 형상 변화를 비교한다. 범프의 명암이 진해졌다는 사실과 실제 정점이 움직였다는 사실을 구분한다.

2. 사진에서 쓸 표본과 실제 결 크기를 정한다

1. 원본 사진에서 가죽만 있는 부분을 고른다. 실밥, 슬롯 경계, 그림자, 반사점, 원근이 큰 부분을 제외한다.

2. 픽셀 수와 별도로 표본이 실제 몇 mm를 덮는지 정한다. 정확한 근거가 없으면 추정값으로 기록한다.

3. UV의 방향과 가로·세로 비율을 맞춘다. 정사각형이 아닌 이미지도 사용할 수 있으며, 이미지 자체를 정사각형으로 늘여 결을 찌그러뜨릴 필요는 없다.

4. Base Color, Height, Normal, Roughness가 같은 표본과 방향을 사용하는지 확인한다. 타일 크기와 회전이 어긋나면 색 능선과 빛의 반응이 분리된다.

표본의 물리 크기는 사진과 실측 근거로 확인하며, 정확한 근거가 없는 값은 추정으로 기록한다.

3. 높이 데이터는 가죽의 상대 높이로 정리한다

D2의 02:20~03:30는 흑백 변환과 Levels를, D4의 03:00~05:03는 주파수별 조절과 Height 확정을 보여 준다. 이를 현재 사진에 옮기는 절차는 다음과 같다.

1. 원본을 보존하고 편집용 사본을 만든다. 이후 필터 계산은 가능하면 16비트 문서에서 한다. 8비트를 16비트로 바꿔도 이미 잃은 높이 정보는 복원되지 않는다.

2. 흑백 변환 후 넓은 조명 얼룩과 실제 작은 결을 분리한다. 넓은 밝기 차이가 높이에 섞이면 타일마다 가죽이 부풀거나 꺼진다.

3. High Pass 또는 주파수 조절은 조명 성분을 줄이는 보조 도구로 사용한다. 능선 양쪽의 이중 테두리나 고리 모양이 생기면 필터 반경·대비를 재검토한다.

4. Levels와 대비를 조절해 능선·골을 읽기 쉽게 하되, 넓은 영역을 완전한 흑백으로 잘라 평평한 단과 절벽을 만들지 않는다.

5. 반사점, 색 얼룩, 업스케일이 만든 선을 높이로 오인하지 않는다. 단일 사진에서 얻은 결과는 사진 기반 추정 높이다.

6. 진짜 능선과 골이 반대로 읽히면 높이 반전 또는 Bump Invert를 시험한다. 색상의 밝기만으로 최종 방향을 결정하지 않는다.

7. 중립값과 값 범위를 기록하고 무손실로 저장한다. PNG/TIFF라는 확장자만으로 16비트를 보장하지 않으므로 실제 저장 파일의 비트 깊이를 확인한다.

5. 심리스 검수는 높이 변환 뒤 다시 한다

1. 단일 타일을 100%로 보고 흐린 복구 띠, 능선 끊김, 점 노이즈를 찾는다.

2. 가로·세로 Offset으로 원래 경계를 내부로 옮겨 본다. 기존 보정 지점과 다른 Offset도 검사한다.

3. 3×3 이상 반복을 축소해 밝기 체스판, 십자 띠, 결 밀도 차이, 독특한 흠집의 반복을 본다.

4. 최종 크기와 조명에서 검사한다. 경계 픽셀 평균 차이가 낮더라도 반복 띠가 보이면 보류한다.

5. 높이에서 자연스럽게 이어져도 노멀 변환 뒤 기울기 차이로 선이 생기는지 확인한다.

가장자리 단차가 줄어도 결 밀도와 복구 띠가 반복되면 부분 개선으로 기록한다. 새 높이맵에서 다른 Offset과 축소 반복을 다시 검사한다. 심리스 검수를 함께 적용한다.

7. 범프부터 약하게 확인한다

1. 중립 색과 고정 Roughness로 시작한다. 강도 0 대조군을 같은 카메라와 조명에서 만든다.

2. 먼저 결의 방향과 크기를 맞춘 뒤 강도를 올린다. 결이 너무 커 보이면 Strength보다 UV/표본 크기를 먼저 확인한다.

3. Strength는 효과를 섞는 정도, Distance는 높이 변화의 배율이다. 영상의 Distance 1을 mm 단위 가죽에 그대로 사용하지 않는다.

4. 빛을 좌우로 바꾸며 능선과 골의 음영이 반응하는지 본다. 사진의 하이라이트가 색에 고정돼 있으면 높이를 더 세게 하기 전에 사진 명암을 정리한다.

5. 근접과 최종 2K 구도를 모두 본다. 멀리서 모아레·반짝임이 생기면 반복 크기, 필터링, 대비를 다시 조정한다.

범프는 외곽 실루엣을 바꾸지 않는다. 외곽에 실제 능선 높이가 필요한 경우에만 다음 단계로 넘어간다.

8. 실제 디스플레이스먼트 두 경로

A. Displace modifier 경로

실제 메시를 변형하므로 Solid 모드에서도 형상 변화가 보인다. 텍스처, UV, Direction, Midlevel, Strength와 정점 그룹을 명시한다. 높이를 표현할 정점이 먼저 있어야 하므로 필요한 세분화는 Displace 앞에 둔다. D3의 07:00~08:18에서 순서와 UV에 따른 차이를 확인할 수 있다.

가죽처럼 얇은 파트는 앞면 마스크와 가장자리 완충 구간을 이용해 뒷면·슬롯·접합부가 함께 부푸는 것을 제한한다. 기존 접힘 modifier와의 상대 순서는 현재 리그와 마스크가 정의된 좌표를 확인해 결정한다. 강좌 큐브의 순서만 보고 기존 리그를 일괄 재배치하지 않는다.

로컬 변위 = (높이값 - Midlevel) × Strength

예를 들어 입력이 0~1, Midlevel이 0.5, Strength가 0.16mm이면 가중치·변환 전 범위는 -0.08~+0.08mm다. 실제 맵이 그 범위를 전부 사용하지 않을 수 있고, 월드 변위는 오브젝트/부모의 변환에 따라 달라진다. Displace modifier

B. 재질 Displacement 경로

Height → Displacement 노드 → Material Output의 Displacement를 연결한다. 노드 연결 외에 재질의 Displacement 방식, 지원되는 렌더 엔진과 충분한 세분화를 함께 확인한다. Bump Only이면 외곽이 바뀌는 실제 변위를 얻었다고 기록하지 않는다. 재질 변위 방식, Displacement 노드

D3의 화면은 Blender 3.3.1을 사용하며 예전 Experimental·Adaptive Subdivision 설정을 보여 준다. 현재 버전의 메뉴 위치와 지원 조건을 확인한다. 목표 장면의 EEVEE 렌더에 Cycles용 설정만 옮겨 적용 완료로 표시하지 않는다. 엔진에 독립적으로 메시를 바꾸는 modifier 경로와 구분한다.

두 경로를 같은 요철에 동시에 강하게 적용하지 않는다. 상세 시험 중에는 Apply로 영구화하지 말고 비교 가능한 modifier와 원본을 남긴다.

9. 시험 후보의 기록과 비교

대상 모델·이미지의 비트 깊이·물리 표본 크기·UV·세분화·적용 범위·Strength·Midlevel을 기록한다. 설정값과 실제 월드 변위는 다를 수 있으므로 구분한다.

동일 모델·카메라·조명에서 기본 재질, 범프만, 변위만, 범프+변위를 비교한다. 실제 변위는 켜짐/꺼짐의 평가 정점 차이로 확인한다. 슬롯 단면·실밥·접힘을 검수한 뒤 후보 채택을 판단한다. 시험 중인 맵과 승인본은 구분한다.

10. 색과 반사를 망치지 않는 연결 규칙

D5의 10:58 화면에는 Smoothness → Invert → Roughness 연결이 보인다. Roughness는 밝을수록 거칠고 Smoothness는 밝을수록 매끈하므로, 둘은 같은 이름의 맵이 아니다. 완전 반전 뒤 필요한 범위를 다시 조절한다.

가죽은 기본적으로 비금속으로 두고 Metallic을 올려 광택을 만들지 않는다. 금속 부품이 있다면 별도 재질 또는 확인된 마스크로 다룬다. AO를 Base Color에 곱하는 방법은 선택 사항이다. 사진에 이미 그림자가 있거나 렌더에서 접촉 음영이 계산되면 골이 지나치게 검어질 수 있으므로 AO 없는 상태와 비교한다.

Materialize의 평면 Parallax와 Blender의 실제 메시 변위, 사진의 색 변화와 가죽의 높이 변화, 미리보기와 저장된 데이터의 품질을 각각 구분한다.

지갑 모델링과 표면 맵 강좌 10편 분석 기록

분석일은 2026년 11월 1일이다. 모델링 5편과 범프·디스플레이스먼트 5편을 대상으로 원본 영상의 시간대별 화면, 확보된 자막, 로컬 시각 분석을 대조했다. 과거 완료한 심리스 강좌 5편과는 별도 작업이다.

이 기록에서 ‘학습’은 프로젝트에 다시 사용할 제작 원리와 확인 기준을 정리했다는 뜻이다. 모델 가중치를 재훈련한 것이 아니다. 전체 타임라인의 장면·움직임 분석과 표본 화면의 의미 분석을 구분하며, 모든 프레임과 모든 마우스 조작을 연속 시청했다고 표현하지 않는다.

3. 예시 지갑에 남기는 제작 원칙

1. 실제 카드 공간과 가죽 두께를 먼저 만들고 표면 결은 그 위에 추가한다.

2. 봉제선은 경로·한 땀·간격·접힘 연결을 별도로 제어한다.

3. 퀼팅 부풀림과 작은 가죽 엠보싱은 다른 크기의 작업이다.

4. 사진의 색, 촬영 명암, 상대 높이와 거칠기는 같은 데이터가 아니다.

5. Height를 Non-Color로 읽고, 미세 결은 범프부터 검수한다.

6. 실제 변위에는 충분한 정점·올바른 UV·중립값·단위·적용 범위가 필요하다.

7. 저장 파일의 비트 깊이와 반복 품질을 검사한다. 16비트라는 이유만으로 심리스나 실제 스캔 높이가 되지 않는다.

8. 새로운 시험은 승인 모델·본편 영상과 분리하고 비교 가능한 기록을 남긴다.

4. 분석 범위와 검증 자료

원본 영상은 10편 모두 로컬에 확보했다. 시간대별 화면 308개를 57개 시트로 직접 검토했고, 그중 8개 시점을 원본 해상도로 추가 대조했다. 제작 설명을 포함한 자막은 6편에서 확보해 읽었다. M4의 음악 자막 7행은 설명 근거에서 제외했고, M1·M2·M3는 자막 없이 화면을 분석했다.

로컬 Qwen3-VL은 10요청·40표본 프레임을 처리했다. FrameLens는 10편 전체 타임라인을 폭 640px·2fps 프록시로 처리하는 장면·움직임 분석에 사용했다. 이 두 결과가 모든 조작의 의미를 자동으로 확인했다는 뜻은 아니다. 세부 집계는 공개 분석 범위, 공개 파일 해시는 정본 파일 목록을 기준으로 한다.

원본 영상·자막·전체 캡처는 작업 폴더의 검증 근거로 보존한다. 매뉴얼에는 내용을 재구성한 설명과 원문 링크를 담았다. 새 텍스처 제작, Blender 수정, 렌더와 외부 게시를 이번 문서화 작업의 완료로 포함하지 않는다.
