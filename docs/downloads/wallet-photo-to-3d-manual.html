1부. 사진 촬영과 3D 표면 복원

사진 기반 지갑 3D 복원 매뉴얼 · 2026년 11월 1일

먼저 선택할 작업 방식

예시 지갑에는 실측 치수와 기존 모델을 중심으로 삼고, 사진 복원 결과를 외형·무늬·주름의 참고로 사용하는 방식이 적합하다. 아래 선택 기준과 제작 절차는 강좌 원리를 지갑 프로젝트에 맞춰 작성한 적용안이다. 실제 제품을 새로 촬영하거나 복원한 검증 결과는 아니다.

가진 자료선택할 방식얻을 수 있는 것과 확인할 한계
같은 지갑·같은 자세를 여러 방향에서 촬영한 원본 사진여러 사진을 이용한 포토그래메트리겹쳐 보이는 표면과 카메라 위치를 추정한다. 가려진 포켓 내부와 실측 두께는 별도 확인한다.
사진 몇 장과 실측 치수치수 기반 모델링 + 사진 대조기존 외피·내피·포켓 구조를 유지하며 실루엣과 패턴 위치를 맞춘다. 부족한 시점은 추가 촬영한다.
직선과 원근이 분명한 사진 한 장fSpy 카메라 맞춤 + 직접 모델링사진과 같은 시점의 투시를 맞춘다. 뒷면·깊이·정확한 두께가 자동으로 생기지는 않는다.
가죽을 가까이 촬영한 사진별도 재질·높이맵 작업색·결의 참고 자료다. 사진 밝기가 실제 높이라는 보장은 없다.

P1~P4는 여러 사진을 이용한 복원 계열, P5는 단일 사진의 원근을 맞춰 직접 모델링하는 계열이다. Gaussian Splat은 보기 좋은 공간 표현이 될 수 있지만, 포켓과 접힘을 편집할 수 있는 메시가 필요한 작업에서는 결과 유형을 먼저 확인한다. Polycam 결과 유형 안내, fSpy 원리.

촬영 전에 정할 것

1. 지갑 하나와 촬영 자세 하나를 정한다. 펼친 상태, 닫힌 상태, 카드가 들어간 상태는 각각 다른 세트로 기록한다. 색상 조합이 다른 지갑이나 서로 다른 실물을 한 복원 세트에 섞지 않는다.

2. 휘어짐과 포켓 벌어짐을 막는 안정된 받침을 준비한다. 받침이 가리는 부위는 누락 목록에 적는다. 손으로 들고 돌리면 형태와 가림이 계속 바뀌므로 피한다.

3. 원본 사진, 촬영용 사진 사본, 정렬 프로젝트, 원본 스캔, 정리한 메시, 텍스처, 검수 기록을 구분한다. 파일명에 제품·자세·촬영 회차를 넣는다.

4. 같은 물체 위에서 식별 가능한 기준점 두 개 사이 거리를 재고 기록한다. 다른 위치의 길이도 하나 더 재어 검증용으로 남긴다. 주변 자를 쓸 경우 지갑과 함께 움직이지 않도록 고정한다.

사진은 보통 절대 크기를 스스로 알려 주지 않는다. 알려진 거리를 지정해야 미터·밀리미터 기준으로 보정할 수 있다. RealityScan 거리 보정 안내.

빛과 카메라 준비

가죽의 반사광과 진한 그림자가 시점마다 움직이면 대응점을 찾거나 색을 합치는 데 방해가 된다. 넓은 확산광 아래에서 촬영하고, 노출이 날아가는 반짝임과 검게 뭉개진 접힘을 먼저 줄인다. 완성 가죽 제품에 분필·무광 스프레이를 바르는 방법은 이 프로젝트의 촬영 절차에 넣지 않는다.

• 한 촬영 묶음에서는 렌즈·줌을 유지한다. 휴대폰이 근접 촬영 중 다른 렌즈로 자동 전환하는지 확인한다. 렌즈가 바뀐 사진은 구분해 기록한다.

• 노출과 화이트밸런스를 가능한 한 일정하게 한다. 초점은 필요한 표면을 선명하게 유지하도록 확인한다. 설정을 고정한 탓에 흐릿한 사진을 계속 찍지 않는다.

• 지갑이 화면을 충분히 채우되 모서리가 잘리지 않게 한다. 거리는 초점과 표면 선명도를 기준으로 정한다. 화분·건물 강좌의 촬영 거리를 작은 지갑에 그대로 옮기지 않는다.

• 촬영 직후 확대해서 가죽 결, 봉제 구멍, 가장자리를 본다. 흔들림·초점 이탈·노출 실패 사진은 다시 찍는다. 업스케일이나 강한 선명화는 사라진 입체 정보를 복구하지 못한다.

확산광·고정 초점거리·선명도·겹침을 우선하는 원칙은 Meshroom 촬영 문서와 RealityScan 촬영 문서로 대조했다.

지갑을 촬영하는 순서

1. 지갑을 고정하고 카메라를 이동하며 중간 높이에서 한 바퀴 촬영한다. 제자리에 서서 카메라 방향만 돌리는 파노라마 촬영과 구분한다.

2. 처음 위치로 돌아와 시작 구간도 다시 겹쳐 찍는다. 경로의 끝과 시작을 연결한다.

3. 조금 더 높은 각도와 낮은 각도로 각각 한 바퀴 돈다. 이전 높이에서 보인 가죽·봉제·모서리가 다음 높이에도 겹쳐 보여야 한다.

4. 포켓 입구, 척추, 코너, 엣지코트 등을 보강 촬영한다. 전체 사진에서 접사로 갑자기 뛰지 말고 중간 거리 사진으로 이어 준다.

5. 뒤집기 전 옆면을 충분히 찍는다. 뒤집어도 같은 자세가 유지되는지 확인한 뒤 별도 세트로 촬영한다. 구부러졌다면 동일한 강체 복원으로 억지로 합치지 않는다.

6. 각 세트에서 안 보인 부위를 기록하고, 확대 확인 후 촬영을 마친다. 사진 수보다 선명한 연결과 표면의 가시 범위를 우선한다.

지갑용 시작 기준은 이웃 사진이 약 70~80% 겹치도록 천천히 이동하는 것이다. 이는 제품에 맞춘 보수적인 시작값이며 성공 보장값은 아니다. Meshroom은 방향에 따라 측면 60%·진행 방향 80% 이상을 안내하고, Polycam은 70~75%를 안내한다. 실제 정렬과 누락을 보고 보강한다. Meshroom 안내, Polycam 안내.

P4의 위아래로 높이를 바꾸며 도는 경로도 같은 원리를 익히는 데 유용하다. 수동 촬영은 이동을 멈추고 한 장씩 찍으므로 흔들림을 점검하기 쉽다. 자동 촬영이 항상 열등하거나 수동이 항상 우수한 것은 아니다. P4 경로와 수동 촬영.

사진 선택 → 정렬 → 표면 복원

다음은 프로그램 버튼 이름이 달라져도 유지되는 작업 순서다. 강좌의 RealityCapture·Blender 화면은 당시 버전이므로, 가격·계정·메뉴 위치를 현재 규칙으로 받아들이지 않는다.

단계할 일다음 단계로 넘어갈 조건
1. 사진 준비원본 보존 후 흐림·반사·형태 변화를 확인한다. 필요한 밝기·색 보정은 일관되게 한다.제품·자세가 하나이고 공통 무늬가 이어진다.
2. 사진 정렬사진을 불러와 카메라 위치와 희소 점군을 계산한다.카메라가 실제 촬영 경로와 비슷하게 배치된다.
3. 정렬 검수분리된 묶음, 누락 사진, 뒤집힌 면, 이중 윤곽을 살핀다.필요한 면이 연결되고 서로 다른 면이 잘못 붙지 않는다.
4. 복원 범위 설정지갑을 포함하는 영역을 정하고 배경·받침 범위를 줄인다.실제 지갑 가장자리를 잘라 버리지 않는다.
5. 시험 메시가벼운 설정으로 표면을 만들고 회색 화면에서 본다.모서리·포켓 입구·두께의 누락과 오류를 구분할 수 있다.
6. 상세 메시·텍스처시험 결과가 유효할 때 상세 복원과 색 합성을 한다.텍스처를 꺼도 형상이 납득된다.
7. 원본 보관·내보내기고밀도 원본을 보관하고 작업용 사본을 내보낸다.메시와 이미지 파일, 축·단위·스케일 기록이 함께 남는다.

Meshroom의 흐름은 사진 입력 → 특징점 대응 → 카메라 정렬 → 깊이 추정 → 메시 → 텍스처로 이해한다. P1에서 OBJ를 Blender에 가져온 뒤 정리하는 부분은 후처리 예시다. 풀·조명·배경을 추가해 보기 좋아진 장면과 스캔 자체의 완성도를 나누어 평가한다. P1 메시 확인, P1 Blender 가져오기.

앞뒤를 합칠 때: 마스크와 공통점

P3는 윗면·아랫면을 각각 정렬하고 시험 메시에서 받침을 잘라낸 뒤, 각 원본 사진에 대응하는 물체 마스크를 생성한다. 마스크가 불러와진 것을 확인하고 양쪽 사진을 다시 정렬한다. 실패하면 두 촬영 세트에서 같은 물리적 위치를 가리키는 공통점을 지정한다. P3 마스크, P3 공통점.

지갑에 적용할 때는 다음을 지킨다.

• 물체를 뒤집었는데 배경은 고정돼 있으면, 배경 대응점이 잘못된 정렬을 유도할 수 있다. 배경·받침을 제외한 마스크를 점검한다. 촬영 후 임의로 잘라 이미지 크기를 바꾸는 것과 마스크를 구분한다.

• 공통점은 동일한 봉제 구멍·특이한 흠집·식별 가능한 패턴의 정확한 위치로 잡는다. 반복되는 악어무늬의 비슷한 칸을 같은 칸이라고 추측하지 않는다.

• 한 공통점에 속하는 각 사진에서 위치를 확대 확인한다. 다른 위치에 새 점을 만든 뒤 같은 점으로 간주하지 않는다. 좁은 한곳에 몰린 점보다 서로 떨어진 여러 공통점을 확인한다.

• 지갑이 휘거나 포켓이 움직였다면 공통점을 늘려도 단일 강체라는 전제가 성립하지 않는다. 자세별 결과를 참고 자료로 남기고 치수 기반 모델링으로 이어 간다.

강좌의 “공통점 두 개로 해결된 사례”를 충분조건으로 일반화하지 않는다. 공통점의 수보다 정확성·배치·사진 간 식별이 우선이며, 강한 가중치로 틀린 대응을 강제하지 않는다. 공식 공통점 안내.

복원 실패를 고치는 순서

증상우선 확인조치
사진이 여러 묶음으로 분리됨겹침, 흐림, 공통 표면 부족중간 시점 보강 → 불량 사진 제외 → 마스크 → 정확한 공통점 순서로 점검한다.
모서리나 봉제가 이중으로 보임지갑 변형, 반복무늬 오대응자세별로 나누고 같은 실물의 같은 위치인지 다시 확인한다.
검정 외피가 뭉개지거나 구멍 남음반사, 어두운 노출, 가림확산광·노출·촬영 각도를 보강한다. 더 높은 품질 설정만 반복하지 않는다.
파란 내피 결이 매끈하게 사라짐촬영 거리·초점·얕은 요철전체 형상과 미세 재질 촬영을 나누고 실제 입체 해상도를 검증한다.
텍스처는 좋지만 회색 메시가 무너짐사진에 가려진 형상 오류치수와 실루엣을 기준으로 재촬영 또는 재모델링한다.
바닥이 막혔지만 포켓이 사라짐자동 구멍 메우기막힌 면을 실제 내부 구조로 간주하지 않고 포켓을 별도 설계한다.

2부. 예시 지갑에 적용하는 방법

예시 치수와 복원 결과의 역할

설명용 예시는 펼친 크기 160 × 110mm, 몸판 가죽 2mm, 척추 1mm다. 영상에서 측정한 수치가 아니며, 실제 제품에는 실측값을 대입한다. 기존 포켓·접힘 구조가 있다면 보존하며 대조한다.

스캔은 외형과 표면을 관찰하는 참고 자료로 둔다. 접힘과 카드 삽입이 필요한 지갑은 외피·내피·포켓·척추의 구조가 살아 있어야 한다. 한 덩어리의 삼각형 스캔을 얻었다고 바로 열리고 닫히는 지갑이 되는 것은 아니다. 이 부의 수치 예시·검수 기준·Blender 적용 순서는 프로젝트에 맞춘 제작안이다.

실측 크기로 맞추는 절차

1. 촬영 중 형태가 유지된 두 기준점의 실제 거리를 기록한다. 가능하면 복원 프로그램에서 거리 제약을 지정한다. 각 기준점은 여러 사진에서 정확히 같은 곳을 가리켜야 한다.

2. Blender로 가져온 뒤 장면의 길이 단위와 가져온 메시의 크기를 확인한다. 단위 표시만 바꿔서는 이미 잘못 들어온 크기가 자동으로 교정되지 않는다.

3. 기준 거리의 비율로 전체를 균일하게 확대·축소한다. 예를 들어 실제 100mm인 거리가 가져온 메시에서 80mm라면 배율은 100 ÷ 80 = 1.25다. 먼저 단위를 같게 환산한다.

4. 보정에 쓰지 않은 다른 길이로 검증한다. 펼친 지갑은 같은 자세에서 전체 폭·높이도 확인한다. 구부러진 표면의 길이와 양 끝의 직선거리를 혼동하지 않는다.

5. X·Y·Z를 각각 늘려 160 × 110mm에 강제로 끼워 맞추지 않는다. 독립 치수가 맞지 않으면 원근·변형·오정렬을 조사한다. 배율·축·기준점·검증 오차를 기록한다.

오차율(%) = 100 × |복원 거리 - 실측 거리| ÷ 실측 거리

허용 오차는 사용 목적에 따라 정한다. 제품 치수, 카드 간섭, 봉제 위치를 판단하는 작업에서는 실제 측정이 우선이다. 강좌나 프로그램 이름만으로 밀리미터 이하 정확도를 보장하지 않는다. 공식 거리 보정 원리.

Blender 정리와 재모델링

고밀도 스캔 원본을 보관하고 작업용 사본에서 시작한다. 메시를 내보낼 때 OBJ만 전달하고 연결된 MTL·이미지를 빠뜨리지 않는다. 파일을 다시 열어 색과 경로가 유지되는지 확인한다. P2에서 보인 메시 축소와 텍스처 내보내기는 이 흐름을 이해하는 예시다. P2 메시 축소, P2 내보내기.

1. 방향과 크기: 앞·뒤·위 방향을 정하고 실측 스케일을 검증한다. 원점·회전·배율을 정리하기 전 기존 리그와 어떤 관계로 배치할지 결정한다.

2. 불필요한 표면 제거: 배경·받침·떠 있는 조각을 지운다. 얇은 지갑 두 면을 하나로 합치는 넓은 거리의 자동 병합은 피한다. 모든 구멍을 한꺼번에 막기 전에 포켓 입구와 실제 틈을 구분한다.

3. 표면 검수: 텍스처를 끄고 앞·뒤·옆에서 실루엣, 법선 방향, 두께, 자기 교차를 본다. 매끈한 음영 표시가 잘못된 메시를 고쳐 주지는 않는다.

4. 편집 가능한 구조 제작: 몸판·척추·내피·포켓을 나누어 기존 모델과 대조한다. 접힘 주변에는 변형 방향을 따라 면을 배치하고 포켓 입구와 봉제 경로를 유지한다.

5. 선택적 형상 대조: 필요하면 스캔 표면에 가까이 맞추는 도구를 제한된 부위에 사용한다. 앞뒤가 가까운 1~2mm 가죽에서 잘못된 면으로 달라붙지 않는지 확인한다. 스캔 오차까지 그대로 복사하지 않는다.

6. 세부 데이터 이전: 검증된 고밀도 표면은 정리한 모델에 법선·높이 정보를 굽는 참고로 쓸 수 있다. 베이크 범위가 반대편 가죽을 잡지 않는지 시험한다. 불량 스캔에서 구운 맵도 불량이다.

메시를 줄이는 Decimate 비율이나 최종 삼각형 수를 강좌에서 복사하지 않는다. 지갑의 모서리·1mm 척추·포켓 틈이 유지되고 기존 2K 장면에서 필요한 품질과 속도를 충족하는지로 판단한다. 접힘용 면 배치가 필요하면 단순 축소 대신 다시 면을 구성한다.

사진 한 장뿐일 때: fSpy 활용

P5는 사진 속 서로 직교하는 평행선 묶음으로 카메라 원근을 맞추고, Blender에서 면·문·배관 등을 직접 만들어 사진을 투사한다. 건물처럼 긴 직선이 많은 대상에 유리하다. P5 fSpy 설정, P5 Blender 형상 제작.

지갑용 적용 순서는 다음과 같다.

1. 왜곡이 적은 원본 사진을 고른다. 과도한 광각, 파노라마, 원근 보정된 이미지와 비대칭으로 잘린 사진은 카메라 추정에 불리할 수 있다.

2. 실제로 평행하고 서로 직교하는 방향의 선을 찾는다. 휘어진 가죽 모서리나 곡선 봉제를 건물의 직선처럼 사용하지 않는다. 유효한 선이 없으면 치수 기반 모델을 사진과 수동으로 대조한다.

3. 원점과 축을 정하고 알려진 기준 길이를 지정한다. 사진상 가이드가 다른 위치에서도 자연스럽게 맞는지 확인한다. 기준 길이가 없는 기본값을 실측 크기로 해석하지 않는다.

4. 맞춘 카메라를 Blender로 가져와 기존 지갑의 실루엣·포켓 위치·패턴 배치를 대조한다. 뒷면과 깊이는 다른 사진·실측·구조 자료로 만든다.

5. 사진 투사는 해당 카메라에서의 외관 대조에 사용한다. 옆면이나 뒷면으로 이동했을 때 늘어짐과 가림을 확인한다. 지갑을 여닫는 장면에는 일반 UV와 필요한 면의 실제 이미지 자료를 준비한다.

fSpy는 카메라의 위치·방향·시야각을 추정한다. 단일 사진의 보이지 않는 부분이나 완전한 깊이 정보를 계산하는 도구로 설명하지 않는다. 공식 원리와 입력 조건, 기준 거리와 원점 설명.

사진 투사, UV와 재질의 차이

강좌의 카메라 기반 노드 방식은 투사 카메라에 의존한다. 카메라와 함께 보관할지, 일반 UV에 고정할지 먼저 정한다. UV Project 방식은 사용할 UV·투사 카메라·이미지 종횡비를 확인하고, 복사본에서 결과를 고정한 뒤 카메라 없이 다시 열어 점검한다. UV 좌표를 고정하는 것과 그림자·반사광을 제거해 순수한 표면색을 만드는 작업은 별개다. P5 투사 고정 과정.

사진에는 표면색 외에도 빛·그림자·반사가 함께 들어 있다. 사진을 Base Color와 Bump·Roughness에 동시에 연결하면 그럴듯해 보일 수 있지만, 검정 무늬가 움푹 들어가거나 하이라이트가 돌출되는 오류도 생긴다. P1·P5의 이런 연결은 시각적 후처리 예시로만 참고한다.

• 재질 작업 후: 색과 높이의 역할 구분, 결 방향·물리 크기·반복 경계 확인, 옆·뒤 시점의 UV 늘어짐 확인.

• 애니메이션 검수: 열림·중간·닫힘에서 척추, 포켓, 카드 간섭을 확인한다. 좋은 정지 스캔이 좋은 접힘을 보장하지 않는다.

보조 영상 분석의 오류와 교정

Qwen3-VL은 후보 장면을 설명하는 보조 수단이었다. 여러 이미지를 한 번에 입력했을 때 다른 시점의 내용을 섞거나, 보이는 UI에서 조작 완료까지 추정하는 오류가 있었다. 아래는 원출력을 직접 화면·자막과 비교해 배제한 대표 사례다.

공식 문서 대조와 재사용 순서

강좌에서 변하지 않는 촬영·기하 원리를 추출하고, 버전 영향이 있는 설명은 다음 공식 문서로 대조했다. 문서 확인일은 2026년 11월 1일이다.

• RealityScan 촬영: 카메라 이동, 공통 표면, 작은 각도 변화와 연결 경로.

• RealityScan 거리 보정: 알려진 거리로 절대 스케일을 정하는 방법.

• RealityScan 공통점: 같은 위치 확인, 가중치와 독립 점검.

• Meshroom 촬영: 확산광·고정 초점거리·겹침·초점 확보.

• Polycam Object Mode: 촬영 모드, 겹침, 마스크와 결과 유형.

• Polycam 기존 사진·영상 처리: 사진 입력과 메시·Splat의 구분.

• fSpy 기본 원리, 설정 예제: 소실 방향과 기준 길이, 입력 사진의 한계.

처음에는 P4로 촬영 경로를 익히고, P1 또는 P2로 복원 흐름을 이해한다. 앞뒤 결합이 필요할 때 P3를 다시 본다. 사진 수가 부족한 경우 P5의 카메라 맞춤을 참고하되, 실측과 직접 모델링을 중심으로 진행한다.
