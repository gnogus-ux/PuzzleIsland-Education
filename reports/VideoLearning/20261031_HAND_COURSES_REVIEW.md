## 주요 관찰과 매뉴얼 반영

### 기본형: 실패 시도까지 포함한 순서

실제 손의 엄지 대립·손바닥 볼륨·마디를 관찰한 뒤 손목과 손바닥, 네 손가락을 만든다. 손목12스팬은 이 예제의 접속 계획으로만 기록했다. 약08~10분의 첫 엄지는 출발 면 배분 문제가 있고 약19분 이후 실제로 다시 만든다. 실패 시도와 최종 방향을 분리해, 처음 나온 조작을 그대로 정답으로 전달하는 오류를 막았다.

메타리그를 이용한 손 변형 시험은 확인했지만 Rigify 최종 컨트롤 생성까지 확인했다고 하지 않았다. 약30분 Join 뒤에도 손목 틈이 보이며 이후 접속면을 채우므로 오브젝트 병합과 실제 연결을 구분했다. 손톱 제작·UV 완성·모든 관절 QA·외부 서비스 업로드는 확인한 범위를 넘겨 주장하지 않았다.

### 리토폴로지: 제작 수업과 비교 수업 구분

세 손의 중립·주먹·가리키기·벌림을 비교하고 손바닥의 색 구분과 관절의 면 전환을 읽었다. 색을 가중치로 해석하지 않았다. 관절 밑3→2스팬은 하나의 모티프이며 모든 밀도와 스타일에 강제하지 않는다. 엄지를 돌아 손바닥과 팔로 연결하는 경로도 목적에 따라 달라진다.

강사는 같은 리그·자동 가중치 기반 비교를 설명하지만 강사 원본의 모든 그룹·보정 데이터를 직접 조사하지 않았다. 발 예시는 면 흐름 원리의 확장으로만 기록했다. 회원 전용 전체 제작 과정을 열거나 우리 캐릭터의 발 수정 범위를 늘리지 않았다.

### 리깅: 회전 전달과 실제 피부 변형 구분

세 마디와 제어 뼈, Copy Rotation 대상·공간·roll·축 복사·잠금, 커스텀 모양, 복제·엄지 맞춤, Deform 오류와 재바인딩, 가중치 보정의 순서를 추적했다. 커스텀 모양을 영향선이나 실제 변형량으로 취급하지 않는다. 채널 잠금과 Limit Rotation을 혼동하지 않는다. Edit Mode의 그룹 소속 제거를 메시 정점 삭제로 오해하지 않는다.

강좌 자체가 마지막 가중치 보정 미완료를 밝히므로 ‘최종 리그·전체 QA PASS’로 보고하지 않았다. 우리 파일의 모든 그룹을 삭제하고 재바인딩하는 절차를 권장하지 않았다. IK·driver·손목 전체 계층·게임 엔진 내보내기는 확인되지 않은 작업이다.

## 현재 버전 공식 문서 대조

ego-browser 전담 공간33에서 세 제작자 공개 페이지와 다음 공식5.2 문서를 실제 읽었다. 공간33은 마지막에 한 번 정상 종료했고 다른 전담 공간은 접근하지 않았다. 업데이트 안내는 있었으나 설치하지 않았다.

- [Copy Rotation](https://docs.blender.org/manual/en/5.2/animation/constraints/transform/copy_rotation.html): 옛 Offset와 Offset (Legacy)의 관계·비권장 상태, Add/Before/After 차이. 옛 Offset를 Add로 무조건 치환하지 않음.
- [Bone Roll](https://docs.blender.org/manual/en/5.2/animation/armatures/bones/editing/bone_roll.html): Recalculate Roll은 Shift+N, 정렬 기준을 선택해야 함.
- [Armature Deform](https://docs.blender.org/manual/en/5.2/animation/armatures/skinning/parenting.html): 변형 뼈 기준 자동 가중치·수동 수정 필요성·동명 기존 그룹 덮어쓰기.
- [Bone Collections](https://docs.blender.org/manual/en/5.2/animation/armatures/properties/bone_collections.html):4.0부터 Armature Layers와 Bone Groups를 대체.
- [Viewport Display](https://docs.blender.org/manual/en/5.2/animation/armatures/bones/properties/display.html): Custom Shape는 표시이며 별도 오브젝트와 표시 변환·크기를 사용.

문서 대조는 실제 Blender5.2 재현과 구분한다. CGC 제목2.6/설명2.5 차이를 숨기지 않았고 정확한 패치 버전은 미확인이다. 리토폴로지 영상의4.4.3 표기는 원해상도에서 확인했다.

## 검증·게시·보존 범위

- Markdown 상대 링크의 대상 존재, JSON 파싱·집계·원본 해시, SVG XML과 외부 미디어 미포함을 확인한다. SVG를 별도 PNG로 렌더해 글자·범례·레이아웃을 직접 검토한 뒤 게시한다.
