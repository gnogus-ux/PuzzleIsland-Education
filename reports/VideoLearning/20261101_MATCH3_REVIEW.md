## 범위와 수행

- Taft Unity/C# 실제 플레이리스트 65편 전체, Catlike 본문·FAQ·라이선스, Winterbolt 1편, git-amend 공개 3편과 제작자 C# 7개를 읽었다.
- 영상 69편의 개별 메타데이터 길이 합은 23:05:26이다. Taft 목록 표시 합20:59:05와 개별 영상 합20:58:27는38초 차이가 나며 원본별 값을 그대로 보존했다. 이 수치는 연속 시청/청취 시간 보고가 아니다.
- 실제 확인한 영상 고유 시점 2,094개, 시트 472장, 단독 프레임 135장. 개요/상세/단독의 중복 시점은 합산하지 않았다.
- 전편의 시작~끝 90초 개요와 전체 정제 자동자막을 읽고 핵심 코드·UI를 추가 확인했다. Taft 앞 40편은 30초 상세 표본도 읽었다. 뒤 25편의 준비만 된 미열람 상세 이미지는 완료 수에서 제외했다.
- 추출 이미지는 폭1280, 시트는1600×1440이다. 원본이1920×1080인 영상을 원 해상도로 읽었다고 주장하지 않는다. 음향 전체 청취/모든 프레임·명령 확인도 아니다.

## 중요한 교정

| 관찰 | 문서 반영 |
|---|---|
| Taft Part번호/목록 혼동 | Unity 실제65개와 소수/Android 편 모두 인벤토리에 포함 |
| 여러 편에 걸친 오타·수정 | 중간 입력 프레임, 최종 코드, 후속 자막·시연을 구별 |
| coroutine/await 설명 | 병렬 스레드/자동 입력 잠금이라고 가르치지 않음 |
| run·연결 그룹·고유 제거 | Winterbolt flood fill과 직선 매치를 분리, 전역 개수로 특수 판정 금지 |
| 컬렉션 API | Union 반환 미사용·같은 리스트 cast·반복 중 변경 구별 |
| 낙하·장애물 | 생성만이 아닌 리필/셔플/힌트 등 영향 경로를 함께 검증 |
| 저장·종료 | 오래된 BinaryFormatter 예제·counter0·씬 UI 수명·별점 경계를 보완 항목으로 기록 |
| Catlike | skin 분리의 장점과 Unity 의존·점수 정책·교착 종료·첫수 AI 한계 함께 기록 |
| git-amend | 공개3편/7소스에서 없는 인접성·busy·rollback·cascade를 구현했다고 하지 않음 |

코드 추론으로 기록한 Catlike 탐색 경계, Slime 반복/경계, 폭탄 순환, 부모 좌표 가정은 Unity에서 실행 재현한 버그 판정이 아니다. 교육 예제의 규칙·화면을 실제 프로젝트의 승인 기준보다 우선하지 않았다.

Unity6.3·Microsoft 공식 웹 문서 재대조는 미완료다. [호환 페이지](../../docs/MATCH3_UNITY6_COMPATIBILITY.md)는 확인 목록이며 검증 완료표가 아니다.

## 실행하지 않은 것

Unity 실행·컴파일·빌드·APK 설치·실기기 QA·게임 코드/세이브 변경·Blender 조작·Claude/Painter 연결 테스트를 하지 않았다. 이 매치3 학습의 외부 AI 호출은0회다. 새 도구/패키지/유료 자원을 설치하거나 구매하지 않았다.

## 공개 범위

교육 설명·새 의사코드·자체 SVG·출처 링크·회차별 분석·검토 해시만 공개한다. 원 영상·음성·자동자막 원문·대량 화면·외부 코드 전체·자산·개인 PC 경로·비공개 저장소의 새 Git 참조는 포함하지 않는다. 원 자료 라이선스와 현행 API 근거는 각 문서에서 구별한다. 학습 자료가 실제 게임 제작/검증 완료를 대신하지 않는다.
