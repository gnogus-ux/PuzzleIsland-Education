## PC에 설치된 분석 도구의 사용

- **Qwen3-VL 4B Instruct / Ollama:** 실제 로컬 모델 `qwen3-vl:4b-instruct`에 10번 요청, 총 40장의 시간순 표본을 제출했다. 5편 모두 비어 있지 않은 응답을 받았다. 원본 가로 1920 이미지는 입력 때 가로 1024로 축소했다. 모델 응답만으로 메뉴·숫자·성공 여부를 확정하지 않았다.
- **FrameLens AI:** 각 강좌의 핵심 60초씩, 총 300초를 640px·3fps의 무음 프록시로 분석했다. 프록시에서 총 15개 장면 구간을 검출했다. 이것은 원본 전편의 컷 수나 제작 단계 수가 아니다. 화면 변화·대표 프레임·움직임/이미지 지표 분석이며 메뉴를 해석하는 기능과 구분한다.
- **VideoReverse:** 설치 구성은 외부 의미 분석 API가 연결되지 않은 mock 시연 상태여서 실행하지 않았다. 가상 결과를 원본 강좌의 역분석으로 채택하지 않았다.
- 새 유료 API·외부 AI 영상 전송은 없었다. 원본 영상·음성·자동 자막·대량 캡처·AI 요청과 원시 응답은 Git에 게시하지 않았다.

## 모델·자막의 오류를 교정한 사례

1. Qwen이 hogual의 180%·50% 등 화면 확대율을 텍스처의 실제 크기 변화처럼 설명했다. 원본 문서 제목과 화면을 대조해 **배율과 물리 스케일을 분리**했다. History의 항목과 활성 레이어도 섞어 읽은 값은 제외했다.
2. PiXimperfect 다중 이미지 응답 일부는 07:00 화면에 10:00의 Layer Style 설명을, 08:25.5에 뒤쪽 View 메뉴를 붙였다. 실제 07:00 화면은 `Dodge and Burn`, `Soft Light`, Flow 1%다. 모델의 시간 배정과 `uncertain=false`를 신뢰 근거로 쓰지 않았다.
3. What Make Art의 00:20에 Canvas Size 대화상자가 있다고 한 모델 설명은 실제 01:00 화면과 혼동한 것이다. 01:00의 3840×2160→2160×2160 경고와 03:06.5의 +1080/+1080·Wrap을 원본으로 확인했다.
4. PTC 09:34.5의 `Layer Mask > Density 100%`는 브러시 불투명도나 이미지 Fill 수치가 아니다. 해당 화면의 Curves/Multiply·마스크와 도구 옵션을 별개로 읽었다. 변형 선택 영역의 W/H도 전체 문서 크기로 채택하지 않았다.
5. TriMech 자막의 Offset을 mirror처럼 표현한 문장은 실제 `Wrap Around` 선택과 구분했다. 03:50.5의 결과는 노멀 생성 대화상자다. 이를 실제 메시 변위 완료나 흑백 높이 맵 생성으로 기록하지 않았다.

자동 자막의 고유명·도구명·단축키 오류는 문맥으로 정리했으며 긴 원문이나 문장 번역을 복제하지 않았다. 매뉴얼은 강좌 내용의 자체 요약과 별도 적용 원리로 작성했다.

## 작업 원리로 정리한 결론

- 같은 문서의 반대편으로 픽셀을 옮겨 바깥을 이어 놓고 내부 접합을 정리한다. 절반 Offset은 편한 시작점이며 유일한 값은 아니다.
- 무늬에 맞춘 짧은 복구, 다른 Offset 재검사, 축소 반복에서의 명암·색·밀도 보정이 모두 필요하다.
- 경계 평균 차이 감소는 시각 품질 통과가 아니다. 내부 복구 띠와 기울기 문제도 검사한다.
- 사진 밝기→높이는 추정이며, 컬러 패턴·노멀·실제 변위를 구분한다. 가죽 높이 제작과 Blender 연결은 강좌 5편의 실측 결과가 아닌 매뉴얼의 적용 제안이다.

## 공식 문서와 적용 한계

Adobe의 현재 Pattern Preview/Define Pattern 안내와 Blender 5.2의 Displacement, Image Texture, Displace modifier를 웹에서 직접 읽었다. 실제 링크는 매뉴얼과 검증 JSON에 기록했다. Adobe의 예전 3D FAQ 주소는 다른 제품의 글로 이동해 현재 노멀 생성 메뉴 지원의 근거로 사용하지 않았다. 강좌에 나온 옛 Photoshop 3D 메뉴와 현재 PhotoCraft의 기능 일치는 미검증이다.

이번 결과는 **교육 문서 작성 완료**다. 새 텍스처 제작·Blender 적용/렌더·Unity/Android 시험·독립 검수 완료를 의미하지 않는다. 기존 승인 게임/캐릭터/지갑 에셋은 수정하지 않았다. 학습 원본의 권리는 제작자에게 있으며 외부 에셋 재배포 권한을 얻었다고 가정하지 않는다.
